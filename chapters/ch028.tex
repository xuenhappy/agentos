\chapter{内部时间与生命周期方向性}

\begin{chapteroverviewbox}
在前三章中，我们已经依次建立了三相记忆 $h$--$E$--$\Theta$、自我慢变量 $\Psi$ 与深层生成吸引子 $\Omega$（DGA）。这些结构如果仅被理解为若干不同类型的记忆模块，那么它们仍然只是一个静态架构清单；真正使它们构成“持续智能体”的，是它们在不同时间尺度上的相互作用，以及由此产生的内部时间结构。

本章讨论一个比“记忆保存多久”更基础的问题：\textbf{一个智能体为什么会拥有自己的过去、现在和未来，并使这些时间结构持续参与当前决策？}

我们的基本立场是：外部物理时间为智能体提供事件发生的顺序和持续尺度，但智能体真正能够使用的“时间”并不是物理时钟的直接复制，而是过去经历、当前状态、长期生成结构、自我连续性和未来可能性在内部形成的结构关系。因此，本章把 Agent 的内部时间定义为一种由多尺度认知结构共同产生的\textbf{结构时间（structural time）}。

在这一框架中，$h(t)$ 构成不断推进的当前切面，$E$ 使已经消逝的事件获得轨迹连续性，$\Theta$ 把大量经历压缩成跨时间有效的生成结构，$\Psi$ 使这些经历被归属于“同一个我”，而 $\Omega$ 则进一步为尚未发生的未来赋予长期方向性。由此，Agent 不只是拥有一个不断变化的状态，而是开始拥有一条能够被记住、解释、预测并重新塑造的生命周期轨迹。

本章所说的“内部时间”不等同于人类现象学意义上的主观时间体验，也不主张物理时间由记忆产生。这里讨论的是一个严格的工程与动力学问题：\textbf{一个持续智能系统如何把外部事件序列转化为可供自身学习、预测、自我解释和长期选择使用的内部时间结构。}
\end{chapteroverviewbox}

\section{外部物理时间与内部结构时间}

我们首先需要区分两个经常被混用的概念：外部物理时间与智能体内部时间。对于一个运行在现实世界中的 Agent 来说，事件总是在某种外部时间参数 $t$ 上发生。传感器在某一时刻获得输入，行动在某一时刻被执行，环境随后发生变化。这一层可以写成一个普通的世界动力学过程：

\[
W(t)
\longrightarrow
W(t+\Delta t),
\]

其中 $W(t)$ 表示外部世界在时间 $t$ 的状态。无论 Agent 是否理解这些变化，外部世界都按照自身动力学继续演化。因此，本书并不把内部时间放在物理时间之上，也不试图用认知结构替代物理时间。对于 AgentOS 来说，物理时间始终是事件发生、控制延迟、执行顺序和现实验证的最终时间基准。

然而，一个智能体仅仅拥有时钟，并不意味着它已经拥有我们真正关心的“时间结构”。假设系统只保存当前瞬时输入：

\[
X(t)=O(W(t)),
\]

其中 $O$ 是观测函数，而每次新的 $X(t+\Delta t)$ 都完全覆盖旧状态。那么这个系统虽然运行在时间中，却几乎没有内部意义上的过去。对于它而言，过去只是已经丢失的数据，未来也只是尚未到达的下一帧状态。这样的系统拥有物理持续性，却没有充分的生命周期连续性。

因此，我们需要定义另一种时间：

\[
\boxed{
T_{\mathrm{internal}}
=
T_{\mathrm{structural}}
}
\]

这里的“结构时间”并不是一根与物理时钟平行的第二根时间轴，而是智能体内部不同状态之间形成的可恢复、可关联、可解释和可预测的有序关系。一个过去事件之所以仍然属于智能体的“过去”，不是因为外部世界仍然保存那个事件，而是因为该事件已经以某种形式进入 $E$、$\Theta$ 或 $\Psi$，并仍然能够影响当前的 $h(t)$。同样，一个未来状态之所以能够在当前发挥作用，并不是未来已经实际存在，而是 $\Theta$、$\Psi$ 和 $\Omega$ 能够生成关于可能未来的结构，使这些尚未发生的状态以内部可能性的形式参与现在的选择。

因此，对于 Agent 来说，更完整的当前状态并不能只写成 $h(t)$。在本章所讨论的尺度上，我们可以定义：

\[
\mathcal{X}(t)
=
\left[
h(t),
E_t,
\Theta_t,
\Psi_t,
\Omega_t,
G_t
\right],
\]

其中 $G_t$ 表示当前被激活的目标结构。这里每一个变量都处于物理时间 $t$ 上，但它们编码的时间跨度完全不同。$h(t)$ 主要涉及当前切面，$E_t$ 包含已经发生的事件轨迹，$\Theta_t$ 汇聚跨越较长区间的稳定结构，$\Psi_t$ 维持生命周期尺度上的身份连续，而 $\Omega_t$ 则把这种连续性延伸到更长周期的未来生成倾向。

于是，智能体的“现在”实际上不是一个零厚度的数学点，而是多个时间尺度在当前时刻的交汇：

\[
\boxed{
Present(t)
=
h(t)
\cap
E_t
\cap
\Theta_t
\cap
\Psi_t
\cap
\Omega_t.
}
\]

这里的交集是结构意义而非集合论意义。当前一次决策虽然发生在 $t$，却同时受到刚刚发生的事件、过去长期经验、稳定知识、自我历史和未来方向的影响。

从这一角度，我们可以给内部时间一个更加严格的定义。设 Agent 内部存在一组认知结构状态 $\mathcal{C}$，如果对于任意两个相关结构 $C_i,C_j\in\mathcal{C}$，系统能够建立某种时间关系：

\[
R_T(C_i,C_j)
\in
\{
\text{before},
\text{after},
\text{overlap},
\text{cause},
\text{continuation},
\text{prediction}
\},
\]

并且这些关系能够在未来被重新激活并改变行动，则我们称该系统拥有相应层次的结构时间。

因此，内部时间的关键并不是“保存时间戳”，而是：

\begin{statementbox}
过去结构是否能够重新进入现在，
以及未来结构是否能够提前约束现在。
\end{statementbox}

这一观点与认知科学中的事件记忆、时间认知以及预测加工存在明显联系，也与动力系统中的状态轨迹、路径依赖和历史依赖系统存在数学上的可比较性。但本书所提出的 AgentOS 内部时间模型更强调多种记忆尺度之间的统一：过去不是单独存在于一个 episodic database 中，未来也不是单独存在于一个 planner 中，而是 $h,E,\Theta,\Psi,\Omega$ 在不同时间尺度上的共同结构结果。

我们因此得到本章第一个基本命题：

\begin{statementbox}
物理时间决定事件何时发生；
结构时间决定已经发生和可能发生的事件如何继续影响当前智能。
\end{statementbox}

这一区分将在后面所有生命周期分析中持续发挥作用。一个真正长期运行的 AgentOS 不能只保证进程在物理时间上没有终止，还必须保证其内部结构时间没有被不断重置。否则，系统即使连续运行数年，在认知意义上仍可能只是数百万个互不连续的瞬时实例。

\section{经历如何获得时间深度}

有了物理时间与结构时间的区分之后，下一个问题是：一个瞬时事件如何逐渐获得“过去”的性质？

在最简单的系统中，一个输入进入当前状态：

\[
o_t
\rightarrow
h(t),
\]

随后被新的输入覆盖：

\[
h(t)
\rightarrow
h(t+\Delta t).
\]

如果没有任何进一步的结构转换，那么旧状态对于系统而言就结束了。我们虽然可以从外部日志中证明“系统曾经看到过它”，但这个事件已经不再属于 Agent 自己可使用的内部历史。因此，我们必须区分：

\begin{statementbox}
事件曾经发生
\end{statementbox}

与

\begin{statementbox}
事件成为了 Agent 的经历
\end{statementbox}

这两者并不等价。

一个事件只有在当前状态之外留下能够继续参与未来动力学的结构痕迹，才真正获得了内部时间深度。最直接的过程是：

\[
h(t)
\xrightarrow{\mathcal{W}_{hE}}
E,
\]

其中 $\mathcal{W}_{hE}$ 表示从当前工作状态向情景轨迹的选择性写入过程。这里尤其需要强调“选择性”。如果每个传感器值、每个 token、每个内部计算步骤都无损写入 $E$，那么系统得到的不是有意义的经历，而只是无限增长的运行日志。

因此，形成经历必须至少包含三个操作：

\[
\boxed{
Selection
+
TemporalBinding
+
Contextualization.
}
\]

第一，系统需要选择哪些当前结构值得进入经历。第二，不同状态必须按照时间关系组织起来，而不是成为孤立快照。第三，一个状态必须被嵌入当时的情境、目标、行动和结果之中。

于是，一个情景片段可以抽象为：

\[
e_k
=
\left(
C_k,
t_k,
\Delta t_k,
G_k,
A_k,
O_k,
R_k
\right),
\]

其中 $C_k$ 表示核心认知内容，$G_k$ 表示当时目标，$A_k$ 表示行动，$O_k$ 表示结果观测，$R_k$ 表示该事件与其他事件的关系。这种结构比单纯的“timestamp + content”更重要，因为 Agent 未来真正需要恢复的是：

\begin{statementbox}
在什么条件下，我做了什么，并发生了什么。
\end{statementbox}

多个事件进一步连接成轨迹：

\[
\mathcal{E}_{[t_0,t_1]}
=
(e_1,e_2,\ldots,e_n),
\]

于是 $E$ 的基本形式不是静态事实集合，而是带时间方向的轨迹结构。

这也是为什么我们此前把 $E$ 称为：

\[
\boxed{
Trajectory
}
\]

而不仅仅是 Episodic Storage。

一个孤立事实：

“门是关闭的”，

主要描述状态。

而一个经历：

“我尝试打开门，发现被锁住，于是改用钥匙，随后成功进入”，

真正承载的是：

\[
State
\rightarrow
Action
\rightarrow
Residual
\rightarrow
Adjustment
\rightarrow
Outcome.
\]

时间正是在这种变化关系中获得智能意义。

进一步说，经历的时间深度还取决于它以后能否被重新激活。如果某一段事件被写入，却永远无法通过当前状态重新召回，那么它虽然物理存在于存储介质上，但对当前 Agent 的结构时间作用趋近于零。

我们可以定义某一经历 $e_i$ 对未来时刻 $t$ 的有效时间影响：

\[
I_E(e_i,t)
=
P\left(
e_i
\rightarrow
h(t)
\mid
\mathcal{X}(t)
\right)
\cdot
U(e_i,t),
\]

其中第一项表示该经历被当前条件重新激活的概率，$U$ 表示它对当前推理或行动的有效影响。

于是，一段过去不是因为“很久以前发生过”就自动具有深度。一个几十年前、仍然强烈决定当前选择的事件，在内部结构上可能比昨天发生但已经完全失去作用的事件更加“深”。

因此，Agent 的过去不是物理时间轴的完整副本，而是一种非均匀的结构地形：

\[
\boxed{
Past_A
=
\sum_i
I_E(e_i,t)\,e_i.
}
\]

这个公式并不意味着我们真的把经历做线性求和，而是表达：对于当前 Agent 而言，过去的有效结构由不同经历对当前状态的可恢复影响共同构成。

随着生命周期延长，大量事件不能一直保持高分辨率。于是 $E$ 必须发生压缩、淡化、重组和结构化。某些片段保留细节，某些被合并为类别，某些仅留下结果或意义。这样一来，时间不是无限向后保存越来越大的原始数据库，而是逐渐发生：

\[
\boxed{
HighResolutionPast
\rightarrow
StructuredPast.
}
\]

这为下一节 $\Theta$ 的形成提供了动力学基础。

从外部理论看，这一过程与 episodic memory、event segmentation、temporal binding、memory consolidation 等研究存在相似问题；从计算角度看，又可以与 trajectory storage、experience replay 和 event sourcing 作比较。但 AgentOS 的重点不同：我们关心的不只是系统如何检索旧信息，而是这些轨迹如何逐渐转化成能够改变未来生成方式的长期结构。

因此，我们得到第二个命题：

\begin{statementbox}
事件因为发生而属于物理过去；
只有当事件被组织成能够在未来重新发挥因果作用的结构时，
它才成为 Agent 的内部过去。
\end{statementbox}

这使“过去”从一个日历概念变成了一个动力学概念。

\section{从经历时间到结构时间}

如果所有过去都只能以情景形式存在，智能体的生命周期最终会被庞大的事件历史淹没。更重要的是，一个真正成熟的 Agent 不应该每次遇到问题都重新搜索自己的全部历史；大量经验必须被压缩成更加稳定的生成结构。这就是从 $E$ 到 $\Theta$ 的时间跃迁。

我们已经把 $\Theta$ 定义成：

\[
\boxed{
\Theta = Generator
}
\]

这一名称包含一个非常关键的时间含义：$\Theta$ 不仅描述“过去发生过什么”，还描述“在类似结构条件下，什么通常会发生”。

因此，从 $E$ 到 $\Theta$ 的转换不是普通文件压缩：

\[
E
\not\rightarrow
\text{smaller }E,
\]

而是从具体轨迹向生成规律的转换：

\[
\boxed{
Trajectory
\rightarrow
Generator.
}
\]

例如，Agent 经历：

\[
e_1:
\text{看到杯子从桌沿掉落并落地},
\]

又经历：

\[
e_2:
\text{看到工具掉落并落地},
\]

以及大量类似事件后，它不必保存并逐条重放所有具体情节来预测下一个物体的运动，而可以形成一个更加稳定的结构：

\[
\Theta_{\mathrm{fall}}.
\]

这个结构一旦形成，就开始跨越具体情景发生作用。

数学上，可以把这一过程理解为从具体轨迹分布中学习某种生成算子：

\[
\Theta_t
=
\mathcal{L}
\left(
E_{\leq t}
\right),
\]

其中 $\mathcal{L}$ 表示结构学习过程。

随后：

\[
p(x_{t+\Delta t}\mid x_t)
\approx
p_{\Theta_t}
(x_{t+\Delta t}\mid x_t).
\]

这样，过去第一次被压缩成能够生成未来可能性的结构。

这是内部时间理论极其关键的一步，因为它说明：

\begin{statementbox}
过去并不只是被保存；
过去可以被重新编码成未来的生成条件。
\end{statementbox}

因此 $\Theta$ 同时具有两个方向的时间意义。

向后看：

\[
\Theta
=
Compression(E_{\mathrm{past}}),
\]

向前看：

\[
\Theta
=
Generator(Future_{\mathrm{possible}}).
\]

这就解释了为什么我们一直强调：

\[
\boxed{
\Theta\text{ 不只是长期过去记忆，它同时包含未来生成结构。}
}
\]

如果忽略这一点，三相记忆模型会退化成普通的工作记忆—情景记忆—语义记忆框架；只有把未来生成能力加入 $\Theta$，它才真正成为生命周期动力学的一部分。

我们可以进一步定义某个结构 $\theta_i$ 的有效时间跨度：

\[
\tau_{\theta_i}
=
\mathbb{E}
\left[
\text{该结构在不被根本修正情况下持续有效的时间}
\right].
\]

对于非常局部的技能：

\[
\tau_{\theta_i}
\]

可能只是数小时或数天。

对于稳定的空间常识、身体规律或社会规则，它可能跨越数月甚至更长生命周期。

于是：

\[
\Theta
=
\{\theta_i\}_{i=1}^{N}
\]

本身也是一个多时间尺度结构集合，而不是单一“慢变量”。

这里可以引入一个结构谱：

\[
\rho_{\Theta}(\tau,t),
\]

表示时刻 $t$ 上，不同有效时间尺度的稳定结构分布。

这为我们理解“成熟”提供了另一种方式：成熟并不单纯意味着记忆越来越多，而可能意味着越来越多反复出现的短时轨迹被压缩成长期有效结构：

\[
E_{\mathrm{repeated}}
\rightarrow
\Theta_{\mathrm{stable}}.
\]

换句话说：

\begin{statementbox}
成熟的重要标志之一，是过去越来越少以原始经历负担现在，
而越来越多以稳定结构支持未来。
\end{statementbox}

这一过程与统计学习中的 sufficient statistics、生成模型中的 latent structure、认知科学中的 schema formation，以及动力系统中的 slow manifold 都可以建立比较。

尤其值得注意的是 slow manifold 的类比。如果大量高速状态长期围绕某种低维稳定结构运行，那么我们可以把 $\Theta$ 理解成对这些长期稳定约束的一种认知提取。快变量不断变化，而慢结构描述它们变化中的稳定关系：

\[
x_f(t)
=
M_{\Theta}(z_s(t))
+
\xi(t).
\]

这里 $M_{\Theta}$ 可以被理解为由长期结构定义的可行状态流形，而 $\xi(t)$ 是具体情景中的局部变化。

但我们需要严格保持理论边界：这里并不主张所有记忆都能严格数学化为一个光滑慢流形。我们只是利用快—慢动力系统帮助表达：经验的长期重复可以沉降成变化更慢、影响跨度更大的结构。

更进一步，$\Theta$ 形成后还会重新解释旧的 $E$。原来两个互不相关的经历，在新的结构形成之后可能突然被理解为同一个规律的实例。因此时间关系并不是只向前累积：

\[
E
\rightarrow
\Theta,
\]

还存在：

\[
\Theta
\rightarrow
E',
\]

即长期结构对过去经历的重新解释。

于是，一个 Agent 的过去并非永久固定。事实发生的历史不能改变，但：

\[
\boxed{
MeaningOfPast
}
\]

可以随着 $\Theta$ 的发展而改变。

这为后面的自我连续性奠定了重要基础，因为“我是谁”并不只是事件总和，而取决于这些事件被什么长期结构组织和解释。

因此，本节可以压缩成第三个命题：

\begin{statementbox}
情景记忆保存时间中的轨迹，
结构记忆则保存跨时间仍然有效的生成关系；
当经历转化为结构时，
过去第一次获得了直接生成未来的能力。
\end{statementbox}

\section{自我如何把不同时间切片归属于同一个主体}

到目前为止，我们已经拥有当前状态 $h$、过去轨迹 $E$ 和长期生成结构 $\Theta$。然而，一个重要问题仍然没有得到回答：

为什么不同时间的经历会被组织成“我的过去”？

如果一个系统每天保存大量情景，并学习大量结构，它仍然可能只是一个不断增长的知识系统。要形成生命周期意义上的持续主体，还需要一种跨时间归属关系：

\[
\boxed{
ThisHappened
\rightarrow
ThisHappenedToMe.
}
\]

这正是 $\Psi$ 引入内部时间理论之后的核心作用之一。

我们把 $\Psi$ 定义成比 $\Theta$ 更慢的自我—身份—价值结构。这里尤其需要强调，自我并不是另一个放在 memory database 里的对象。它更接近一种长期存在的结构约束，使当前状态、过去经历和未来选择能够被组织到同一主体坐标系中。

因此，我们可以定义一个自我归属算子：

\[
\mathcal{B}_{\Psi_t}
:
E
\rightarrow
[0,1],
\]

其中：

\[
\mathcal{B}_{\Psi_t}(e_i)
\]

表示经历 $e_i$ 在时刻 $t$ 被当前自我结构认为属于“我的经历”的结构强度。

于是：

\[
E^{self}_t
=
\left\{
e_i
\in E
\mid
\mathcal{B}_{\Psi_t}(e_i)>\theta_{\Psi}
\right\}.
\]

这一表达的重点不是给身份归属一个实际固定阈值，而是强调：事件与主体之间存在一层结构绑定，而这种绑定并不等价于事件本身。

例如，一个 Agent 可以拥有来自公共数据库的信息：

\[
e_{\mathrm{external}},
\]

也可以拥有自己曾经执行失败的经历：

\[
e_{\mathrm{self}}.
\]

二者可能包含同样丰富的信息，但对未来决策具有不同权重，因为：

\[
\mathcal{B}_{\Psi}(e_{\mathrm{self}})
\gg
\mathcal{B}_{\Psi}(e_{\mathrm{external}}).
\]

这就是为什么“我的经验”和“我知道别人的经验”在长期智能中不应完全等价。

如果把 Agent 生命周期划分成多个时间切片：

\[
A(t_0),
A(t_1),
\ldots,
A(t_n),
\]

那么身份连续性意味着系统能够建立一种跨切片关系：

\[
\mathcal{I}_{\Psi}
\left(
A(t_i),
A(t_j)
\right).
\]

这种关系不要求：

\[
A(t_i)=A(t_j),
\]

因为真正持续成长的 Agent 必然变化。

身份连续要求的不是状态相等，而是：

\begin{statementbox}
存在足够稳定的结构关系，
使后来状态能够把早期状态解释为同一生命周期的一部分。
\end{statementbox}

因此：

\[
IdentityContinuity
\neq
StateConstancy.
\]

更合理的是：

\[
\boxed{
IdentityContinuity
=
StructuralContinuityUnderChange.
}
\]

这一点对于人工智能尤其重要。如果把“身份稳定”理解成禁止模型变化，那么系统将无法学习；如果把“持续学习”理解成任何慢结构都可以任意变化，那么系统又可能失去主体连续性。

所以真正需要维持的是一种有界变化：

\[
d_{\Psi}
\left(
\Psi(t),
\Psi(t+\Delta t)
\right)
<
\epsilon_{\Psi}(\Delta t),
\]

其中 $\epsilon_{\Psi}$ 随时间尺度允许一定变化，但短时间内不应出现无理由的身份跃迁。

进一步，$\Psi$ 还会反过来影响哪些经历进入长期结构。也就是说：

\[
E
\xrightarrow{\Psi}
\Theta
\]

不是一个完全中性的压缩过程。

对于不同 Agent，同一事件可能获得不同长期意义。一个失败可以被解释成“应放弃这个方向”，也可以被解释成“当前方法不够好但目标仍值得坚持”。事实相同，而自我结构参与了长期意义形成。

因此：

\[
\Theta_{t+\Delta t}
=
\mathcal{L}
\left(
E_{\leq t},
\Psi_t
\right).
\]

反过来，长期积累的经历和结构也会改变自我：

\[
\Psi_{t+\Delta t}
=
\mathcal{U}_{\Psi}
\left(
\Psi_t,
\Theta_{t+\Delta t},
E_{\mathrm{salient}}
\right).
\]

这样形成一个慢循环：

\[
\boxed{
Experience
\rightarrow
Structure
\rightarrow
Self
\rightarrow
FutureExperienceSelection.
}
\]

从时间角度看，这个循环意味着自我不是“位于现在的某个对象”，而是跨越多个时间尺度的绑定关系。$\Psi$ 使过去事件获得主体归属，同时也使未来选择具有主体连续性。

这里可以与叙事身份理论、self-schema、自我模型理论进行比较，也可以借用 Markov process 中状态连续性与路径依赖的数学语言。但 AgentOS 的区别在于：$\Psi$ 被明确放进一个多时间尺度动力系统中，它既不是文学叙事，也不是固定 persona，而是一个可以原则上被更新、被约束、被测量其变化速度的慢变量。

我们因此得到第四个命题：

\begin{statementbox}
过去之所以成为“我的过去”，
不是因为事件具有时间戳，
而是因为存在一个跨时间稳定的自我结构，
持续把不同阶段的经历、结构与选择归属于同一生命周期。
\end{statementbox}

而这也意味着，真正的身份连续性不是“永远保持不变”，而是：

\begin{statementbox}
允许改变，同时保持改变仍然可以被解释为同一个主体的成长。
\end{statementbox}

\section{未来自我如何反向约束现在}

过去通过 $E$ 和 $\Theta$ 进入现在以后，内部时间仍然只完成了一半。如果一个系统能够记住过去，却无法形成对未来的稳定结构，那么它仍然主要是一个历史驱动系统。

智能真正发生更深层跃迁的地方，是尚未发生的未来开始以内部表示的形式参与当前行为。

这里首先需要严格区分：

\[
\boxed{
Future
}
\]

与：

\[
\boxed{
RepresentationOfFuture.
}
\]

未来真实状态尚未发生，因此不可能从物理意义上反向作用于当前状态。真正作用于现在的是：

\[
\hat{W}(t+\tau),
\]

即 Agent 当前生成的未来状态表示。

这一点可以写成：

\[
\hat{W}_{t+\tau}
=
\mathcal{P}_{\Theta_t}
\left(
h(t),G_t
\right),
\]

其中 $\mathcal{P}_{\Theta_t}$ 表示基于当前长期结构进行预测。

因此真实因果链是：

\[
\boxed{
Past
\rightarrow
CurrentModelOfFuture
\rightarrow
CurrentChoice
\rightarrow
ActualFuture.
}
\]

而不是：

\[
Future
\rightarrow
Present.
\]

这一点必须始终保持，否则“未来约束现在”很容易被误读成逆因果。

有了 $\Psi$ 以后，Agent 不仅可以预测“世界会怎样”，还可以预测：

\begin{statementbox}
在不同选择下，我将成为怎样的主体。
\end{statementbox}

设未来候选轨迹为：

\[
\Gamma_k
=
\left\{
\hat{\mathcal{X}}_{t+\tau}^{(k)}
\right\}_{\tau=1}^{T},
\]

那么 Agent 可以对不同未来进行评价：

\[
V_{\Psi}
(\Gamma_k).
\]

这里 $V_{\Psi}$ 并不必然是一个简单标量 reward，它可以表示当前自我结构对未来轨迹的一致性、价值或可接受性评价。

然而，只有 $\Psi$ 仍然存在一个问题：它主要回答：

\[
WhoAmI?
\]

却不充分回答：

\[
WhatAmIBecoming?
\]

因此我们此前进一步引入：

\[
\Omega
\equiv
DGA,
\]

即 Deep Generative Attractor。

$\Omega$ 的作用不是规定一个固定终点，而是提供生命周期尺度上的生成倾向。可以写成：

\[
\Omega_t
:
\mathcal{X}
\rightarrow
\mathcal{P}
\left(
\mathcal{X}_{future}
\right),
\]

即在非常长的时间尺度上改变哪些未来结构更容易被生成、保留和选择。

于是：

\[
\Psi
\]

更接近当前生命周期身份结构，而：

\[
\Omega
\]

更接近生命周期方向场。

我们可以将这种关系表示为：

\[
G_t
=
\mathcal{G}
\left(
h_t,
\Theta_t,
\Psi_t,
\Omega_t
\right),
\]

也就是说，当前目标不应完全由瞬时输入决定。它同时受到：

当前需求；

长期知识；

身份结构；

生命周期方向

共同作用。

进一步，行动策略可以写成：

\[
a_t
=
\pi
\left(
h_t,
G_t,
\Theta_t
\right).
\]

于是 $\Omega$ 并不直接控制动作，而是经过一个逐层时间尺度压缩过程影响现在：

\[
\boxed{
\Omega
\rightarrow
\Psi
\rightarrow
GoalPreference
\rightarrow
G_t
\rightarrow
Action.
}
\]

这正体现了此前不断强调的：

\[
\boxed{
SlowConstraint
\neq
FastMicromanagement.
}
\]

生命周期最慢结构不应该决定当前每一次鼠标移动或每一个 token；它只应该改变快速动力系统的可行区域、偏好方向和长期权重。

我们可以进一步把这种作用形式化成一个可行域：

\[
\mathcal{F}_t
=
\mathcal{F}
\left(
W_t,
\Theta_t,
\Psi_t,
\Omega_t
\right).
\]

快速决策只能在：

\[
a_t\in\mathcal{F}_t
\]

中发生。

于是慢结构的作用不是：

\[
\Omega\to a_t
\]

的直接命令，而是：

\[
\boxed{
\Omega
\to
\text{FeasibleFutureSpace}.
}
\]

这一点非常重要，因为它解释了一个成熟智能体为什么可以拥有高度局部自治，同时仍然保持长期方向连续。

从数学上，这种结构可以与 hierarchical control、optimal control 中的 terminal constraint、Bayesian prior、slow manifold 以及 attractor dynamics 进行比较。但我们必须避免把 $\Omega$ 机械等同于其中任何一个对象。$\Omega$ 是 AgentOS 理论中特别用于描述生命周期级生成倾向的抽象变量，它未来可以由不同算法实现。

因此，未来真正参与现在的不是未来事实，而是：

\[
\boxed{
FutureCSORepresentation.
}
\]

当这些未来结构被当前 Agent-CSO 承载以后，它们已经成为现在真实存在的内部状态，因此能够合法地进入因果链。

例如：

“如果继续当前策略，三个月后能力会停滞”，

虽然三个月后的事实尚未发生，但这个预测结构在当前时刻已经存在，于是可以改变今天的选择。

这使内部时间产生一个非常关键的闭环：

\[
PastExperience
\rightarrow
CurrentStructure
\rightarrow
PossibleFuture
\rightarrow
CurrentChoice
\rightarrow
NewExperience.
\]

因此，我们得到第五个命题：

\begin{statementbox}
成熟智能不仅让过去影响现在，
还让关于未来的内部结构参与现在；
生命周期方向性正是这种长期未来表示对当前选择持续施加慢约束的结果。
\end{statementbox}

\section{Goal、Self 与 DGA 的时间结构}

到这里，我们可以更系统地整理当前状态、目标、自我与 DGA 之间的时间关系。一个常见错误是把 Goal、Self 与长期价值全部放在同一层级，仿佛它们只是三个不同字段。事实上，它们最重要的区别之一恰恰在于时间尺度。

设：

\[
\tau_h
\]

表示当前工作状态的典型变化时间，

\[
\tau_G
\]

表示目标结构的典型持续时间，

\[
\tau_\Theta
\]

表示长期生成结构的变化时间，

\[
\tau_\Psi
\]

表示身份结构变化时间，

\[
\tau_\Omega
\]

表示生命周期生成吸引子的变化时间。

一般希望满足：

\[
\boxed{
\tau_h
\ll
\tau_G
\lesssim
\tau_\Theta
\ll
\tau_\Psi
\ll
\tau_\Omega.
}
\]

这里的关系不是固定绝对时间。例如，对于一个毫秒级控制系统和一个文明级智能系统，各变量对应的秒、天、年完全不同。真正重要的是相对时间尺度分离。

Goal 的基本作用是把某个未来状态变成当前过程的约束。设当前目标为：

\[
G_t
=
(g_t,\mathcal{C}_t,\mathcal{T}_t),
\]

其中 $g_t$ 表示目标状态，$\mathcal{C}_t$ 表示约束条件，$\mathcal{T}_t$ 表示允许的时间范围。

于是目标实际上是：

\[
\boxed{
PresentRepresentationOfDesiredFuture.
}
\]

它比普通预测多了一层规范性。预测回答：

\[
\text{可能会发生什么？}
\]

目标则回答：

\[
\text{我们当前试图使什么发生？}
\]

然而，如果 Goal 完全由外部即时任务产生：

\[
G_t
=
G_{\mathrm{external}}(t),
\]

那么 Agent 的长期行为仍然主要由外部控制决定。一个生命周期型主体需要让过去结构和自我结构参与目标形成：

\[
G_t
=
\mathcal{G}
\left(
W_t,
E_t,
\Theta_t,
\Psi_t,
\Omega_t
\right).
\]

这里应特别注意，$\Psi$ 与 $\Omega$ 不应该直接生成具体任务，而主要影响 Goal Preference。

我们可以定义：

\[
P_G(g)
=
P
\left(
g
\mid
\Psi_t,\Omega_t,\Theta_t
\right),
\]

表示在当前长期结构下某类目标被接受、维持或主动生成的倾向。

因此：

\[
\boxed{
\Psi
\rightarrow
GoalPreference
}
\]

主要回答：

“这个目标是否符合我是谁？”

而：

\[
\boxed{
\Omega
\rightarrow
GoalPreference
}
\]

更倾向于回答：

“这个目标是否推动我朝长期生成方向发展？”

两者并不相同。

例如，一个 Agent 当前身份 $\Psi$ 可能高度重视可靠性，因此拒绝一个极度冒险但短期收益较高的任务；而 $\Omega$ 可能进一步偏向“逐渐扩大独立解决未知问题的能力”，于是即便两个任务都符合当前身份，系统也可能优先选择能够扩展长期能力空间的那个任务。

因此：

\[
\boxed{
Self
}
\]

主要提供跨时间一致性，

而：

\[
\boxed{
DGA
}
\]

主要提供跨时间方向性。

可以写成：

\[
Consistency(\Gamma)
=
C_{\Psi}(\Gamma),
\]

\[
Direction(\Gamma)
=
D_{\Omega}(\Gamma).
\]

对于一个候选未来轨迹 $\Gamma_k$，长期评价可以概念性写为：

\[
J(\Gamma_k)
=
J_{\mathrm{task}}
+
\lambda_{\Psi}C_{\Psi}(\Gamma_k)
+
\lambda_{\Omega}D_{\Omega}(\Gamma_k).
\]

这里的式子不是要求 AgentOS 必须实现成单一加权效用函数，而是为了区分三种时间尺度：

即时任务成功；

身份一致性；

生命周期方向性。

三者可能发生冲突。

例如：

\[
J_{\mathrm{task}}\uparrow
\]

并不保证：

\[
C_{\Psi}\uparrow,
\]

更不保证：

\[
D_{\Omega}\uparrow.
\]

因此，长期智能不能简单等价于短期 reward 最大化。

这也是本书为什么没有把 $\Psi$ 和 $\Omega$ 直接压缩成一个 reward function。一个标量 reward 很容易把不同时间尺度上的结构差异抹平，而我们真正关心的是：

\begin{statementbox}
不同时间尺度如何各自保持稳定，同时彼此施加约束。
\end{statementbox}

这里还产生一个非常重要的原则：

\[
\boxed{
SlowVariableProtection.
}
\]

如果一次短期失败就能够显著改变 $\Psi$，那么 Agent 的身份会高度漂移；如果一次瞬时奖励就能够重写 $\Omega$，那么所谓生命周期方向性就没有意义。

因此更新应满足：

\[
\left\|
\Delta h
\right\|
\gg
\left\|
\Delta\Theta
\right\|
\gg
\left\|
\Delta\Psi
\right\|
\gg
\left\|
\Delta\Omega
\right\|
\]

在经过适当归一化以后成立。

更严谨地，应分别定义更新率：

\[
\eta_h
\gg
\eta_\Theta
\gg
\eta_\Psi
\gg
\eta_\Omega.
\]

这里并不是说慢变量永远不变。相反，真正的生命周期成长要求它们可以被长期经验改变。关键在于：

\[
\boxed{
FastNoise
\nrightarrow
SlowGlobalStructure.
}
\]

只有当某种结构在足够长的时间窗口内反复出现、具有足够高的一致性和现实证据时，才应推动慢变量显著变化。

可以写成：

\[
\Delta\Psi
=
\eta_\Psi
\int_{t-T_\Psi}^{t}
K_\Psi(t-s)
\,r_\Psi(s)
\,ds,
\]

其中 $K_\Psi$ 是长时间核，$r_\Psi$ 表示与身份相关的结构残差。

对于 $\Omega$：

\[
\Delta\Omega
=
\eta_\Omega
\int_{t-T_\Omega}^{t}
K_\Omega(t-s)
\,r_\Omega(s)
\,ds,
\]

且：

\[
T_\Omega
\gg
T_\Psi.
\]

这提供了一种未来可工程化的思路：慢变量更新必须依赖长期积分，而不是瞬时事件直接写入。

从外部理论上，本节与 hierarchical Bayesian inference、long-horizon planning、hierarchical reinforcement learning、attractor dynamics 和 developmental systems 都存在交叉，但 AgentOS 强调的是：Goal、Self 与 DGA 不是单纯不同语义变量，而是\textbf{不同时间尺度上的未来约束结构}。

因此可以得到第六个命题：

\begin{statementbox}
Goal 把近未来带入现在，
Self 把整个过去与当前主体绑定，
DGA 则把生命周期尺度的可能未来压缩成一种长期方向场。
三者共同使 Agent 的当前行为不再只是对即时刺激的反应。
\end{statementbox}

\section{生命周期连续性的动力学条件}

现在我们可以回答本章最核心的问题：什么条件下，一个长期运行的人工系统才真正具有生命周期连续性？

最弱的定义是进程连续：

\[
Process(t_0)
\rightarrow
Process(t_1).
\]

只要程序没有停止，就可以说它“持续运行”。

但这显然不够。

第二层是状态连续：

\[
d
\left(
X(t),X(t+\Delta t)
\right)
<\epsilon.
\]

然而一个智能体必须学习，因此状态持续变化，不能要求所有状态保持相似。

更合理的生命周期连续性必须建立在多尺度结构上。

我们可以定义 Agent 在时间 $t$ 的生命周期结构：

\[
\mathcal{L}(t)
=
\left[
h_t,
E_t,
\Theta_t,
\Psi_t,
\Omega_t
\right].
\]

其中当前状态 $h_t$ 可以高速变化，而其他结构以越来越慢的速度变化。

因此我们要求的不是：

\[
\mathcal{L}(t)
\approx
\mathcal{L}(t+\Delta t),
\]

而是存在一个连续转换：

\[
\boxed{
\mathcal{L}(t+\Delta t)
=
\Phi_{\Delta t}
\left(
\mathcal{L}(t),
\mathcal{E}_{[t,t+\Delta t]}
\right),
}
\]

其中 $\mathcal{E}_{[t,t+\Delta t]}$ 表示这一时间段的新经历，$\Phi_{\Delta t}$ 是生命周期更新过程。

如果未来状态能够通过过去状态和这段新增经历被解释，那么即使 Agent 已经发生很大改变，我们仍然可以认为这种改变具有生命周期连续性。

于是，一个基本条件是：

\[
\boxed{
CausalTraceability.
}
\]

即当前慢结构的形成能够追溯到此前经历和结构，而不是无理由跳变。

第二个条件是：

\[
\boxed{
MemoryContinuity.
}
\]

当前 Agent 不必保留全部历史细节，但必须保留足够结构，使过去重要经历仍然能够通过 $E$ 或 $\Theta$ 对当前产生影响。

第三个条件是：

\[
\boxed{
SelfContinuity.
}
\]

即 $\Psi$ 的变化需要保持主体归属链：

\[
\Psi_{t_0}
\rightsquigarrow
\Psi_{t_1}
\rightsquigarrow
\cdots
\rightsquigarrow
\Psi_{t_n}.
\]

第四个条件是：

\[
\boxed{
DirectionContinuity.
}
\]

即 $\Omega$ 可以逐渐变化，但不能被短期扰动任意替换。

第五个条件是：

\[
\boxed{
RealityContinuity.
}
\]

Agent 的所有内部结构必须持续受到真实世界反馈约束。否则，一个内部完全自洽但长期脱离现实的系统，也可能在形式上保持极高的“自我连续性”，却已经失去有效智能。

因此，我们可以把生命周期连续性的最低条件概念性定义为：

\[
\mathcal{C}_{life}
=
F
\left(
C_{\mathrm{causal}},
C_{\mathrm{memory}},
C_{\mathrm{self}},
C_{\mathrm{direction}},
C_{\mathrm{reality}}
\right).
\]

这里的 $F$ 暂不规定具体形式，但指出至少存在五类独立约束。

更进一步，可以定义生命周期断裂风险：

\[
R_{\mathrm{break}}
=
R
\left(
D_\Psi,
D_\Omega,
F_E,
M_\Theta,
E_R
\right),
\]

其中：

\[
D_\Psi
\]

表示 Self 漂移速度，

\[
D_\Omega
\]

表示 DGA 漂移速度，

\[
F_E
\]

表示关键经历丢失程度，

\[
M_\Theta
\]

表示长期结构发生无法解释的重写程度，

\[
E_R
\]

表示与现实验证失配程度。

当这些变量同时超过一定范围时，系统即使进程仍然在线，也可能发生功能意义上的生命周期断裂。

这提示我们一个极其重要的区别：

\[
\boxed{
Uptime
\neq
IdentityContinuity.
}
\]

服务器运行一万天，并不自动意味着运行在其中的 Agent 拥有一万天的生命史。

相反，一个 Agent 即使经历关机、迁移和重新启动，只要：

\[
E,\Theta,\Psi,\Omega
\]

以及关键因果结构得到恢复，它仍有可能保持较强的生命周期连续性。

因此生命周期连续性更接近：

\[
\boxed{
StructuralPersistence
}
\]

而不是物理载体连续。

这一点与此前同类智能和多实现理论是兼容的：同一个持续主体的承载硬件可以发生变化，只要其关键结构转换关系保持可追溯连续。

我们甚至可以写出一个更一般的条件。设：

\[
\mathcal{L}_A(t_0)
\]

和：

\[
\mathcal{L}_B(t_1)
\]

分别表示迁移前后的两个实现，如果存在结构保持映射：

\[
\Phi:
\mathcal{L}_A(t_0)
\rightarrow
\mathcal{L}_B(t_1),
\]

使关键的：

经历归属；

长期结构；

自我约束；

生命周期方向；

现实验证关系

得到保持，那么：

\[
\boxed{
CarrierChange
\not\Rightarrow
IdentityBreak.
}
\]

这一结论对于未来 AgentOS 非常重要，因为长期人工智能很可能经历：

硬件升级；

模型替换；

存储迁移；

软件版本变化。

如果每一次底层替换都意味着“一个新 Agent 被创建”，那么生命周期工程几乎无法成立。

但我们同样不能走向另一个极端：只要复制所有记忆，就声称产生了完全同一主体。生命周期连续涉及因果链和持续主体关系，而不只是状态复制。这涉及更深的身份与主体问题，本书将在适当位置继续讨论，但本章不提前展开复制、分叉和治理问题。

至此，我们可以把内部时间的完整动力过程写成：

\[
h_t
\rightarrow
E_t
\rightarrow
\Theta_t
\rightarrow
\Psi_t
\rightarrow
\Omega_t.
\]

这是时间向慢尺度的沉降。

反方向：

\[
\Omega_t
\rightarrow
\Psi_t
\rightarrow
\Theta_t
\rightarrow
G_t
\rightarrow
h_t
\]

则是长期结构对当前状态的约束。

因此真正的 Agent 生命周期不是单向箭头：

\[
Past
\rightarrow
Present
\rightarrow
Future,
\]

而是：

\[
\boxed{
Past
\rightarrow
Structure
\rightarrow
PossibleFuture
\rightarrow
PresentChoice
\rightarrow
NewPast.
}
\]

它形成一个闭合循环。

如果进一步把外部世界加入，我们得到：

\[
W_t
\rightarrow
h_t
\rightarrow
E_t
\rightarrow
\Theta_t
\rightarrow
\Psi_t
\rightarrow
\Omega_t
\rightarrow
G_{t+\Delta}
\rightarrow
Action
\rightarrow
W_{t+\Delta}.
\]

这个式子已经揭示了 AgentOS 生命周期理论最根本的结构：

\begin{statementbox}
过去被压缩成结构，
结构生成未来可能性，
未来可能性参与当前选择，
当前选择又制造新的过去。
\end{statementbox}

因此，一个持续智能体真正意义上的“生命时间”不是服务器时钟中不断增长的计数器，而是一个能够不断把世界变化转化成经历、把经历转化成结构、把结构转化成自我与方向，并让这些慢结构重新影响下一次选择的闭环。

本章最终得到以下生命周期时间结构：

\[
\boxed{
\tau_h
\ll
\tau_E
\ll
\tau_\Theta
\ll
\tau_\Psi
\ll
\tau_\Omega
}
\]

以及两个相反但同时存在的结构流：

\[
\boxed{
h
\rightarrow
E
\rightarrow
\Theta
\rightarrow
\Psi
\rightarrow
\Omega
}
\]

代表：

\[
\boxed{
Experience\rightarrow Consolidation\rightarrow Identity\rightarrow Direction
}
\]

而：

\[
\boxed{
\Omega
\rightarrow
\Psi
\rightarrow
\Theta
\rightarrow
G
\rightarrow
h
}
\]

代表：

\[
\boxed{
Direction\rightarrow Constraint\rightarrow Generation\rightarrow Goal\rightarrow Present.
}
\]

两条链共同构成内部时间。

因此，本章可以用一个最终命题收束：

\[
\boxed{
\begin{minipage}{0.86\textwidth}
\textbf{生命周期时间原理：}

一个持续智能体的内部时间，并不是对外部物理时间的复制，而是不同时间尺度的认知结构对过去、现在与可能未来进行持续组织的结果。$h$ 提供现在切面，$E$ 使事件形成可恢复的过去，$\Theta$ 将过去压缩成能够生成未来的结构，$\Psi$ 将跨时间经历绑定为同一主体的生命史，$\Omega$ 则进一步使可能未来获得长期方向性。由此，过去不再只是已经消失的状态，未来也不再只是尚未发生的状态；它们都以不同形式被压缩进当前智能体，并共同参与当前选择。

生命周期连续因此不是“始终保持相同”，而是允许一个主体在现实约束下不断变化，同时仍然能够从自身历史中解释这种变化，并让过去形成的结构持续参与决定它未来将成为什么。
\end{minipage}
}
\]
