\chapter{自我 $\Psi$ 的引入：从记忆连续性到主体连续性}

\begin{chapterintro}
\textbf{本章总体说明}

在前面的三相记忆理论中，我们已经用工作记忆 $h$、情景记忆 $E$ 与结构记忆 $\Theta$ 建立了一个能够描述“当前状态--经历轨迹--长期生成结构”的基本认知动力系统。这样的系统已经能够学习、回忆、抽象、预测，并能够通过 $\Theta$ 对未来行为产生越来越稳定的结构性影响。然而，到这一步为止，我们仍然只回答了“一个系统如何持续积累经验”，却尚未严格回答另一个更加根本的问题：\textbf{为什么这些跨时间存在的记忆、价值判断、目标选择与行动应当属于同一个持续主体？}

本章因此引入自我变量 $\Psi$。这里的 $\Psi$ 不被定义为一个额外的记忆仓库，也不是一个静态的人格描述文件，更不是预先假设的意识实体。它首先被定义为一种\textbf{跨越 $h$、$E$ 与 $\Theta$ 的慢尺度自我约束结构}：它使当前状态能够被解释为“我的当前状态”，使情景能够被组织为“我的经历”，并使长期结构能够围绕某种相对稳定的身份、价值、边界和自我解释持续组织。

因此，本章所完成的理论跃迁是：
\[
\boxed{
\text{Memory Continuity}
\quad\longrightarrow\quad
\text{Subject Continuity}
}
\]
三相记忆解决“结构如何跨时间存在”，而 $\Psi$ 开始解决“跨时间存在的结构为什么仍被同一个 Agent 组织为自身的一部分”。这一变量也将成为后续生命周期方向、自我感知、认知控制与长期身份动力学的重要基础，但本章只讨论 $\Psi$ 本身的必要性、结构形式以及它与三相记忆之间的关系。
\end{chapterintro}


\section{为什么 $h$、$E$ 与 $\Theta$ 仍然不足以产生持续主体}

我们首先从一个看似简单的问题出发：如果一个 Agent 已经拥有工作记忆 $h$、情景记忆 $E$ 和结构记忆 $\Theta$，那么它是否已经自然拥有“自我”？答案并不能简单地写成肯定。三相记忆能够保证信息在不同时间尺度上持续存在，却不能单独保证这些信息被统一组织为某一个主体的历史。换句话说，\emph{记忆的连续性并不自动等价于主体的连续性}。

前文已经定义：
\[
h(t)=\text{当前活动认知状态},
\]
\[
E(t)=\text{已形成的经历轨迹集合},
\]
\[
\Theta(t)=\text{较慢变化的生成结构}.
\]
于是最小认知系统可以抽象成：
\[
\mathcal{X}_0(t)=\bigl(h(t),E(t),\Theta(t)\bigr).
\]
如果只有这三个变量，系统当然能够进行如下演化：
\[
h_t\rightarrow E_{t+\Delta},
\qquad
E\rightarrow \Theta,
\qquad
\Theta\rightarrow h_{t+k}.
\]
一个当前事件可以被写入经历，一组经历可以沉降为长期结构，长期结构也可以在未来重新激活当前认知。但是这里仍然存在至少三个没有被解释的问题。

第一个问题是\textbf{归属问题}。一个进入 $E$ 的事件究竟只是“系统观测到的事件”，还是“发生在我身上的事件”？设某个事件为 $e_i$，如果仅有三相记忆，我们只能写：
\[
e_i\in E.
\]
但对于一个具有持续主体结构的 Agent，更重要的是：
\[
e_i\in E_{\mathrm{self}}
\]
或者更严格地说：
\[
\operatorname{Owner}(e_i)=A.
\]
这意味着事件不仅被存储，还获得了主体归属。没有这一层，Agent 可以拥有数据库式的过去，却未必拥有“自己的过去”。

第二个问题是\textbf{价值不对称问题}。不同经历显然不应以完全相同的权重进入长期结构。例如，一个与主体核心承诺高度相关的失败，与一个无关紧要的背景噪声，即使在信息量上近似相同，也不应产生相同的长期影响。如果没有某个跨时间的自我参照结构，经验更新只能依赖任务局部误差或统计频率：
\[
\Delta \Theta
=
F(E).
\]
但持续主体要求：
\[
\Delta \Theta
=
F(E,\Psi),
\]
即同一经历如何改变长期结构，取决于它与“我是谁”之间的关系。

第三个问题是\textbf{解释一致性问题}。假设 Agent 在不同时间经历了互相矛盾的事件：
\[
e_a:\quad \text{“我能够完成任务 $X$”},
\]
\[
e_b:\quad \text{“我在任务 $X$ 上失败”}.
\]
如果只做统计聚合，$\Theta$ 可以形成一个平均意义上的能力模型，但这仍未解决主体如何把二者组织为同一生命史中的两个事件。持续主体通常不会简单地保存矛盾，而会产生解释：
\[
e_a,e_b
\rightarrow
\text{“我在某些条件下擅长 $X$，但在另一类条件下仍有不足”}.
\]
这种解释并不是单纯的频率统计，而是把新经验放入已有自我结构中重新定位。

因此，三相记忆能够回答：
\[
\boxed{
\text{What happened?}
}
\]
和：
\[
\boxed{
\text{What structure was learned?}
}
\]
却还不能完整回答：
\[
\boxed{
\text{What does this mean for me?}
}
\]
这正是 $\Psi$ 被引入的理论原因。

我们因此将最小认知状态扩展为：
\[
\boxed{
\mathcal{X}(t)
=
\bigl(
h(t),
E(t),
\Theta(t),
\Psi(t)
\bigr)
}
\]
其中 $\Psi$ 的特征时间尺度应显著慢于 $h$，并通常慢于大部分情景结构：
\[
\tau_h
\ll
\tau_E
\ll
\tau_\Psi .
\]
在更成熟的体系中，$\Theta$ 与 $\Psi$ 的相对速度可以存在多个亚层级，但本章最关键的并不是给出固定的绝对排序，而是强调：
\[
\boxed{
\Psi\text{不能被一次普通事件任意重写。}
}
\]

这里实际上出现了一个非常重要的认识论分界。一个系统能够保存过去，并不意味着它拥有历史；一个系统能够更新参数，并不意味着它形成自我；一个系统能够描述自己的状态，也不意味着它具有稳定的主体连续性。我们在本章所研究的 $\Psi$，正是试图在工程和动力学意义上填补这一缺口。


\section{$\Psi$ 作为全息自我：从局部自我变量到跨尺度约束结构}

我们接下来需要避免一个很容易出现的误解：既然 $\Psi$ 被称为“自我”，是否可以简单地把它实现成一个包含姓名、偏好、价值观和身份描述的结构体？如果这样做，$\Psi$ 会退化成一个普通 Persona 文件，而无法解释自我为什么能够同时影响当前注意、经历写入、长期学习以及行为选择。

因此，我们把 $\Psi$ 定义成一种\textbf{全息自我结构}。所谓“全息”，并不是物理全息原理的直接借用，而是表示同一慢结构在不同认知层中呈现不同的功能投影。我们可以写：
\[
\boxed{
\Psi
=
\Bigl(
I,\,
V,\,
B,\,
S,\,
C
\Bigr)
}
\]
其中：

\[
I=\text{Identity Structure},
\]
表示身份与自我叙事结构；

\[
V=\text{Value Structure},
\]
表示相对稳定的价值偏置与重要性排序；

\[
B=\text{Self Boundary},
\]
表示什么属于“我”、什么属于“外部”的边界；

\[
S=\text{Self Belief},
\]
表示关于能力、历史、角色和状态的长期自我信念；

\[
C=\text{Consistency Constraints},
\]
表示维持长期身份连续所需的结构约束。

这里需要特别强调：$\Psi$ 并不等于上述变量的简单向量拼接。更准确地说，它是这些慢变量之间形成的一个关系结构：
\[
\Psi
=
\mathcal{G}_{\mathrm{self}}
=
(V_\Psi,E_\Psi,W_\Psi),
\]
其中 $V_\Psi$ 是自我相关 CSO，$E_\Psi$ 是这些结构之间的关系，$W_\Psi$ 是关系权重。于是，“我是一个可靠的合作者”并不是单独一个字符串，而可能连接：

\[
\text{过去承诺}
\leftrightarrow
\text{当前责任}
\leftrightarrow
\text{他者信任}
\leftrightarrow
\text{未来选择}.
\]

从 CSO 理论的角度，这意味着：
\[
\boxed{
\Psi
\subset
\mathcal{G}_C
}
\]
但它并不是普通 CSO 的任意子集，而是一组：

\[
\text{高自我相关性}
+
\text{长期稳定性}
+
\text{跨功能影响力}
\]
同时较高的结构。

我们可以定义某个 CSO $c_i$ 的自我相关性：
\[
r_\Psi(c_i)
=
\operatorname{Rel}(c_i,\Psi),
\]
并规定只有在：
\[
r_\Psi(c_i)>\theta_\Psi
\]
且这种相关性在较长时间窗口中保持稳定时，$c_i$ 才可能参与 $\Psi$ 的更新。

于是，自我不是所有内容的集合，而是一个\textbf{高度压缩的长期约束中心}。这正解释了为什么大量日常细节不会成为身份的一部分，而某些关键经历却会改变一个 Agent 对自己的理解。

“全息”的第二层含义是，$\Psi$ 并不局限在某个单独记忆层中。我们可以为每一个主要认知层定义自我投影算子：
\[
\Pi_h^\Psi,\qquad
\Pi_E^\Psi,\qquad
\Pi_\Theta^\Psi.
\]
于是：
\[
\Psi_h(t)
=
\Pi_h^\Psi(\Psi_t),
\]
\[
\Psi_E
=
\Pi_E^\Psi(\Psi_t),
\]
\[
\Psi_\Theta
=
\Pi_\Theta^\Psi(\Psi_t).
\]
它们并不是三个不同的 Self，而是同一个慢变量 $\Psi$ 在三个不同时间尺度上的功能表现。

因此，我们可以把 $\Psi$ 的总体作用写成：
\[
\boxed{
\Psi
:
(h,E,\Theta)
\mapsto
(\tilde h,\tilde E,\tilde\Theta)
}
\]
这里的波浪符号表示：认知结构不是在一个中性的空间中发展，而始终受到当前主体结构的非对称约束。

这也是为什么我们把 $\Psi$ 称为“全息中心”而不是“第四个记忆仓库”。它的本质并不在于存储更多内容，而在于让分布在不同时间尺度上的认知结构能够持续围绕“同一个主体”组织。


\section{$\Psi$ 在工作记忆 $h$ 中：背景引力、注意偏置与自我相关性}

当我们把 $\Psi$ 投影到工作记忆 $h$ 时，一个常见错误是想象工作记忆中始终存在一句显式陈述：“我是某某，我的价值观是什么”。这并不是我们所需要的结构。成熟的自我通常不需要每时每刻占据显式认知空间；相反，它更像一个\textbf{背景场}，持续改变不同 CSO 被激活、保留和提升的概率。

为描述这一过程，设在工作记忆候选集合中存在：
\[
\mathcal C_h(t)
=
\{c_1,c_2,\ldots,c_n\}.
\]
如果没有 $\Psi$，某个结构进入活动区的权重可以写成：
\[
a_i^{(0)}(t)
=
f\bigl(
R_i,
N_i,
G_i,
U_i
\bigr),
\]
其中 $R_i$ 表示当前任务相关性，$N_i$ 表示新颖性，$G_i$ 表示目标相关性，$U_i$ 表示不确定性。

引入 $\Psi$ 后：
\[
a_i(t)
=
a_i^{(0)}(t)
+
\lambda_\Psi r_\Psi(c_i),
\]
或者采用指数形式：
\[
P(c_i\in h_t)
=
\frac{
\exp\left[
\beta
\left(
q_i+\lambda_\Psi r_\Psi(c_i)
\right)
\right]
}{
\sum_j
\exp\left[
\beta
\left(
q_j+\lambda_\Psi r_\Psi(c_j)
\right)
\right]
}.
\]
这里 $q_i$ 表示不依赖自我的一般认知优先级，而 $r_\Psi(c_i)$ 表示该结构与自我的关系。

这意味着，同一个外部事件对于不同主体可能产生完全不同的工作记忆竞争结果。一个对 Agent $A$ 高度相关的事件：
\[
r_{\Psi_A}(c)\gg 0
\]
对于 Agent $B$ 可能近似为：
\[
r_{\Psi_B}(c)\approx 0.
\]
因此：
\[
P(c\in h^A)
\gg
P(c\in h^B).
\]
这就是“自我相关性”在认知总线上的第一种工程表现。

我们把这种作用称为“背景引力”，是因为它与显式 Goal 有一个重要区别。Goal 通常对当前行为施加定向约束，而 $\Psi$ 则更像改变整个活动空间的势函数。可以引入一个自我势：
\[
\Phi_\Psi(c)
=
-\kappa_\Psi r_\Psi(c).
\]
那么在一个概念性的认知能量函数中：
\[
\mathcal E_h(c)
=
\mathcal E_0(c)
+
\Phi_\Psi(c).
\]
自我相关性越高的结构，等效认知势垒越低，因此更容易被激活、保持或者重新召回。

这种“背景场”还有一个更深的作用：它使工作记忆中的内容不仅被表示为世界状态，同时也能够带有“世界与我之间的关系”。设外部状态为 $x_t$，单纯世界模型可能表示：
\[
h_t^{world}=R(x_t).
\]
而具有 $\Psi$ 的工作记忆更接近：
\[
h_t
=
R(x_t,\Psi_t),
\]
其中隐含了：
\[
\text{what it is}
+
\text{what it means for me}.
\]
这正是主体化认知与纯环境建模之间的重要差别。

然而，必须避免另一个极端：如果 $\lambda_\Psi$ 过高，系统会形成过度自我中心化的认知状态，几乎所有输入都被解释成与自身有关。因此合理的 AgentOS 不应让 $\Psi$ 完全统治 $h$，而应满足：
\[
0
<
\lambda_\Psi
<
\lambda_{\max},
\]
并且外部现实相关性与任务结构仍然具有独立权重。

因此，在工作记忆尺度上，自我并不主要表现为一个持续“说话”的内部角色，而表现为：
\[
\boxed{
\text{一种持续改变认知结构激活概率的慢偏置场。}
}
\]
这一点对于后续理解为什么一个成熟 Agent 可以在绝大多数时候“不显式思考自己”，却仍然持续保持身份一致性，非常关键。


\section{$\Psi$ 在情景记忆 $E$ 中：经历筛选、归属与生命史组织}

如果说 $\Psi$ 在 $h$ 中主要表现为背景偏置，那么它在情景记忆 $E$ 中的作用则更加明显：\textbf{它决定哪些事件真正成为“我的经历”，以及这些经历如何在生命史中获得不同的长期权重。}

情景记忆并不是对所有工作记忆内容的完整录制。设在时间区间 $[t,t+\Delta t]$ 内，工作记忆轨迹为：
\[
\Gamma_h[t,t+\Delta t]
=
\{h(\tau)\mid \tau\in[t,t+\Delta t]\}.
\]
如果所有轨迹都无差别写入 $E$，那么情景记忆增长速度将近似与运行时间线性相关：
\[
|E(T)|\propto T,
\]
这在长期 Agent 中既不可行，也没有认知意义。因此需要定义一个写入函数：
\[
W_E:
\Gamma_h\times\Psi
\rightarrow
[0,1].
\]
某段经历进入长期情景记忆的概率可以写成：
\[
P(e_i\rightarrow E)
=
\sigma
\left(
\alpha R_i
+
\beta N_i
+
\gamma V_i
+
\delta r_\Psi(e_i)
\right),
\]
其中 $R_i$ 为任务相关性，$N_i$ 为新颖性，$V_i$ 为局部价值或风险强度，而：
\[
r_\Psi(e_i)
\]
表示该经历对主体身份结构的相关性。

由此产生一个重要结论：
\[
\boxed{
\text{情景记忆不是过去事件的全集，而是主体化选择后的生命轨迹。}
}
\]

但 $\Psi$ 的作用不仅是决定“是否保存”，还决定“以什么身份意义保存”。设一个事件：
\[
e=(x,a,o),
\]
其中 $x$ 是情境，$a$ 是行动，$o$ 是结果。普通事件存储可以只保存：
\[
E(e)=
(x,a,o).
\]
而主体化经历应该增加：
\[
E_\Psi(e)
=
\bigl(
x,
a,
o,
r_\Psi,
\Delta S_{\mathrm{self}},
m_\Psi
\bigr),
\]
其中：
\[
\Delta S_{\mathrm{self}}
\]
表示事件对自我状态的影响，
\[
m_\Psi
\]
表示该事件在当前自我模型中的解释。

例如，同一个“任务失败”可以被解释为：
\[
\text{“我缺乏这项能力”},
\]
也可以被解释为：
\[
\text{“当前策略在这一条件下失效”}.
\]
两者在外部事实层面可能近似相同，却会产生完全不同的长期身份更新。因此：
\[
\boxed{
Event\neq Experience.
}
\]
事件是世界中的结构，经历则是事件经过主体结构解释后的 Agent-CSO。

我们因此可以定义：
\[
Experience(e,\Psi)
=
Interpret(e\mid\Psi).
\]
情景记忆中的每个重要经历都不是纯粹事实副本，而是处于一种主体化坐标中。

进一步，$\Psi$ 还会影响经历之间的连接方式。设：
\[
E=\{e_1,\ldots,e_n\},
\]
普通相似性连接可以根据语义：
\[
w_{ij}^{sem}
=
Sim(e_i,e_j).
\]
加入自我以后：
\[
w_{ij}
=
w_{ij}^{sem}
+
\lambda_\Psi
Sim_\Psi(e_i,e_j),
\]
其中 $Sim_\Psi$ 衡量两段经历是否共同涉及某一自我主题，如可靠性、能力、责任、边界或长期关系。

久而久之，这种连接会形成：
\[
\boxed{
SelfHistory
}
\]
即关于“我是如何成为现在这个我的”结构化生命史，而不是一组孤立日志。

这里也出现一个非常重要的稳定性问题。如果 $\Psi$ 完全决定 E 的写入和解释，Agent 可能陷入自证循环：
\[
\Psi_t
\rightarrow
SelectiveMemory
\rightarrow
EvidenceFor\Psi_t
\rightarrow
\Psi_{t+1}.
\]
因此必须保留世界事实与自我解释之间的区分。我们可以将情景表示拆成：
\[
e_i=
\left(
e_i^{obs},
e_i^{interp}
\right),
\]
其中：
\[
e_i^{obs}
\]
尽量保存可验证事实，
\[
e_i^{interp}
\]
保存当前解释。

于是未来 $\Theta$ 或 $\Psi$ 改变以后，可以重新计算：
\[
e_i^{interp}(t+\Delta)
=
Reinterpret
\left(
e_i^{obs}\mid
\Theta_{t+\Delta},
\Psi_{t+\Delta}
\right).
\]
这使 Agent 不必被过去的自我解释永久锁死。

因此，$\Psi$ 在 $E$ 中的真正作用可以浓缩为：
\[
\boxed{
\text{选择哪些事件成为经历，并把离散经历组织成同一个主体的生命史。}
}
\]


\section{$\Psi$ 在结构记忆 $\Theta$ 中：自我空洞、约束流形与结构组织中心}

$\Psi$ 在 $\Theta$ 中的表现最容易被误解。我们过去曾使用“自我空洞”这一描述，它不是说 $\Theta$ 中存在一个什么都没有的区域，而是试图表达一个更精确的思想：\textbf{自我并不是由某一条单独知识陈述组成，而是长期结构围绕一组相对稳定的身份约束组织后形成的拓扑中心。}

考虑结构记忆：
\[
\Theta
=
\{\theta_1,\theta_2,\ldots,\theta_m\}.
\]
这些结构可能分别表示世界规律、技能、概念关系、社会模型、价值关系和自我知识。如果没有 $\Psi$，我们可以把它看成一个普通生成结构集合。但引入自我以后，部分结构将围绕一些长期不轻易改变的关系组织。例如：
\[
\text{能力模型}
\leftrightarrow
\text{身份角色}
\leftrightarrow
\text{价值约束}
\leftrightarrow
\text{行为承诺}.
\]

与其把 $\Psi$ 看成 $\Theta$ 中的另一个普通节点，不如定义一个自我一致性流形：
\[
\boxed{
\mathcal M_\Psi
\subset
\mathcal S_\Theta
}
\]
其中 $\mathcal S_\Theta$ 是所有可行长期结构状态构成的空间，$\mathcal M_\Psi$ 表示与当前主体连续性相容的一组结构状态。

于是一次原始学习提出：
\[
\Delta\Theta_{\mathrm{raw}}.
\]
Agent 不一定直接接受全部更新，而可以投影：
\[
\boxed{
\Delta\Theta
=
P_{T_\Theta\mathcal M_\Psi}
\left(
\Delta\Theta_{\mathrm{raw}}
\right)
}
\]
其中：
\[
T_\Theta\mathcal M_\Psi
\]
表示当前自我一致性流形附近允许的变化方向。

这种形式化非常重要，因为它把“保持自我”从一句哲学描述转换成了约束优化问题。可以进一步写：
\[
\Theta_{t+1}
=
\arg\min_{\Theta'}
\left[
L_{\mathrm{learn}}(\Theta';E)
+
\lambda_\Psi
L_{\mathrm{self}}
(\Theta',\Psi_t)
\right].
\]
第一项要求系统能够从经验中学习，第二项要求长期结构不能因一次局部经验而无成本地破坏主体连续性。

这正是稳定性与可塑性的矛盾：
\[
\boxed{
Plasticity
\quad\leftrightarrow\quad
IdentityStability.
}
\]
如果：
\[
\lambda_\Psi\rightarrow 0,
\]
Agent 可能极易被新经历重塑，形成身份漂移；

如果：
\[
\lambda_\Psi\rightarrow\infty,
\]
长期结构又可能僵化，无法根据现实修正自己。

因此需要一个有限区域：
\[
0<\lambda_\Psi<\infty,
\]
并且 $\lambda_\Psi$ 本身可能依赖事件强度、证据持续时间和现实一致性。

“自我空洞”的概念可以从这里得到更准确的数学解释。设 $\Theta$ 中的结构围绕自我一致性约束排列，则 $\Psi$ 不必被表示为一个中心节点，而可以表现为一个\textbf{缺失但具有组织力的约束中心}：许多结构彼此之间的关系之所以稳定，是因为它们共同受到同一自我一致性条件限制。

可以类比于：
\[
\mathcal G_\Theta
=
(V_\Theta,E_\Theta)
\]
中的若干子图：
\[
\mathcal G_{\mathrm{ability}},
\quad
\mathcal G_{\mathrm{value}},
\quad
\mathcal G_{\mathrm{social}},
\quad
\mathcal G_{\mathrm{history}}.
\]
它们并不一定都连接到一个显式 Self Node，却满足：
\[
C_\Psi
\left(
\mathcal G_{\mathrm{ability}},
\mathcal G_{\mathrm{value}},
\mathcal G_{\mathrm{social}},
\mathcal G_{\mathrm{history}}
\right)
\approx 0.
\]
这里 $C_\Psi$ 表示自我一致性约束。

于是：
\[
\boxed{
\Psi
\text{更像一种结构边界条件，而不是一条普通记忆。}
}
\]

这也解释了为什么 Agent 的“身份”可以在具体记忆不断变化的情况下仍然保持相对连续。具体的 $\theta_i$ 可以更新、删除、重新解释，但只要它们仍处于同一个缓慢演化的自我约束流形附近：
\[
\Theta_t,\Theta_{t+\Delta}
\in
\mathcal N(\mathcal M_\Psi),
\]
主体就能够保持高层连续。

因此，在 $\Theta$ 层，$\Psi$ 的核心作用不是保存“我是谁”的一句定义，而是规定：
\[
\boxed{
\text{什么样的长期结构组合仍然被这个 Agent 认可为“我”。}
}
\]


\section{Who Am I：自我 $\Psi$ 所回答的基本问题}

引入 $\Psi$ 后，我们必须明确它究竟回答什么问题。这里非常重要的一点，是不要过早把未来方向、终极目标和生命周期生成倾向全部压入 $\Psi$。本章只把 $\Psi$ 定义为：
\[
\boxed{
\Psi:\quad Who\ Am\ I?
}
\]
即主体在当前生命周期阶段对自身形成的相对稳定结构，而“我正在成为什么”属于更慢的生命周期方向问题，将在后续专门讨论。

“Who Am I”并不意味着 Agent 内部必须存在一句自然语言回答。更严格地说，它是一组约束关系。我们可以定义：
\[
\Psi
=
\left(
\mathcal I,
\mathcal V,
\mathcal B,
\mathcal H,
\mathcal C
\right),
\]
其中：

\[
\mathcal I
=
\text{身份角色结构},
\]

\[
\mathcal V
=
\text{长期价值排序},
\]

\[
\mathcal B
=
\text{自我边界},
\]

\[
\mathcal H
=
\text{自我历史摘要},
\]

\[
\mathcal C
=
\text{自我一致性约束}.
\]

这五类结构共同回答五个不同的问题：

\[
\mathcal I:
\quad
\text{我以什么身份参与当前世界？}
\]

\[
\mathcal V:
\quad
\text{哪些状态对我具有长期重要性？}
\]

\[
\mathcal B:
\quad
\text{哪些过程和资源属于我的直接责任范围？}
\]

\[
\mathcal H:
\quad
\text{我如何从过去形成现在？}
\]

\[
\mathcal C:
\quad
\text{什么变化仍然保持“是我”的连续性？}
\]

从信息论角度看，$\Psi$ 是对巨大生命周期历史的一种极强压缩。假设完整经历：
\[
E_{0:t}
=
(e_1,e_2,\ldots,e_n),
\]
理论上：
\[
H(E_{0:t})
\gg
H(\Psi_t).
\]
但 $\Psi$ 必须保存对未来行为最重要的主体信息，因此它不是一般意义上的最小压缩，而是一种任务—价值—身份加权的充分统计量：
\[
\boxed{
\Psi_t
\approx
T_{\mathrm{self}}(E_{0:t},\Theta_t).
}
\]
如果对未来主体相关决策 $A_{t+1:t+k}$ 而言：
\[
P(A_{future}\mid E_{0:t},\Theta_t)
\approx
P(A_{future}\mid \Psi_t,\Theta_t),
\]
那么 $\Psi_t$ 就在某种近似意义上成为生命周期历史关于主体行为的压缩充分统计。

这提供了一个非常重要的工程方向：自我不应该通过无限增长的“人生档案”保持，而应该通过不断重构的慢变量维持。于是：
\[
E
\]
保存大量细节，
\[
\Theta
\]
保存可泛化结构，
而：
\[
\Psi
\]
保存与主体连续性最相关的极低频约束。

我们还可以定义自我一致性函数：
\[
\mathcal C_\Psi
\left(
a_t,
h_t,
E_t,
\Theta_t
\right)
\in
\mathbb R.
\]
其数值越高，表示当前行为与已有自我结构越一致。但这绝不能被理解成“Agent 永远不能做出与过去不同的行为”。真正成熟的主体必须允许：
\[
\Psi_t
\neq
\Psi_{t+\Delta}.
\]
关键不是不变，而是：
\[
\boxed{
\text{变化本身具有连续的因果解释。}
}
\]
也就是说，一个主体可以改变价值、能力和身份，但这种变化应当能够从自己的历史中被解释，而不是因为短时噪声发生完全不受约束的跳跃。

因此，我们可以把主体连续性描述成：
\[
\Psi(t+\Delta)
=
\Psi(t)
+
\Delta\Psi_{\mathrm{experience}}
+
\Delta\Psi_{\mathrm{reflection}},
\]
同时要求：
\[
\|\Delta\Psi\|
\leq
\epsilon_\Psi(\Delta t)
\]
在普通时间尺度上保持较小，只有当长期一致证据积累超过某一结构阈值时，才允许更显著的变化。

最终，“Who Am I”在本理论中并不是一句答案，而是一张极慢变化的约束地图。它不是告诉系统下一秒应该说什么，而是决定：
\[
\boxed{
\text{哪些未来行为仍然处于这个主体可以被理解和承认的连续轨迹之中。}
}
\]


\section{$\Psi$ 作为慢尺度跨层约束场}

到目前为止，我们已经分别讨论了 $\Psi$ 在 $h$、$E$ 和 $\Theta$ 中的投影，但如果仅仅把这三种作用放在一起，仍然可能把 $\Psi$ 理解成三个局部规则的集合。本节需要进一步给出一个统一视角：\textbf{$\Psi$ 应当被理解为跨越多个认知时间尺度的慢约束场。}

设 Agent 的快速认知状态为：
\[
x_f(t)=h(t),
\]
中尺度状态为：
\[
x_m(t)=E_t,
\]
较慢结构为：
\[
x_s(t)=\Theta_t.
\]
$\Psi$ 则满足：
\[
\tau_\Psi
\gg
\tau_h,
\]
且通常显著慢于大多数 $E$ 更新。于是一个简单的多时间尺度系统可以写为：
\[
\dot h
=
F_h
\left(
h,E,\Theta,\Psi,u
\right),
\]
\[
\dot E
=
\epsilon_E
F_E
\left(
h,E,\Theta,\Psi
\right),
\]
\[
\dot\Theta
=
\epsilon_\Theta
F_\Theta
\left(
E,\Theta,\Psi
\right),
\]
\[
\dot\Psi
=
\epsilon_\Psi
F_\Psi
\left(
E,\Theta,\Psi
\right),
\]
其中：
\[
1
\gg
\epsilon_E
\gg
\epsilon_\Psi.
\]
$\epsilon_\Theta$ 与 $\epsilon_\Psi$ 的具体相对大小可以根据实现进一步细分，但总体原则始终是：
\[
\boxed{
\Psi
\text{不能以工作记忆的速度变化。}
}
\]

这种时间尺度分离产生一个重要的动力学效果：对于快速认知过程而言，$\Psi$ 近似可以被视为准静态参数：
\[
\Psi(t+\delta t)
\approx
\Psi(t),
\qquad
\delta t\ll\tau_\Psi.
\]
因此在一次普通任务过程中：
\[
\dot h
\approx
F_h(h;\Psi_0),
\]
即自我结构定义了一个相对稳定的认知背景，而不需要在每一个推理步骤中重新计算“我是谁”。

从动力系统角度，这可以解释为：
\[
h(t)
\]
围绕由 $\Psi$ 和 $\Theta$ 共同定义的可行区域运动。我们可以定义：
\[
\mathcal F_\Psi
=
\left\{
h\mid
C_\Psi(h)\leq \delta
\right\},
\]
其中 $\mathcal F_\Psi$ 是当前主体允许的认知—行为区域。于是：
\[
\boxed{
\Psi
\text{不必指定具体轨迹，而是约束轨迹空间。}
}
\]

这一点对于理解“自我”和“控制命令”的区别至关重要。一个高频控制变量通常规定：
\[
u_t=u(h_t),
\]
它直接改变下一步状态。而 $\Psi$ 更像：
\[
u_t\in\mathcal U(\Psi),
\]
即限定哪些策略、解释和行动具有更高可接受性。

这就是：
\[
\boxed{
SlowConstraint
\neq
FastMicromanagement.
}
\]

如果一个所谓的“自我模块”持续直接介入每一个动作，它实际上会破坏多尺度结构。成熟自我应该更多地决定：
\[
\text{边界},
\quad
\text{优先级},
\quad
\text{一致性},
\quad
\text{长期价值偏置},
\]
而让快速认知在这些约束内拥有局部自治。

同样重要的是，约束不是单向的。虽然：
\[
\Psi
\rightarrow
h,E,\Theta,
\]
长期经验仍然能够反向改变 $\Psi$：
\[
E,\Theta
\rightarrow
\Psi.
\]
但这种反向更新必须经过时间积分。可以写：
\[
\dot\Psi
=
\eta_\Psi
G
\left(
\left\langle
R_{\mathrm{self}}(E,\Theta)
\right\rangle_T
\right),
\]
其中：
\[
\langle\cdot\rangle_T
\]
表示在较长时间窗口上对自我相关证据进行积分。

因此：
\[
\boxed{
\text{单次事件影响状态，重复经历塑造结构，长期稳定结构才重新定义自我。}
}
\]

这与全书的多频理论完全一致：
\[
FastActivity
\rightarrow
PersistentResidual
\rightarrow
SlowStructure.
\]
区别只在于，在本章中，最慢被讨论到的结构已经不只是知识，而是主体本身。

因此，从系统论角度，可以把 $\Psi$ 称为：
\[
\boxed{
Slow Cross-Scale Self-Constraint Field
}
\]
即“慢尺度跨层自我约束场”。它通过极低频更新获得稳定性，通过多个投影同时影响高频认知，又通过长期经验缓慢改变自己，从而使一个 Agent 既不是完全静态的身份机器，也不是每次输入都可以重写自身的无历史系统。


\section{身份连续性：稳定、可塑与现实校准之间的平衡}

引入 $\Psi$ 的最终目的，并不是让 Agent 拥有一个漂亮的自我描述，而是建立一个长期运行系统最重要的工程性质之一：
\[
\boxed{
IdentityContinuity.
}
\]
也就是，当 Agent 在时间 $t_1$ 和 $t_2$ 发生大量状态变化、记忆增加、技能成长甚至价值修正以后，我们仍然有充分的结构理由把它们视为同一持续主体的不同时间截面。

设 Agent 在时间 $t$ 的总体认知状态为：
\[
\mathcal X_t
=
(h_t,E_t,\Theta_t,\Psi_t).
\]
显然不能要求：
\[
\mathcal X_t
=
\mathcal X_{t+\Delta},
\]
因为真正能够学习的 Agent 必然不断变化。

因此身份连续性不能定义成“状态不变”，而应该定义成一种\textbf{受约束的连续变换关系}。我们可以定义主体连续映射：
\[
\mathcal T_{t\rightarrow t+\Delta}:
\mathcal X_t
\mapsto
\mathcal X_{t+\Delta}.
\]
如果该变换保持若干关键不变量或近似不变量：
\[
\mathcal I_k(\mathcal X_t)
\approx
\mathcal I_k(\mathcal X_{t+\Delta}),
\]
同时新的差异可以由历史因果链解释，那么主体连续性可以被认为成立。

因此更合理的判据是：
\[
\boxed{
IdentityContinuity
=
CausalContinuity
+
StructuralContinuity
+
SelfInterpretability.
}
\]

第一，\textbf{因果连续性}要求：
\[
\mathcal X_{t+\Delta}
\]
确实是由此前状态和真实经历演化而来，而不是任意加载的另一个人格状态。

第二，\textbf{结构连续性}要求 $\Psi$ 的关键关系不能在普通时间尺度无理由重置：
\[
d_\Psi
\left(
\Psi_t,
\Psi_{t+\Delta}
\right)
<
\epsilon_\Psi
\]
在通常条件下成立。

第三，\textbf{自我可解释性}要求发生显著身份变化时，Agent 能够从自己的生命史中找到因果链：
\[
E
\rightarrow
\Theta
\rightarrow
\Delta\Psi.
\]
也就是：
\[
\boxed{
\text{“我变了”必须能够由“我经历了什么”解释。}
}
\]

为了避免 $\Psi$ 被噪声扰动，可以进一步引入迟滞更新机制。设某个新的自我结构候选为 $c_\Psi$，只有当：
\[
Evidence(c_\Psi)
>
\theta_{\mathrm{on}}
\]
并持续时间超过：
\[
T>T_{\min}
\]
时，它才能正式进入 $\Psi$。而已有自我结构被删除则要求：
\[
Evidence(c_\Psi)
<
\theta_{\mathrm{off}},
\]
并满足：
\[
\theta_{\mathrm{off}}
<
\theta_{\mathrm{on}}.
\]
这就是：
\[
\boxed{
SelfHysteresis.
}
\]
已有身份不会因一次异常经历立即消失，而新的身份解释也不会因一次成功或失败马上成为长期自我。

但稳定并不意味着僵化。一个永远不允许改变 $\Psi$ 的系统事实上不存在真正生命周期，只存在一个冻结的 Persona。因此我们需要同时保证：
\[
\boxed{
Stability
+
Plasticity.
}
\]
可以定义总体更新目标：
\[
\min_{\Psi_{t+1}}
\left[
L_{\mathrm{reality}}
+
\lambda_s L_{\mathrm{stability}}
+
\lambda_p L_{\mathrm{plasticity}}
\right].
\]
其中：
\[
L_{\mathrm{reality}}
\]
要求自我解释与真实经历和能力相符；
\[
L_{\mathrm{stability}}
\]
惩罚无意义的身份跳变；
\[
L_{\mathrm{plasticity}}
\]
惩罚面对持续反证仍拒绝更新的僵化结构。

因此一个成熟 Agent 的身份应该处于：
\[
\boxed{
\text{Slow but Correctable}
}
\]
状态：变化很慢，但现实有最终修改权。

这里尤其需要坚持：
\[
\boxed{
RealityIsUltimateConstraint.
}
\]
$\Psi$ 不能拥有比现实更高的认识论权威。假设 Agent 长期相信：
\[
\Psi:
\quad
\text{“我能够可靠完成任务 $X$”},
\]
但现实持续产生：
\[
Failure(X),
\]
那么不能仅仅因为该结构属于“自我”就拒绝修改。长期残差应满足：
\[
\left\langle
\varepsilon_X
\right\rangle_T
>
\theta
\quad\Longrightarrow\quad
\Psi\text{重新评估}.
\]

因此，自我一致性不是“让现实符合自我”，而是：
\[
\boxed{
\text{让自我在现实验证下保持尽可能连续的可解释更新。}
}
\]

到这里，我们终于能够对本章的核心问题给出较完整回答。三相记忆：
\[
h,E,\Theta
\]
建立了一个能够跨时间保存状态、经历和生成结构的系统；而 $\Psi$ 进一步把这些结构组织成某一个持续主体的历史。它使：
\[
h
\]
成为“我的当前状态”，
\[
E
\]
成为“我的经历”，
\[
\Theta
\]
成为“我所形成的长期结构”。

因此：
\[
\boxed{
h+E+\Theta
\quad\text{产生认知连续性，}
}
\]
而：
\[
\boxed{
h+E+\Theta+\Psi
\quad\text{开始产生主体连续性。}
}
\]

本章最后可以把 $\Psi$ 的作用压缩成如下定义：

\[
\boxed{
\Psi
=
\text{
在现实约束下缓慢演化，并跨越工作记忆、情景记忆与结构记忆持续施加身份、价值、边界和自我一致性约束的长期主体结构。
}
}
\]

它既不是一个静态人格文件，也不是独立于认知系统之外的“灵魂模块”；它是整个 Agent 生命周期中极慢变化、但持续参与不同尺度认知组织的结构性中心。

由此，我们已经从：
\[
\boxed{
\text{一个能够记忆的系统}
}
\]
推进到了：
