\chapter{工作记忆有限容量定理}
\label{chap:working-memory-finite-capacity}

\begin{chapteroverviewbox}
本章建立 AgentOS 原理论中的一个基础约束：任何具有有限物理承载、有限计算带宽和有限更新周期的智能体，在任意给定时刻都不可能稳定地将无限数量、无限关系密度的认知结构同时维持在全局显式工作状态中。因此，工作记忆 $h(t)$ 的根本限制并不是“能够放入多少 Token”，而是系统能够在当前时间尺度内保持多少\textbf{相互可区分、关系可追踪、约束可满足、能够共同参与推理和行动的有效认知结构}。

我们将这一约束称为\textbf{工作记忆有限容量定理}。它首先是 AgentOS 的理论公理化约束，而不是声称已经由认知科学证明的一条普适自然定律。它吸收工作记忆容量理论、有限计算资源、图结构复杂度、控制系统有限带宽以及全局工作空间等外部理论的启发，但本章给出的 ``有效认知复杂度''、``结构相干容量'' 与相关数学形式属于本书为了描述持续智能体而构造的理论语言。

本章的任务不是立即介绍如何治理这一有限容量。后续章节中的 SPC、TCE、CCM、Scheduler、Boundary 与 Offloading 都可以看成这一基本约束的不同工程回应；但在本章中，我们首先把问题保持在更基础的位置：\textbf{为什么工作记忆必然有限，什么东西真正消耗工作记忆容量，以及越过这一边界以后为什么会发生认知退化。}

本章最终建立如下核心关系：
\[
\boxed{
C_{\mathrm{run}}(t)
\leq
C_{\mathrm{cap}}\!\left(h(t),\mathcal{A},\tau\right)
}
\]
其中 $C_{\mathrm{run}}(t)$ 表示当前显式认知状态所承担的有效结构负载，$C_{\mathrm{cap}}$ 表示在给定认知架构 $\mathcal{A}$ 与工作时间尺度 $\tau$ 下，工作记忆 $h(t)$ 能够稳定维持的相干结构容量。只有保持这一不等式，工作记忆才能继续充当整个 Agent 的可治理、可解释和可行动的全局认知表面。
\end{chapteroverviewbox}


\section{工作记忆为什么必然有限}
\label{sec:wm-why-finite}

我们首先必须把工作记忆从一种抽象的“信息容器”重新放回真实智能系统中理解。无论一个智能体最终由生物神经系统、数字计算机、混合神经符号系统还是未来其他物理介质承载，只要它实际存在于物理世界中，就必然受到有限存储、有限通信带宽、有限同步速度、有限计算功率以及有限控制周期的约束。于是，任何在时刻 $t$ 被提升到全局显式工作状态中的认知结构，都必须在有限的时间窗口内完成若干基本操作：被保持、被区分、与其他结构建立关系、接受目标和约束、参与预测、参与行动选择，并在状态发生变化后及时更新。如果这些操作所需的总资源超过当前系统能够提供的有效带宽，那么问题并不是“记忆内容多了一点”，而是工作状态本身开始失去结构一致性。

为了形式化这一点，我们把工作记忆记作
\[
h(t),
\]
但应注意，$h(t)$ 不是一个静态集合，而是一个随时间变化的\textbf{活跃认知状态面}。设当前进入显式工作状态的 Agent-CSO 集合为
\[
V_h(t)=
\left\{
c_1(t),c_2(t),\ldots,c_{n(t)}(t)
\right\},
\]
它们之间存在当前必须被维持的语义、因果、目标、时序、约束、排斥和条件关系
\[
E_h(t).
\]
于是工作记忆更准确地可以表示为一个时间依赖的认知图
\[
\mathcal{G}_h(t)
=
\left(
V_h(t),E_h(t)
\right).
\]
系统真正需要维持的不是 $|V_h|$ 个彼此孤立的对象，而是整个 $\mathcal{G}_h(t)$ 的有效结构。即使两个状态拥有相同的节点数量，它们所需要的认知资源也可能完全不同。例如十个互相独立的事实与十个彼此存在复杂条件依赖的变量，其节点数相同，但后者要求系统同步保持更多关系、条件和反事实路径。

因此，我们可以把工作记忆所承担的瞬时资源需求抽象为
\[
R_h(t)
=
R_{\mathrm{state}}(t)
+
R_{\mathrm{relation}}(t)
+
R_{\mathrm{update}}(t)
+
R_{\mathrm{control}}(t),
\]
其中 $R_{\mathrm{state}}$ 表示保持活跃状态本身的资源，$R_{\mathrm{relation}}$ 表示保持结构关系所需的资源，$R_{\mathrm{update}}$ 表示根据新观测及时修正这些关系的资源，而 $R_{\mathrm{control}}$ 表示让这些结构继续受当前目标、约束和注意机制控制所需的资源。一个显式认知状态能够稳定存在的必要条件，是在当前时间尺度 $\tau_h$ 内有
\[
R_h(t)
\leq
R_{\mathrm{available}}(t).
\]
当右侧资源有限时，左侧能够稳定承载的结构自然存在上界。

这里最关键的认识是：\textbf{有限性不是一个实现缺陷，而是任何真实智能体的存在条件。}一个完全没有容量限制的工作记忆必须隐含无限存储、无限带宽、无限同步速度或者无限计算能力，而这些条件对于实际物理智能体并不成立。即使未来硬件规模远高于今天，这条逻辑仍然不会消失；变化的只是容量边界的位置，而不是有限性本身。

因此，本书不把智能成熟理解为“不断扩大显式工作区直到可以同时想一切”，而恰恰相反：越成熟的智能，越应该学会让有限的全局工作面只承载当前真正需要跨功能协调的结构。后面我们将看到，大量自动化、长期记忆、局部闭环和认知卸载，其根本意义都可以追溯到这一简单约束。但在本章我们首先确立第一条原则：
\begin{proposition*}
任何实际智能体的全局显式工作状态都具有有限结构承载能力。
\end{proposition*}


\section{容量不是 Token 数：从存储容量到结构容量}
\label{sec:wm-not-token-count}

在当前大语言模型语境中，工作记忆很容易被误解成 Context Window，于是人们自然把“工作记忆容量”理解成模型一次可以读入多少 Token。这种工程指标当然重要，但如果我们把它直接当成认知容量，就会遗漏真正限制复杂推理的那一层结构。一个系统能够接收一百万个 Token，并不意味着它能够在同一时刻把其中一百万个信息单元都作为活跃变量参与统一推理；同样，一个文本已经位于 Context 中，也不意味着它仍然处于系统的有效工作状态。

我们因此需要区分三个层次：
\[
C_{\mathrm{storage}},
\qquad
C_{\mathrm{accessible}},
\qquad
C_{\mathrm{coherent}}.
\]
$C_{\mathrm{storage}}$ 表示物理或逻辑上可以容纳多少信息；$C_{\mathrm{accessible}}$ 表示其中多少内容能够在当前操作中被有效检索；而 $C_{\mathrm{coherent}}$ 表示其中多少结构能够\textbf{同时保持关系一致并参与统一认知过程}。通常存在
\[
C_{\mathrm{coherent}}
\leq
C_{\mathrm{accessible}}
\leq
C_{\mathrm{storage}}.
\]
这三个容量随着硬件、模型、注意机制和编码方式不同可以发生数量级变化，但它们在概念上不能被混为一谈。

考虑两个具有相同文本长度的任务。任务 $A$ 包含大量彼此独立的事实查询，例如分别读取数百个互不相关的编号；任务 $B$ 只包含几十个变量，但要求同时满足一个高度耦合的约束系统：
\[
g_k(x_1,\ldots,x_n)=0,
\qquad
k=1,\ldots,m.
\]
从 Token 数量看，$A$ 甚至可能远大于 $B$；然而从显式推理压力看，$B$ 可能更困难，因为一次局部变化会沿着关系网络传播并改变大量其他变量的可行域。这说明工作记忆容量真正受到影响的，是需要同步维持的\textbf{关系结构复杂度}。

我们可以把当前工作图
\[
\mathcal{G}_h=(V_h,E_h)
\]
的简单结构负载定义为
\[
C_G(t)
=
\alpha |V_h(t)|
+
\beta |E_h(t)|
+
\gamma \Xi\!\left(\mathcal{G}_h(t)\right),
\]
其中 $\Xi(\mathcal{G}_h)$ 用于描述高阶关系特征，例如条件依赖深度、环路数量、约束耦合、跨子图依赖或高阶超边。这里 $\alpha,\beta,\gamma$ 并不是普适常数，而只是不同类型结构对当前系统认知资源需求的有效权重。

进一步，如果节点本身具有不同的内部结构复杂度，则可以写成
\[
C_G(t)
=
\sum_{i\in V_h} c_i
+
\lambda
\sum_{(i,j)\in E_h}r_{ij}
+
\mu
\sum_{\ell\in\mathcal{L}_h}q_\ell,
\]
其中 $c_i$ 表示第 $i$ 个活跃 Agent-CSO 的显式维持代价，$r_{ij}$ 表示关系维护代价，而 $q_\ell$ 则表示闭环或高阶耦合造成的额外协调负担。

这套表示立即解释了一个经常出现的现象：当 Context 持续增长时，系统未必突然“装不下”更多 Token，而可能首先出现关系信号衰减。模型依然能够看到各个局部片段，却越来越难判断哪些关系属于当前主要因果链；某些旧约束被遗忘，局部推理仍然流畅，但全局已经自相矛盾；计划后半部分满足最新目标，却破坏了早期设定的边界条件。此时发生的并不是传统意义上的存储溢出，而是
\begin{proposition*}
结构相干容量先于文本存储容量耗尽。
\end{proposition*}

因此，本书所说的工作记忆有限容量，核心对象应当是 $C_{\mathrm{coherent}}$，而不是 Context Length。本章之后所有关于容量、过载和认知退化的讨论，也都应建立在这一更严格的区别之上。


\section{同时可维持的关系结构数量}
\label{sec:wm-relational-capacity}

一旦我们承认工作记忆的核心瓶颈是关系结构，而不是孤立内容数量，就必须进一步问：究竟是什么使某些认知图比其他认知图更难被同时维持？最直接的答案不是节点数，而是\textbf{关系的数量、关系的耦合形式以及关系更新产生的传播范围}。

设当前认知图为
\[
\mathcal{G}_h(t)=
\left(V_h,E_h\right).
\]
对于一个完全稀疏、近似独立的图，若平均度数为 $\bar d\approx O(1)$，则边数量随节点数近似线性增长：
\[
|E_h|
\sim
O(|V_h|).
\]
此时新增一个认知对象通常只引入少量新的关系。相反，如果当前任务要求大量变量相互比较，平均度数可能随着节点数增长，则
\[
|E_h|
\sim
O(|V_h|^2)
\]
成为可能。此时节点数量翻倍，系统要同时保持的潜在关系并不是翻倍，而可能接近四倍。工作记忆的“突然崩溃感”因此可以有一个非常自然的结构来源：\textbf{关系负载可以比对象数量增长得更快。}

但仅仅计算边数量仍然不够，因为不同关系并不具有相同认知成本。一个稳定的、已经被长期结构支持的关系，例如“物体不能同时位于两个远离位置”，可能几乎不需要显式推理；而一个刚刚建立、尚未确定、需要持续验证的关系则必须长期占据显式资源。因此我们为每条关系引入活跃权重
\[
a_{ij}(t)\in[0,1],
\]
并定义关系维护负载
\[
C_R(t)
=
\sum_{(i,j)\in E_h}
a_{ij}(t)\,r_{ij}(t).
\]
其中 $r_{ij}$ 不仅取决于关系类型，还取决于不确定性、变化速度、目标相关性和违反该关系可能造成的损失。

我们还需要考虑传播复杂度。设一个节点状态变化 $\delta c_i$ 会通过依赖关系传播到邻接节点，则在一个短时间窗口 $\Delta t$ 内需要被重新评估的节点集合可表示为
\[
\mathcal{N}_{\Delta t}(i).
\]
可以定义局部结构扰动放大率
\[
\kappa_i
=
\frac{
|\mathcal{N}_{\Delta t}(i)|
}{
1+|\delta c_i|
},
\]
或者更一般地，以 Jacobian
\[
J_{ij}
=
\frac{\partial x_j}{\partial x_i}
\]
描述结构中的局部敏感性。如果 $\|J\|$ 较大，则很小的局部更新可能引起广泛的全局重计算。此时即使图本身节点并不多，也可能对工作记忆形成巨大的动态压力。

因此我们可以把瞬时关系结构复杂度更一般地表示为
\[
C_{\mathrm{rel}}(t)
=
F\!\left(
|V_h|,
|E_h|,
H(E_h),
D_{\mathrm{dep}},
N_{\mathrm{loop}},
\|J\|,
U
\right),
\]
其中 $H(E_h)$ 表示关系类型和不确定性的有效熵，$D_{\mathrm{dep}}$ 表示依赖深度，$N_{\mathrm{loop}}$ 表示需要显式维持的闭环数量，$\|J\|$ 表示结构耦合敏感度，$U$ 则表示当前不确定性。

这也解释了为什么人类和 Agent 都会自然使用“分块”“概念化”“抽象”“命名”和“技能化”。一个原本由几十个节点组成的子图，如果能够被压缩为一个稳定高阶 CSO
\[
\mathcal{G}_{sub}
\longrightarrow
C^\star,
\]
那么上层工作记忆不再需要实时展开该子图内部的全部关系，而只需要维持 $C^\star$ 与其他高层结构之间的少量关系。于是认知容量并没有凭空增加，而是通过\textbf{结构重新编码}降低了当前显式关系数量。

所以，本书中的“工作记忆容量”不是一个固定槽位数，而更接近一个在当前表示方式下可稳定承载的\textbf{有效关系图规模}。同一个 Agent，通过更好的抽象、技能化和长期结构化，可以在不改变物理基础容量的情况下处理更复杂的问题。这一结论将在后面成为理解“熟练为何减少思考”的关键，但此处我们只需要记住：

\begin{conclusion}
真正耗尽工作记忆的，通常不是对象数量本身，而是必须同时保持活跃的关系结构。
\end{conclusion}


\section{认知相干性：工作记忆容量的真正判据}
\label{sec:cognitive-coherence}

如果工作记忆只是存储结构，那么我们只需要定义一个简单容量上限；但工作记忆的真正功能是让多个认知结构在同一时刻参与统一判断。因此，对工作记忆是否“仍然正常工作”的判断，不应仅仅基于内容是否存在，而应基于这些内容是否仍然保持\textbf{认知相干性}。

我们将认知相干性记作
\[
\Gamma_h(t),
\qquad
0\leq\Gamma_h(t)\leq1.
\]
它不是单一统计量，而是若干结构性质的综合函数：
\[
\Gamma_h
=
\Phi
\left(
\Gamma_{\mathrm{constraint}},
\Gamma_{\mathrm{causal}},
\Gamma_{\mathrm{goal}},
\Gamma_{\mathrm{temporal}},
\Gamma_{\mathrm{referential}}
\right).
\]
其中 $\Gamma_{\mathrm{constraint}}$ 表示当前认知状态满足已知约束的一致程度；$\Gamma_{\mathrm{causal}}$ 表示因果链是否保持连贯；$\Gamma_{\mathrm{goal}}$ 表示局部推理是否仍服务于当前主目标；$\Gamma_{\mathrm{temporal}}$ 表示事件时序是否发生错误重排；$\Gamma_{\mathrm{referential}}$ 则表示对象身份、变量指代和语义绑定是否保持稳定。

例如设当前工作记忆中存在一组约束
\[
g_k(x)\leq 0,
\qquad
k=1,\ldots,m.
\]
可以定义约束违反量
\[
V_c(t)
=
\sum_{k=1}^{m}
w_k
\max
\left(
0,g_k(x(t))
\right),
\]
并令
\[
\Gamma_{\mathrm{constraint}}
=
\exp
\left(
-\lambda_c V_c
\right).
\]
当系统开始遗忘早期限制、重复使用相互冲突的假设时，$V_c$ 增加，相干性下降。

同样，如果当前目标为 $G^\star$，而活跃认知路径 $p_i$ 与该目标之间的相关度为 $\rho(p_i,G^\star)$，则可以定义目标相干度
\[
\Gamma_{\mathrm{goal}}
=
\frac{
\sum_i a_i\rho(p_i,G^\star)
}{
\sum_i a_i+\varepsilon
}.
\]
当大量边缘支线同时占据工作记忆时，即使每条支线局部都“有道理”，整个工作状态仍可能因为目标中心消失而失去相干性。

因此我们可以提出一个比简单容量阈值更严格的稳定条件。设最低可接受相干水平为 $\Gamma_{\min}$，则工作记忆的稳定区定义为
\[
\mathcal{S}_h
=
\left\{
\mathcal{G}_h:
\Gamma_h(\mathcal{G}_h)
\geq
\Gamma_{\min}
\right\}.
\]
于是所谓“容量上界”并不是说多加入第 $N+1$ 个对象后物理存储突然失败，而是存在某个结构区域，使
\[
C_{\mathrm{run}}\uparrow
\quad\Rightarrow\quad
\Gamma_h\downarrow,
\]
并最终穿过
\[
\Gamma_h=
\Gamma_{\min}.
\]
超过这一点以后，系统仍可能继续输出语言、执行动作甚至保持局部流畅，但已经不再可靠地维持全局结构一致性。

这一区分对于研究大模型 Agent 尤其重要。生成过程局部流畅并不是相干性的充分证据。一个系统可以在语言层面继续产生语法正确的句子，同时忘记二十步之前的任务约束；可以逐步完成每一个局部子任务，却最终得到与最初目标不一致的整体结果。换言之，
\[
\boxed{
LocalFluency
\neq
GlobalCognitiveCoherence.
}
\]

因此，本章后面所谓“工作记忆容量”应始终理解为：在一定时间窗口内，使工作认知图保持 $\Gamma_h\geq\Gamma_{\min}$ 所允许的最大有效结构负载。这个定义比“能够放多少内容”严格得多，也更适合作为 AgentOS 的设计基础。


\section{工作记忆容量 $W$：从固定槽位到有效资源预算}
\label{sec:working-memory-W}

为了建立可计算的理论，我们仍然需要一个能够表示工作记忆总体能力的量。历史讨论中我们使用 $W$ 表示工作记忆容量，并使用
\[
C_{\max}(W)=\alpha W
\]
作为第一阶近似。这个表达具有良好的工程直觉：随着工作记忆资源 $W$ 增加，可稳定维持的有效认知结构上界通常也会增加。但如果我们希望把理论进一步推进，就必须明确 $W$ 不是简单的“槽位数量”，而是一组异质资源共同形成的有效预算。

我们可以定义
\[
W
=
\left(
W_m,
W_a,
W_c,
W_b,
W_u
\right),
\]
其中：

\[
W_m
\]
表示可用于维持活跃状态的记忆资源；

\[
W_a
\]
表示注意和路由资源；

\[
W_c
\]
表示当前认知周期可以用于结构计算的计算资源；

\[
W_b
\]
表示模块之间有效通信带宽；

\[
W_u
\]
表示单位时间能够完成的结构更新能力。

于是更一般的工作记忆容量不再是标量，而可以写成
\[
C_{\mathrm{cap}}
=
\mathcal{C}
\left(
W_m,W_a,W_c,W_b,W_u;
\mathcal{R},\tau_h
\right),
\]
其中 $\mathcal{R}$ 表示当前表征方案，$\tau_h$ 表示工作状态需要维持和更新的时间尺度。

这一定义揭示了一个重要事实：\textbf{工作记忆容量不仅由硬件决定，也由表示方式决定。}如果同一问题可以用更有效的结构编码表达，那么每个有效 CSO 所消耗的资源减少，于是可维持结构容量增加。设原始表示 $\mathcal{R}_1$ 下平均单位结构代价为
\[
\bar c_1,
\]
经过更好的抽象后变为
\[
\bar c_2<\bar c_1,
\]
则即使总资源 $W$ 不变，也可能有
\[
C_{\mathrm{cap}}(W,\mathcal R_2)
>
C_{\mathrm{cap}}(W,\mathcal R_1).
\]
这也是为什么人类专家面对熟悉领域时能够“同时看见更多东西”。并不是其生理工作记忆容量突然扩大，而是大量底层关系已经被压缩成高层稳定结构。

因此，在第一阶工程近似中，我们仍然可以写
\[
C_{\max}(W)
=
\alpha_{\mathcal R} W,
\]
但应该把 $\alpha_{\mathcal R}$ 理解成一个与表征效率、结构压缩程度、当前任务类型和系统架构有关的有效系数。对于真正复杂的系统，更一般的形式是
\[
C_{\max}
=
F
\left(
W,
\mathcal R,
\mathcal G_h,
\tau_h,
U
\right),
\]
其中 $U$ 表示环境和任务不确定性。

我们还可以定义\textbf{工作记忆裕度}
\[
M_h(t)
=
C_{\mathrm{cap}}(t)
-
C_{\mathrm{run}}(t).
\]
这里特意使用 $M_h$ 而不是 $h(t)$ 表示容量裕度，因为在本书中 $h(t)$ 已经具有明确含义：它是工作记忆本身。可靠系统不应仅仅要求
\[
M_h(t)\geq0,
\]
而应保留一定安全余量
\[
M_h(t)\geq M_{\min}>0.
\]
其原因类似工程系统中的 reserve margin：如果工作记忆始终运行在理论极限附近，那么任何新的异常、突然出现的约束或世界反馈都会使系统立即越过稳定边界。

由此我们得到工作记忆工程的第二条关键原则：
\begin{proposition*}
成熟智能不仅需要容量，还需要认知容量裕度。
\end{proposition*}
这为后续所有“为什么要抑制不必要结构进入全局工作区”的工程设计提供了量化基础。


\section{有限复杂度定理：有效运行结构的上界}
\label{sec:finite-complexity-theorem}

现在我们可以正式给出本章的核心命题。需要再次强调，“定理”在这里首先表示 AgentOS 理论体系中的形式化命题；它的严格普适性仍需要未来实验和数学研究进一步验证。

\textbf{工作记忆有限容量定理：}

对于任意具有有限物理资源、有限状态更新速率和有限通信带宽的智能系统 $A$，给定其工作记忆架构 $\mathcal A$、显式认知时间尺度 $\tau_h$、表示方式 $\mathcal R$ 以及最低认知相干阈值 $\Gamma_{\min}$，存在有限的有效结构容量
\[
C_{\mathrm{cap}}
<
\infty,
\]
使得当工作记忆当前承载的有效运行结构复杂度满足
\[
C_{\mathrm{run}}(t)
\leq
C_{\mathrm{cap}},
\]
且系统保留足够更新资源时，工作状态可以维持
\[
\Gamma_h(t)
\geq
\Gamma_{\min}.
\]
反之，当
\[
C_{\mathrm{run}}(t)
>
C_{\mathrm{cap}}
\]
持续足够长时间，则系统不能同时保证所有活跃结构的保持、关系更新、约束一致与目标一致，认知相干性将出现下降。

第一阶近似可以写成
\[
\boxed{
C_{\mathrm{eff}}(t)
\leq
C_{\max}(W)
=
\alpha W
}
\]
其中 $W$ 是工作记忆有效资源预算，$\alpha$ 是与表示和编码效率相关的有效系数。

更精细地，我们可把运行结构复杂度写成
\[
C_{\mathrm{run}}(t)
=
\sum_i
a_i(t)c_i(t)
+
\lambda_R
\sum_{(i,j)}
a_{ij}(t)r_{ij}(t)
+
\lambda_D D(t)
+
\lambda_U U(t),
\]
其中：

\[
a_i(t)
\]
表示第 $i$ 个 Agent-CSO 当前进入显式工作状态的激活权重；

\[
c_i(t)
\]
表示其显式处理代价；

\[
a_{ij}(t)r_{ij}(t)
\]
表示必须被工作记忆持续维护的关系代价；

\[
D(t)
\]
表示动态更新压力；

\[
U(t)
\]
表示当前不可约不确定性。

于是容量约束写成
\[
\boxed{
\sum_i a_ic_i
+
\lambda_R\sum_{ij}a_{ij}r_{ij}
+
\lambda_D D
+
\lambda_U U
\leq
C_{\mathrm{cap}}.
}
\]

这个形式有两个重要意义。

第一，它允许我们解释为什么“相同任务”在不同阶段对工作记忆压力不同。初学阶段，大量结构需要显式激活：
\[
a_i\approx1,
\]
而熟练阶段，很多关系已经被长期结构或局部程序吸收，不再需要进入当前工作面：
\[
a_i\rightarrow0.
\]
于是虽然任务外部复杂程度没有变化，
\[
C_{\mathrm{world}}
\]
可能保持不变，但
\[
C_{\mathrm{run}}
\]
显著下降。

第二，它说明工作记忆有限定理并不要求我们定义某个绝对“任务复杂度”。本章真正关心的是：
\begin{definition*}
当前有多少结构必须在同一时间尺度上被全局显式协调。
\end{definition*}
这是一个运行态量，而不是世界固有属性。

因此，同一个外部问题可以通过不同认知组织方式产生完全不同的
\[
C_{\mathrm{run}}.
\]
这也是 AgentOS 与单纯增加 Context Window 路线的根本区别之一：我们的目标并不是无限扩大 $C_{\mathrm{cap}}$，而是同时研究如何改变认知结构的承载方式，使真正必须进入显式全局处理的
\[
C_{\mathrm{run}}
\]
尽可能小。


\section{越过容量边界后的退化：过载、干扰、遗忘与错误}
\label{sec:overload-degradation}

工作记忆容量边界的意义，只有在我们理解越界以后发生什么时才真正清楚。简单地说，系统不会在
\[
C_{\mathrm{run}}=C_{\mathrm{cap}}
\]
这一点突然“关闭”。真实认知系统更可能进入一个连续退化区：为了维持运行，它开始牺牲某些结构精度、关系一致性、更新速度和长期目标，从而表现出一系列看似不同、实际上具有共同来源的故障现象。

设容量利用率
\[
\rho_h(t)
=
\frac{
C_{\mathrm{run}}(t)
}{
C_{\mathrm{cap}}(t)
}.
\]
当
\[
\rho_h\ll1
\]
时，系统具有较大认知余量，可以容纳新的异常和反事实推理；随着
\[
\rho_h\to1,
\]
状态逐渐接近高负载区域；当
\[
\rho_h>1,
\]
则系统必须通过某种隐式或显式方式丢弃结构，否则计算和更新过程无法继续。

我们可以用一个概念性退化函数描述这一过程：
\[
P_{\mathrm{err}}
=
\sigma
\left[
k
(\rho_h-\rho_0)
\right],
\]
其中 $\sigma$ 可以取 logistic 形式，$\rho_0$ 表示错误率开始明显上升的容量利用区域。这个表达并不是声称所有 Agent 都服从 logistic 曲线，而是强调：错误率很可能并非线性增长，而是在接近结构容量边界时快速恶化。

最早出现的往往是\textbf{关系干扰}。若多个 Agent-CSO 共享相似表示或竞争相同注意资源，则其关系可能发生串扰。可以把两个活跃结构 $c_i,c_j$ 之间的干扰写成
\[
I_{ij}
=
a_i a_j
S(c_i,c_j)
Q_{ij},
\]
其中 $S$ 表示表示相似度，$Q_{ij}$ 表示资源竞争程度。总干扰为
\[
I(t)
=
\sum_{i\neq j}I_{ij}.
\]
当 $I(t)$ 增大时，系统可能出现错误绑定、变量混淆和上下文污染。

第二类现象是\textbf{选择性遗忘}。由于工作状态必须继续运行，系统开始降低某些结构的激活权重：
\[
a_i\downarrow.
\]
如果被降低的结构恰好属于边缘信息，系统仍可以保持正确；但如果早期关键约束被错误降权，就会出现“推理后半程忘记前半程要求”的现象。

第三类是\textbf{局部最优化替代全局相干}。当系统无法同时维持整个任务图时，它可能把一个大图
\[
\mathcal G_h
\]
隐式拆成若干局部子图
\[
\mathcal G_h^1,
\mathcal G_h^2,\ldots
\]
分别解决，但没有足够资源维持它们之间的全局约束。结果是每一段局部答案都看似合理，而组合之后互相冲突。

第四类是\textbf{更新滞后}。即使所有结构仍然保留，系统也可能不能及时刷新它们：
\[
\tau_{\mathrm{update}}
>
\tau_{\mathrm{environment}}.
\]
此时工作记忆中的状态越来越像过期快照，导致认知行动仍然基于已经失效的世界模型。

因此，我们可以将工作记忆超载后的退化过程概括为
\[
\boxed{
Overload
\rightarrow
Interference
\rightarrow
SelectiveSuppression
\rightarrow
CoherenceLoss
\rightarrow
DecisionError.
}
\]
这条链解释了为什么“更多信息”并不单调提高智能表现。输入信息只有在系统能够将其组织进相干结构时才有价值；一旦输入增长超过结构承载能力，额外信息反而可能降低决策可靠性。

所以，本章的容量定理不是一个关于“记忆太小”的悲观结论，而是一个关于\textbf{认知组织必须受到资源约束}的现实结论。


\section{有限容量定理的直接工程推论}
\label{sec:engineering-corollaries}

一旦接受
\[
C_{\mathrm{run}}(t)
\leq
C_{\mathrm{cap}}(t)
\]
是可靠认知运行的基本条件，我们立刻得到一系列非常强的 AgentOS 工程推论。这里我们只给出这些推论本身，而不展开后续章节中相应模块的完整实现。

第一，\textbf{不是所有输入都应该进入工作记忆。}如果任意传感器、文件、消息、工具输出和内部状态都直接写入 $h(t)$，那么系统规模越大，
\[
C_{\mathrm{run}}
\]
反而越容易增长到不可治理区域。因此必须存在某种准入机制，使
\[
WorldInformation
\not\equiv
WorkingMemoryContent.
\]
只有对当前目标、风险、异常或高层决策具有足够价值的结构，才需要被提升进入全局认知面。

第二，\textbf{重复结构必须能够被压缩。}若同一组关系长期反复出现，而每次都重新展开成大量节点和边，则工作记忆会持续浪费容量。对于稳定子图
\[
\mathcal G_{\mathrm{sub}},
\]
系统应当尽可能形成高阶表示
\[
\mathcal G_{\mathrm{sub}}
\rightarrow
C^\star,
\]
使未来只在异常时重新展开内部结构。

第三，\textbf{空间上的同时复杂度可以转换成时间上的序列复杂度。}如果问题不能在一个工作面中同时解决，则可以把原本同步维持的结构分解为时间序列：
\[
\mathcal G
\rightarrow
\{
\mathcal G_1,\mathcal G_2,\ldots,\mathcal G_k
\}.
\]
只要子问题之间保存必要的接口和状态摘要，系统就可以牺牲时间换取有限工作空间。

第四，\textbf{成熟能力不应永久占用全局认知。}如果某个闭环已经高度稳定，那么继续让其每一步进入 $h$ 相当于把局部控制问题升级成全局协调问题。因此成熟智能的一个方向应当是
\[
C_{\mathrm{explicit}}\downarrow
\]
而
\[
C_{\mathrm{competence}}\uparrow.
\]
这不是认知减少，而是结构承载方式发生变化。

第五，\textbf{系统必须保留容量裕度。}在真实环境中，异常是不可预知的。如果正常任务已经使
\[
C_{\mathrm{run}}
\approx
C_{\mathrm{cap}},
\]
那么任何突然出现的新变量都会使系统失去稳定性。因此应保持
\[
M_h(t)
=
C_{\mathrm{cap}}-C_{\mathrm{run}}
\geq
M_{\min}.
\]

第六，\textbf{认知控制必须能够预测容量趋势，而不仅检查当前负载。}若
\[
\dot C_{\mathrm{run}}(t)>0
\]
且根据预测
\[
C_{\mathrm{run}}(t+\Delta t)
>
C_{\mathrm{cap}},
\]
则系统应该在真正越界以前采取措施。这使工作记忆管理天然成为一个预测控制问题，而不是事后清理问题。

第七，\textbf{大型 Agent 的核心问题会逐渐从“有多少知识”转向“何时让什么结构进入显式全局处理”。}随着模型和外部记忆持续增长，存储容量可以远超 $h$ 的显式相干容量。因此真正稀缺的资源不再只是知识，而是
\[
\boxed{
GlobalCoherentAttention.
}
\]

这几条推论后来分别会导向准入控制、认知状态观测、运行负载治理、调度、卸载以及局部闭环等机制。然而，它们都不是任意添加的模块，而是由工作记忆有限性一步步推导出的工程必要性。这也是本章在整部 AgentOS 原理论中的位置：\textbf{先证明为什么有限，再由有限性推出整个智能资源治理体系。}


\section{为什么有限性反而催生高级智能}
\label{sec:finiteness-drives-intelligence}

最后我们讨论一个看似矛盾、实际上非常重要的问题：如果工作记忆有限是一种限制，那么为什么本书反而把它看成高级智能结构产生的重要动力？

直觉上，人们可能认为更高级的智能应该拥有越来越大的工作记忆，最终达到“所有东西同时在脑中”的状态。但从结构动力学角度看，这样的系统未必更高级。若一个系统能够依靠无限工作空间解决一切问题，它就缺少形成压缩、抽象、技能、记忆层级和外部工具的必要压力。有限资源恰恰迫使智能体发展更高级的组织方式。

我们可以用一个简单优化问题来表示这一点。设智能体希望最小化长期任务损失
\[
\mathcal J
=
\int_0^T
L_{\mathrm{task}}(t)\,dt,
\]
同时必须满足
\[
C_{\mathrm{run}}(t)
\leq
C_{\mathrm{cap}}.
\]
那么最优解不会只是不断把更多结构塞入 $h$，而会倾向于寻找某种结构变换
\[
\mathcal T:
\mathcal G_{\mathrm{problem}}
\rightarrow
\mathcal G_{\mathrm{effective}}
\]
使得
\[
C_{\mathrm{run}}
\left(
\mathcal G_{\mathrm{effective}}
\right)
<
C_{\mathrm{run}}
\left(
\mathcal G_{\mathrm{problem}}
\right)
\]
同时保持完成任务所需的关键信息。

于是自然出现几个高级智能现象。

首先是\textbf{抽象}。多个低层结构被压缩成一个高层概念：
\[
\{c_1,c_2,\ldots,c_n\}
\rightarrow
C^\star.
\]
抽象的价值之一，就是减少上层工作记忆需要显式维持的结构数量。

其次是\textbf{分层}。系统把问题分成不同时间尺度和功能位置，使高层只处理跨区域协调，局部问题留在局部闭环中。于是
\[
GlobalCognition
\]
不必承担
\[
AllDynamics.
\]

再次是\textbf{自动化}。一个初学技能需要：
\[
Perception
\rightarrow
ExplicitReasoning
\rightarrow
Action.
\]
熟练以后则可能成为：
\[
Perception
\rightarrow
LocalSkill
\rightarrow
Action.
\]
只有出现异常残差时，相关结构才重新进入显式工作面。因此：
\[
\boxed{
ThinkingLess
\neq
KnowingLess.
}
\]

第四是\textbf{外部化}。当内部显式结构不能无限增长时，智能体会把稳定结构写入语言、文字、程序、工具和环境。这也是为什么人类文明的高级认知能力并不只存在于单个大脑内部。数学符号、纸张、计算机、数据库和制度，本质上都在改变未来认知需要显式维持的结构量。

第五是\textbf{选择性注意}。有限容量迫使系统学习：
\[
WhatMustBeGlobal?
\]
以及：
\[
WhatCanStayLocal?
\]
这使“注意”不再只是信息增强，而成为跨尺度结构提升策略。

因此我们可以提出本章最深的一条推论：
\begin{statementbox}
高级智能不是消灭有限性，而是学会围绕有限性组织自身。
\end{statementbox}

从这个角度看，工作记忆有限容量并不是 AgentOS 设计中的一个次要参数，而是整个架构产生的根本压力源。正因为全局显式认知是有限的，系统才必须形成记忆分层、结构压缩、局部闭环、外部工具、长期技能与多尺度组织。换言之，有限性不是智能的反面，它反而构成了智能不断产生更高阶组织结构的选择压力。

于是，我们可以用下面这一组关系结束本章：
\[
\boxed{
FiniteWorkingMemory
\Rightarrow
SelectiveAttention
\Rightarrow
Abstraction
\Rightarrow
Hierarchy
\Rightarrow
Automation
\Rightarrow
Externalization
}
\]
其最终意义不是说每一种高级智能特征都只能由工作记忆有限性产生，而是指出：\textbf{一旦一个持续智能体必须在有限全局相干容量下长期生存，它就会受到强烈压力，去寻找能够减少当前显式结构负担的认知组织方式。}

这正是 AgentOS 后续原理展开的逻辑起点。下一章我们将不再把 $h(t)$ 仅仅视为一个有限容器，而进一步研究它为什么会成为连接世界、记忆、自我、任务和行动的\textbf{认知总线}。
