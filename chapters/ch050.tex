\chapter{Body Scale 原理：身体可迁移性与智能能力扩张}

\begin{center}
\fbox{
\parbox{0.92\textwidth}{
\textbf{【本章总体说明】}

本章研究一个在传统人工智能理论中经常被参数规模遮蔽的问题：一个智能体的“规模”究竟应当如何度量？如果我们把智能理解为一个持续存在、通过观测与行动同现实形成闭环的动力学主体，那么参数数量、上下文长度和推理算力都只能描述其内部计算资源，而不能充分描述这个智能体能够进入多大范围的现实、能够迁移到多少种身体、能够以多低的代价建立新的感知--预测--控制闭环。

本章因此提出 \textbf{Body Scale} 概念。Body Scale 不是身体尺寸、自由度数量或者传感器数量，而是一个已有智能主体在更换、扩展或重新组合身体以后，其既有认知结构能够在多大程度上继续有效工作的能力。我们把这种能力分解为四个相互联系而又不能相互替代的维度：
\[
\boxed{
BodyScale
=
PerceptualTransfer
+
FeelingTransfer
+
PredictiveTransfer
+
ControlTransfer
}
\]
更严格地说，Body Scale 应被理解为一个关于身体变换的结构保持量：当身体从 $B_i$ 迁移到 $B_j$ 时，智能体原有的 Agent-CSO、世界关系、自我结构、预测能力和行动目的，有多少可以通过有限重新接地而继续成立，而不必重新训练一个新的智能主体。

因此，本章的基本判断是：
\[
\boxed{
\text{一个真正通用的智能体，不仅应当能够学习一个身体，
还应当能够跨身体保存其智能。}
}
\]
这一原则构成后续统一身体接口、语义世界表示、快速身体闭环以及 Kernel--Body 适配机制的理论前提。
}
}

\section{Body Scale 的第一性定义：智能规模不能只由参数规模决定}

我们首先必须重新审视“智能规模”这一常用但含义模糊的概念。当前人工智能系统通常使用参数量、训练数据量、计算量、上下文长度或者推理吞吐量描述模型规模，这些指标当然具有重要工程意义，但它们本质上测量的是一个计算模型内部可以储存、拟合或者临时处理多少结构，而不是一个持续智能主体可以和多大范围、多种形态的现实建立有效闭环。如果一个拥有极大参数量的系统只能通过固定文本接口存在，那么它虽然拥有很大的内部表征容量，却仍可能拥有极窄的现实作用边界。相反，一个参数量并不极大的智能体，如果能够稳定迁移于浏览器、桌面系统、机器人机械臂、车辆乃至新的传感器--执行器组合之间，其实际可作用世界可能远大于前者。因此，在 AgentOS 的认识框架中，我们必须把 Model Scale 与 Body Scale 分开。

我们把一个身体记为
\[
B=
\left(
\mathcal O_B,
\mathcal A_B,
\mathcal X_B,
\mathcal D_B,
\mathcal C_B
\right),
\]
其中 $\mathcal O_B$ 表示该身体能够获得的观测空间，$\mathcal A_B$ 表示其行动空间，$\mathcal X_B$ 表示身体自身的内部状态空间，$\mathcal D_B$ 表示身体与环境之间的局部动力学，而 $\mathcal C_B$ 表示身体能够承受的物理、逻辑与安全约束。这样定义以后，我们便能够看到：所谓“换身体”，并不是简单更换一个输入设备和一个输出设备，而是整体改变
\[
Observation,\quad Action,\quad Dynamics,\quad Constraint
\]
四个方面。一个轮式机器人无法直接使用双足行走策略，一个数字 Agent 不存在物理温度但存在 CPU、内存、网络和权限状态，一个机械臂能够接触现实对象却没有浏览器原生的 DOM 操作能力。不同身体所暴露的原始状态空间可能高度异构。

然而，一个真正持续存在的 Agent 不应该因为这些差异而每次重新成为另一个主体。如果同一 Agent 从数字桌面迁移到机械臂，其关于“容器”“目标”“阻碍”“距离”“资源”“任务完成”“风险”“自己能够或不能够做什么”的大量结构理应继续成立。发生变化的应主要是这些结构如何被新的身体重新接地，而不是主体从零重新形成世界观。因此，我们定义身体迁移
\[
T_{ij}: B_i\rightarrow B_j,
\]
并进一步关心 Agent 内部某一认知结构集合 $\mathcal C_A$ 在这一变换下能够保持多少功能关系。

设智能体在身体 $B_i$ 上已经形成认知结构
\[
\mathcal G_A^{(i)}
=
(V_A^{(i)},E_A^{(i)}),
\]
迁移至 $B_j$ 后形成
\[
\mathcal G_A^{(j)}.
\]
Body Scale 真正关注的不是
\[
\mathcal G_A^{(i)}
=
\mathcal G_A^{(j)},
\]
因为不同身体必然要求不同的底层表示，而是是否存在映射
\[
\Phi_{ij}:
\mathcal G_A^{(i)}
\rightarrow
\mathcal G_A^{(j)}
\]
能够在足够大的结构子集上保持任务相关语义、预测关系与控制意义。换句话说，Body Scale 测量的是\textbf{身体发生变化时，智能结构能够保持多少，而不是身体能够塞进多少传感器。}

因此可以给出本章的第一性定义：
\[
\boxed{
BodyScale(A)
=
\text{Agent }A\text{ 在身体变化下保持认知与行动结构连续性的能力}
}
\]
它本质上是一种跨身体泛化能力，也是一种特殊的 Agent-CSO 承载迁移能力。参数规模描述“智能体内部能够装多少”，Body Scale 描述“智能体能够进入多少不同的现实闭环而仍然保持自己”。对于追求长期存在和通用性的 AgentOS，后者具有与参数规模完全不同、甚至在某些阶段更加根本的意义。


\section{Perceptual Transfer：不同身体如何继续看见同一个世界}

Body Scale 的第一个维度是 Perceptual Transfer，即感知迁移能力。感知迁移所要解决的不是“能否读取新传感器数据”这种较低层工程问题，而是：当同一个现实结构通过完全不同的传感器和身体坐标进入 Agent 时，智能体能否继续把它识别为具有相近意义的 Agent-CSO。例如，一个桌面 Agent 通过 DOM、像素、文本和鼠标坐标观察一个按钮；一个物理机器人通过 RGB-D、力觉和空间坐标观察一个机械按钮。二者的原始观测空间
\[
\mathcal O_{digital}
\neq
\mathcal O_{physical},
\]
但在更高层认知结构上都可能形成
\[
CSO_{\text{button}},
\]
以及诸如
\[
Pressable,\quad StateChanging,\quad GoalRelevant
\]
等关系。如果新的身体要求智能体重新学习“按钮是什么”，则说明其感知结构仍深度绑定于原始通道，而没有形成真正可迁移的世界语义。

因此我们可以把身体 $B$ 的感知过程抽象成
\[
O_B:
\mathcal U
\rightarrow
\mathcal Z_B
\rightarrow
\mathcal R_A,
\]
其中 $\mathcal U$ 是现实结构，$\mathcal Z_B$ 是身体特有的传感与低层表示空间，$\mathcal R_A$ 则是 Agent 能够使用的较高层结构空间。身体迁移的目标并不是要求
\[
\mathcal Z_{B_i}
=
\mathcal Z_{B_j},
\]
这是不必要甚至不可能的；真正需要保持的是，在两个不同身体中存在
\[
\Gamma_i:\mathcal Z_{B_i}\rightarrow\mathcal R_A,
\qquad
\Gamma_j:\mathcal Z_{B_j}\rightarrow\mathcal R_A,
\]
使相同或等价的现实结构最终能够落入相近的 Agent-CSO 邻域。

如果现实对象为 $C\in\mathcal U$，我们可以写
\[
r_i(C)
=
\Gamma_i(O_{B_i}(C)),
\]
\[
r_j(C)
=
\Gamma_j(O_{B_j}(C)).
\]
理想的感知迁移并不要求
\[
r_i(C)=r_j(C),
\]
而只要求在任务相关意义上满足
\[
d_{\mathrm{sem}}
\left(
r_i(C),
r_j(C)
\right)
<
\epsilon_P,
\]
其中 $d_{\mathrm{sem}}$ 是认知语义距离，$\epsilon_P$ 是能够维持功能等价的容许误差。这体现了我们在前文确立的原则：
\[
\boxed{
FunctionalEquivalence
>
RepresentationalIdentity
}
\]

我们进而定义感知迁移系数
\[
\eta_P(B_i,B_j)
=
\frac{
\left|
\mathcal C_{\mathrm{percept}}^{\,transfer}
\right|
}{
\left|
\mathcal C_{\mathrm{percept}}^{\,relevant}
\right|
},
\qquad
0\leq \eta_P\leq 1.
\]
分子表示换身体以后不需要从零重学、只需重新接地即可继续工作的感知相关认知结构；分母表示目标任务所需要的全部相关结构。$\eta_P$ 越高，说明 Agent 的认知世界越独立于具体传感器。

这里尤其需要避免一种误解：感知迁移不是追求“身体无关”。任何真实 Agent 都必须被身体限定，身体决定它能够测到什么、分辨到什么、以什么噪声测到以及什么现实结构对它而言可达。因此 Body Scale 追求的不是消灭具身差异，而是把差异限制在尽可能靠近身体的一侧，让已经稳定形成的世界语义在更高层继续成立。身体不同，但“障碍”“容器”“可抓取”“权限受限”“目标已完成”等关系不应每次重新发明。

从这个角度看，感知迁移实际上是一个\textbf{从身体特定坐标系向主体稳定语义空间的重新接地问题}。后续具体的语义世界接口会进一步处理这种映射，但本章只需要确立这一原则：Body Scale 的第一步不是让 Agent 拥有更多传感器，而是让新的传感器能够进入原有世界模型，而不摧毁原有世界模型。


\section{Feeling Transfer：不同身体如何保持“这正在怎样影响我”的连续性}

如果只有感知迁移，Agent 仍然可能在更换身体时失去重要的主体连续性。原因在于，世界不仅以“是什么”的形式进入智能体，还以“正在怎样作用于我”的形式影响智能体。对于生物身体，这种影响可能表现为能量不足、受损、温度失衡、疼痛、威胁和运动疲劳；对于数字身体，则可能表现为算力饱和、内存压力、网络延迟、权限受限、工具不可用、任务队列阻塞或资源预算耗尽。原始物理量完全不同，但它们可能在 Agent 的功能动力学中承担相似作用。

因此，我们将 Body Scale 的第二个维度定义为 Feeling Transfer。这里的 Feeling 必须严格使用功能意义，而不能直接等同于人类主观体验。我们关心的是一个身体状态如何形成对 Agent 行动、资源分配和风险控制具有实际因果作用的调制状态。

令身体内部状态为
\[
x_B(t)\in\mathcal X_B.
\]
身体状态通过某个映射
\[
F_B:
\mathcal X_B
\rightarrow
\mathcal Y_A
\]
形成 Agent 可使用的影响状态 $\mathcal Y_A$。例如，机器人剩余电量
\[
E_{\mathrm{battery}}=12\%
\]
和服务器可用算力
\[
C_{\mathrm{free}}=8\%
\]
从物理意义看完全不是同一变量，但二者都可能映射为一种
\[
ResourcePressure\uparrow
\]
的功能状态，从而引起保守行动、降低探索和优先寻找补充资源。因此我们更关心的是：
\[
F_{B_i}(x_i)
\sim
F_{B_j}(x_j)
\]
是否在控制意义上等价，而不是底层量纲是否一致。

可以定义两个身体之间的功能影响映射
\[
\Xi_{ij}:
\mathcal Y_i\rightarrow\mathcal Y_j.
\]
如果对于一类关键身体状态 $x_i$ 和对应状态 $x_j$，满足
\[
\left\|
u_A(F_{B_i}(x_i))
-
u_A(F_{B_j}(x_j))
\right\|
<
\epsilon_F,
\]
则意味着虽然身体状态不同，但它们对 Agent 高层控制产生了近似等价的影响，其中 $u_A$ 表示 Agent 根据身体影响状态形成的高层调制响应。

由此可以定义
\[
\eta_F(B_i,B_j)
=
1-
\frac{
D_{\mathrm{functional}}
(F_{B_i},F_{B_j})
}{
D_{\max}
},
\]
其中 $D_{\mathrm{functional}}$ 衡量两个身体影响映射在 Agent 决策上的功能差异。$\eta_F$ 越高，意味着 Agent 换身体以后能够更快理解“什么状态意味着危险”“什么状态意味着资源不足”“什么状态意味着执行不稳定”，而无需重新建立整套自我调节逻辑。

这一步对于身份连续性具有比表面上更深的意义。如果不同身体都把原始状态直接送入高层认知，那么 Agent 的自我模型将不可避免地绑定到具体硬件：换身体就等于重新定义“疲劳”“受损”“能力下降”“资源不足”。而如果身体差异首先被转换为稳定的功能作用空间，那么 Agent 可以保存更一般的自我结构：
\[
\boxed{
\text{我处于资源不足状态}
}
\]
而不是必须保存：
\[
\boxed{
\text{我的锂电池电压为某个固定数值}
}
\]
前者可以跨身体迁移，后者只能绑定某个硬件。

因此 Feeling Transfer 本质上是\textbf{身体内状态意义的迁移}。Perceptual Transfer 让不同身体继续看到“同一个世界”，Feeling Transfer 则让不同身体继续维持“这个世界与这个身体正在怎样影响我”的功能连续性。二者共同构成一个持续主体跨身体存在的基本条件。


\section{Predictive Transfer：已有世界模型能否迁移到新的身体动力学}

感知和影响结构能够迁移，并不意味着 Agent 已经真正适应了新身体。智能行动还有第三个不可缺少的成分：预测。任何有效行动都隐含一个最小形式的未来模型，即如果我采取动作 $a$，世界和身体可能如何变化。因此，一个 Agent 从身体 $B_i$ 迁移到 $B_j$ 时，不仅需要重新识别现实，还必须知道旧有预测模型中哪些部分仍然有效，哪些部分必须局部重学。

我们把 Agent 的预测模型写成
\[
\hat{x}_{t+\Delta}
=
P_A
\left(
x_t,
a_t,
B
\right).
\]
其中 $x_t$ 包含当前相关世界结构和主体状态，$a_t$ 是行动，而 $B$ 表示身体条件。这里必须明确区分两类预测结构。第一类是世界规律，它们对身体相对稳定，例如“物体不会因为我改变身体而突然失去持续性”“容器仍然能够容纳对象”“未获得权限的系统资源仍然不可直接访问”。第二类则是身体依赖动力学，例如机械臂在某力矩下会移动多快、鼠标移动多少像素对应怎样的屏幕位移、车辆在当前速度下需要多长制动距离。

因此可以进行分解：
\[
P_A
=
P_{\mathrm{world}}
\circ
P_{\mathrm{body}},
\]
其中
\[
P_{\mathrm{world}}
\]
尽可能保存已经形成的世界级结构，
\[
P_{\mathrm{body}}
\]
则适应不同身体的局部动力学。严格地说二者不会完全独立，但这种分解为工程设计提供了极其重要的方向：\textbf{换身体时重新学习局部动力学，而不要重新学习整个世界。}

设 Agent 在身体 $B_i$ 中形成预测结构集合
\[
\Theta_P^{(i)}
=
\Theta_{\mathrm{world}}
\cup
\Theta_{\mathrm{body}}^{(i)}.
\]
迁移到 $B_j$ 后：
\[
\Theta_P^{(j)}
=
\Theta_{\mathrm{world}}'
\cup
\Theta_{\mathrm{body}}^{(j)}.
\]
理想情况下应满足
\[
D
\left(
\Theta_{\mathrm{world}},
\Theta_{\mathrm{world}}'
\right)
\ll
D
\left(
\Theta_{\mathrm{body}}^{(i)},
\Theta_{\mathrm{body}}^{(j)}
\right),
\]
即世界模型只发生局部修正，而身体模型承担主要适配负担。

由此可以定义预测迁移率
\[
\eta_{\mathrm{Pred}}
=
\frac{
I
\left(
\Theta_P^{(i)};
\Theta_P^{(j)}
\right)
}{
H
\left(
\Theta_P^{(j)}
\right)
},
\]
其直观含义是新身体所需要的有效预测结构中，有多少能够由旧身体上的知识直接贡献。这里的信息量符号只用于形式表达，实际工程测量可以使用预测误差下降速度、样本效率或者重新训练量代替。

我们还可以引入迁移后的残差：
\[
\varepsilon_{ij}(t)
=
x_{t+\Delta}^{obs}
-
\hat{x}_{t+\Delta}^{(i\rightarrow j)}.
\]
一个 Body Scale 较高的系统，不要求迁移后残差立即为零，但要求：
\[
\frac{d}{dt}
\|\varepsilon_{ij}(t)\|
<0
\]
并且达到目标精度所需的新经验量显著低于从零学习：
\[
N_{adapt}^{i\rightarrow j}
\ll
N_{learn}^{scratch}.
\]

这说明 Predictive Transfer 的关键指标不是“第一次就会”，而是\textbf{是否能够利用已有结构快速学会新身体}。真正的身体通用性从来不意味着先验完美适配一切硬件，而意味着旧经验已经把问题压缩成一个较小的接地问题。对于持续智能体而言，这一点至关重要，因为智能生命周期越长，其已经积累的世界结构越丰富。如果每次身体升级都迫使它重置这些结构，那么所谓长期学习就会被身体变化反复打断。因此，预测迁移是 Body Scale 从“统一接口”进入“持续智能”的关键桥梁。


\section{Control Transfer：目标不变时，动作结构能否跨身体重新实现}

Body Scale 的第四个维度是 Control Transfer。它比感知迁移更加接近行动端，其核心问题可以用一句话概括：\textbf{同一个高层意图，能否被新的身体重新实现，而不要求认知核心重新学习所有低层动作细节？}

假设 Agent 想实现目标
\[
g\in\mathcal G.
\]
不同身体具有不同控制空间：
\[
\mathcal A_{B_i}
\neq
\mathcal A_{B_j}.
\]
例如“把文件移动到指定位置”，对于数字身体可能意味着文件系统调用；“把物体移动到指定位置”，对于机械臂则需要运动规划、逆运动学和力控制。二者底层动作完全不同，但从 Agent-CSO 的层面看都可能对应：
\[
Move(Object,Source,Target).
\]
因此控制迁移的目标是建立从稳定意图空间 $\mathcal G_A$ 到身体特定动作空间的映射：
\[
\Pi_B:
\mathcal G_A
\times
\mathcal X_B
\rightarrow
\mathcal A_B.
\]

如果 Agent 的高层策略直接输出身体底层动作：
\[
\pi_A:
h_t\rightarrow a_t^{raw},
\]
则身体与认知被紧密绑定。一旦更换身体，整个高层策略都可能失效。相反，更合理的结构是：
\[
\pi_A:
h_t
\rightarrow
r_t,
\]
其中 $r_t$ 是较稳定的控制意图或控制参考，再由身体侧实现
\[
\pi_B:
(r_t,x_B)
\rightarrow
a_t.
\]
这样，高层只表达“需要达到什么状态、满足什么约束、允许什么误差”，而身体负责解决“这个身体具体怎样做到”。

我们可以把这种结构写成：
\[
AgentIntent
\rightarrow
ControlReference
\rightarrow
BodySpecificControl
\rightarrow
Reality.
\]
虽然具体 ControlReference 的规范将在后续章节展开，本章需要先明确它的理论作用：它是 Control Transfer 的核心断点，把高层语义控制和低层执行自由度分开。

定义任务集合 $\mathcal T$，若身体 $B_i$ 与 $B_j$ 都能够执行其中一部分任务，可以定义控制迁移率：
\[
\eta_C(B_i,B_j)
=
\frac{
\sum_{T\in\mathcal T}
w_T
\,
\mathbf 1
\left[
\pi_A^{(i)}
\text{ 可经有限适配迁移到 }
B_j
\right]
}{
\sum_{T\in\mathcal T} w_T
}.
\]
更细致地，我们可以使用适配成本：
\[
Cost_C^{i\rightarrow j}
=
\alpha N_{\mathrm{demo}}
+
\beta T_{\mathrm{adapt}}
+
\gamma \Delta\Theta_A
+
\delta Risk_{\mathrm{adapt}},
\]
其中 $N_{\mathrm{demo}}$ 为需要新增的示范或训练样本，$T_{\mathrm{adapt}}$ 为适配时间，$\Delta\Theta_A$ 表示高层认知结构必须修改的程度，$Risk_{\mathrm{adapt}}$ 则表示适配过程的风险。理想 Body Scale 应最小化：
\[
\Delta\Theta_A,
\]
也就是让身体变化尽量由身体侧吸收，而不是扰动 Agent 长期认知结构。

这里再次体现了“异常向上、能力向下”的多尺度原则。正常熟练动作应由身体局部闭环处理；只有当动作无法完成、环境异常或残差长期无法消除时，问题才重新上升到高层认知。这样一来，Control Transfer 就不仅是“换一个 actuator adapter”，而是建立一个多尺度控制架构：高层目标保持相对稳定，身体层具有执行自治，现实残差决定何时需要重新认知。

因此 Control Transfer 实际上是 Body Scale 中最接近“能否真正换身体”的判据。感知迁移让 Agent 能够理解新身体看到的世界，Feeling Transfer 让 Agent 理解新身体正在经历什么，Predictive Transfer 让 Agent 能够预测新身体如何运动，而 Control Transfer 最终回答：\textbf{这个主体是否还能通过新身体继续做原来想做的事。}


\section{Body Scale 的统一数学表述：从四个迁移率到身体可扩展域}

前四节分别讨论了 Perceptual、Feeling、Predictive 和 Control Transfer，但 Body Scale 不能简单理解为四个独立分数的机械相加。四者之间存在明显的串联与瓶颈效应。例如，如果感知迁移率极高而控制迁移率接近零，Agent 可能能够理解新身体所看到的世界，却几乎不能有效行动；如果控制接口统一但 Feeling Transfer 很差，Agent 又可能无法正确评估资源、损伤与风险，最终使行为失去主体连续性。因此，更合理的 Body Scale 应被表示成一个多维向量：

\[
\mathbf S_B(A;B_i\rightarrow B_j)
=
\begin{bmatrix}
\eta_P\\
\eta_F\\
\eta_{\mathrm{Pred}}\\
\eta_C
\end{bmatrix}.
\]

其中：
\[
\eta_P
=
PerceptualTransfer,
\]
\[
\eta_F
=
FeelingTransfer,
\]
\[
\eta_{\mathrm{Pred}}
=
PredictiveTransfer,
\]
\[
\eta_C
=
ControlTransfer.
\]

如果为了工程比较需要一个标量，可以构造加权几何平均：
\[
BS_{ij}
=
\prod_{k\in\{P,F,Pred,C\}}
\eta_k^{w_k},
\qquad
\sum_k w_k=1.
\]
我们使用几何平均而不是简单算术平均，是因为它自然体现瓶颈效应：任何一个维度接近零，整体 Body Scale 都会受到显著限制。例如：
\[
\eta_C\rightarrow0
\Rightarrow
BS_{ij}\rightarrow0.
\]

然而，单一身体对之间的迁移能力仍不足以定义一个 Agent 的总体 Body Scale。真正重要的是智能体能够覆盖多少身体族。设可能身体空间为
\[
\mathfrak B
=
\{B_1,B_2,\dots\},
\]
对于给定最小可接受迁移质量 $\theta_B$，定义 Agent 的身体可扩展域：
\[
\mathfrak B_A(\theta_B)
=
\left\{
B_j\in\mathfrak B
\mid
BS(A;B_{base}\rightarrow B_j)
\geq\theta_B
\right\}.
\]
那么可以定义：
\[
\boxed{
BodyScale(A;\theta_B)
=
\mu
\left(
\mathfrak B_A(\theta_B)
\right),
}
\]
其中 $\mu$ 不是简单计数，而可以根据身体类型空间定义某种覆盖度测度。这样，一个 Agent 能够迁移到一百个几乎完全相同的机械臂，并不一定比能够迁移到浏览器、车辆、轮式机器人和机械臂四种高度异构身体具有更大的 Body Scale。

进一步，我们可以定义身体之间的距离：
\[
d_B(B_i,B_j)
=
\lambda_O d_O
+
\lambda_A d_A
+
\lambda_D d_D
+
\lambda_C d_C,
\]
分别衡量观测空间、行动空间、动力学和约束差异。一个真正具有高 Body Scale 的智能体应表现为：即使
\[
d_B(B_i,B_j)
\]
较大，其适配成本增长仍相对缓慢。可以定义 Body Scale 的一个更深刻指标：
\[
\kappa_B
=
-
\frac{
\partial Cost_{adapt}
}{
\partial d_B
}.
\]
直观而言，我们关心的是“身体差异每增加一单位，需要付出多少额外认知重构成本”。

从 CSO 理论看，这个数学结构还有一个更本体化的解释。设 Agent 已经拥有 Agent-CSO 集合
\[
\mathcal C_A,
\]
身体 $B$ 实际承载的是其中一部分与身体直接有关的映射：
\[
\mu_B:
\mathcal C_A
\rightarrow
\mathcal F_B.
\]
换身体并不意味着：
\[
\mathcal C_A
\rightarrow
\mathcal C_A',
\]
全部重写，而更希望主要发生：
\[
\mu_{B_i}
\rightarrow
\mu_{B_j}.
\]
因此高 Body Scale 的实质可以浓缩为：
\[
\boxed{
\text{改变承载映射，而尽量保存认知本体。}
}
\]

这也让 Body Scale 与前文的 CSO Migration 理论实现了自然连接：身体迁移是 Agent-CSO 承载迁移的一种特殊形式，但它要求同时完成感知、主体影响、预测和控制四种意义的重新接地。如果这四类映射可以被标准化并快速学习，那么身体就不再是 Agent 的一次性硬编码外壳，而成为可以更换、扩展和成长的运行载体。


\section{Known Meaning + New Body Grounding：新身体学习不应等于重新学习世界}

现在我们可以讨论 Body Scale 最具有工程价值的原则之一：
\[
\boxed{
KnownMeaning+NewBodyGrounding
}
\]
也就是说，当一个已经长期运行的 Agent 获得新身体时，它最应该重新学习的是“新身体如何连接已经知道的意义”，而不是从头重学所有意义本身。

假设 Agent 已经知道对象 $C$ 具有结构：
\[
AgentCSO(C)
=
\{
Identity,
Relation,
Affordance,
Risk,
GoalRelevance
\}.
\]
获得新身体以后，真正未知的可能只是：
\[
HowToObserve_B(C),
\]
\[
HowToReach_B(C),
\]
\[
HowToManipulate_B(C),
\]
以及：
\[
HowCChangesWhenActedBy_B.
\]
因此适配问题可以分解为：
\[
\boxed{
SemanticPrior
+
EmbodimentIdentification
}
\]
而不是：
\[
\boxed{
WorldLearningFromScratch.
}
\]

从贝叶斯角度，我们可以把旧 Agent 的知识写成先验：
\[
p(\mathcal W\mid H_A),
\]
其中 $H_A$ 表示 Agent 的历史经验。新身体带来的数据为
\[
D_{B_j}.
\]
理想适配是：
\[
p(\mathcal W,\mathcal D_{B_j}
\mid
H_A,D_{B_j}),
\]
其中世界结构 $\mathcal W$ 的大量先验应被保留，主要更新身体动力学部分：
\[
p(\mathcal D_{B_j}\mid D_{B_j}).
\]
如果系统因为换身体而重新初始化：
\[
p(\mathcal W)\approx p_0(\mathcal W),
\]
那么长期生命周期中的大量认知积累就被浪费。

这一原则也可以用样本复杂度表达。设从零学习新身体任务需要：
\[
N_{\mathrm{scratch}}(\epsilon)
\]
个样本达到误差 $\epsilon$；利用旧有 Agent-CSO 进行新身体接地只需要：
\[
N_{\mathrm{ground}}(\epsilon).
\]
则我们希望：
\[
\boxed{
N_{\mathrm{ground}}(\epsilon)
\ll
N_{\mathrm{scratch}}(\epsilon)
}
\]
并进一步定义迁移收益：
\[
G_B(\epsilon)
=
1-
\frac{
N_{\mathrm{ground}}(\epsilon)
}{
N_{\mathrm{scratch}}(\epsilon)
}.
\]
若 $G_B$ 接近 1，说明旧有认知结构显著降低了新身体适配成本。

但是我们还必须防止“旧意义”错误压制新身体带来的新事实。比如一个只能在二维屏幕中行动的数字 Agent，进入三维物理身体后会遇到惯性、摩擦、遮挡、能量消耗、损伤和不可逆动作等新的结构。如果把旧世界模型强行投射到新身体，就可能产生严重负迁移。因此 Known Meaning + New Body Grounding 不是冻结旧结构，而是采用分层更新：
\[
\Theta_{\mathrm{stable}}
\quad \text{尽量保持},
\]
\[
\Theta_{\mathrm{body}}
\quad \text{快速适配},
\]
\[
\Theta_{\mathrm{world}}
\quad \text{在持续残差下缓慢修正}.
\]
即满足：
\[
\tau_{\mathrm{body-adapt}}
<
\tau_{\mathrm{world-revision}}.
\]

这与整本书的慢变量保护原则是一致的：新的局部经验首先应修改局部映射；只有当残差持续存在，并表明原有世界结构本身已经不足时，才逐步上升到更慢、更广泛的结构修正。Body Scale 因此不仅是迁移能力，更是一种\textbf{结构保护机制}。它让 Agent 可以大胆进入新身体，却不必每次冒着破坏长期自我和世界模型的风险。

从作者的视角看，这一点尤其重要。未来真正长期存在的 Agent 很可能会经历多次身体升级：新的摄像头、新的执行器、新的数字环境、新的机器人平台甚至完全不同形态的载体。如果每次升级都意味着重新训练“另一个 AI”，那么我们得到的只是不断更换模型的产品系列，而不是一个持续成长的主体。只有当：
\[
\boxed{
BodyChanges,\quad AgentContinuityRemains
}
\]
成立时，“同一个 Agent 换了身体”才从语言比喻变成可工程定义的事实。


\section{为什么 Body Scale 可能比单纯参数规模更接近通用性的工程指标}

本章最后需要回答一个较强的判断：为什么我们认为，对于长期通用智能系统而言，Body Scale 在某些发展阶段可能比单纯的 Parameter Scale 更值得重视。这里绝不是否定模型规模。没有足够的表示、推理和世界知识容量，Agent 无法完成复杂认知。然而参数规模主要提高的是一个既定计算系统内部的表达能力，而 Body Scale 提高的是\textbf{这个智能主体能够把已有认知投射到多少种现实载体上的能力}。二者作用方向不同。

我们可以把 Agent 的有效能力写成一个非常粗略的乘积：
\[
Capability_{effective}
=
C_{cognitive}
\cdot
C_{body}
\cdot
C_{coupling},
\]
其中 $C_{cognitive}$ 表示内部认知能力，$C_{body}$ 表示身体可达到的现实状态空间，$C_{coupling}$ 表示二者之间的迁移与适配效率。如果模型极强，但：
\[
C_{coupling}\rightarrow0,
\]
那么 Agent 的能力仍被困在一个极窄接口中。反过来，如果身体接口高度统一，既有认知可以快速迁移，那么同一个智能核心就可能覆盖越来越大的行动空间。

从“可解决问题空间”的角度，可以定义：
\[
\mathcal P_A
=
\bigcup_{B\in\mathfrak B_A}
\mathcal P(A,B),
\]
其中 $\mathcal P(A,B)$ 表示 Agent $A$ 通过身体 $B$ 能够进入的问题集合。模型规模增加通常扩大单个
\[
\mathcal P(A,B)
\]
内部的解决能力；Body Scale 增加则扩大可用身体集合：
\[
\mathfrak B_A.
\]
因此：
\[
BodyScale\uparrow
\Rightarrow
\left|
\bigcup_B \mathcal P(A,B)
\right|
\uparrow.
\]
这是一种完全不同的扩张路径。

更重要的是，Body Scale 与长期学习具有乘法关系。一个 Agent 在几十年生命周期中积累的
\[
E,\Theta,\Psi
\]
如果只能服务于一具固定身体，那么这些结构的现实价值受身体寿命和功能上限限制。若它们可以跨身体保持，则每次新身体都不是从零开始，而是继承此前认知资本：
\[
Experience_{past}
\rightarrow
NewBodyCapability.
\]
于是生命周期能力呈现的是累积而不是重置：
\[
Capability_{t+1}
=
Capability_t
+
BodySpecificLearning,
\]
而不是：
\[
Capability_{t+1}
\approx
Capability_{\mathrm{scratch}}.
\]

我们甚至可以定义一个身体扩展效率：
\[
E_{BS}
=
\frac{
\Delta |\mathcal P_A|
}{
Cost_{new-body}
}.
\]
高 Body Scale 系统增加一种新身体以后，能够以较小认知改造成本获得很大的新问题空间；低 Body Scale 系统则需要为每种身体开发几乎独立的模型。因此从系统经济性上，高 Body Scale 具有明显的平台效应。

这里也解释了为什么 Agent Body 的标准化比表面上的接口工程更深。真正应该统一的并不是所有身体底层状态，而是那些能够让高层 Agent-CSO 保持意义连续的边界。我们希望实现：
\[
\boxed{
DifferentBodies,
StableSemanticContract,
AdaptiveLocalDynamics
}
\]
而不是：
\[
\boxed{
DifferentBodies,
DifferentAgents.
}
\]

因此，本章最终给出 Body Scale 原理：

\[
\boxed{
\textbf{
Body Scale 是一个持续智能体跨不同感知、内态、预测和控制载体保持认知结构连续，并以有限重新接地成本扩展其现实作用范围的能力。
}
}
\]

它可以进一步分解为：
\[
\boxed{
\mathbf S_B
=
(
\eta_P,
\eta_F,
\eta_{\mathrm{Pred}},
\eta_C
)
}
\]
并通过身体可扩展域
\[
\mathfrak B_A(\theta_B)
\]
描述一个 Agent 能够稳定进入多少类异构现实载体。

由此我们得到本章最重要的工程判断：

\[
\boxed{
\textbf{
通用智能的规模，不应只由“一个模型内部拥有多少结构”衡量，
还必须由“这些结构能够跨多少种身体继续成为有效结构”衡量。
}
}
\]

参数规模扩大的是认知内部空间，Body Scale 扩大的是智能与现实之间的闭环空间。前者让 Agent 能够理解更复杂的问题，后者让同一个 Agent 能够进入更多世界、拥有更多行动方式，并在身体改变以后继续携带自己的历史。对于一个真正追求生命周期连续性的 AgentOS，这种能力不是附属功能，而是从“模型”走向“持续人工智能生命体”的必要条件。
