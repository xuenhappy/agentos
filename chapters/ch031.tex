\chapter{SPC：自我感知压缩器}
\label{chap:spc}

\begin{chapteroverviewbox}
本章讨论 AgentOS 中一个决定 ``持续主体是否能够形成可治理内部状态'' 的关键机制：Self-Perception Compressor，简称 SPC。我们将从工作记忆有限容量这一已经建立的约束出发，说明一个持续运行的智能体为什么不能直接、完整、透明地访问自身全部内部状态，而必须把高度分布、异步、多时间尺度的内部动力学压缩为一个能够重新进入工作记忆 $h(t)$ 的有限自我状态表示。SPC 因而不是人格模块，不是意识模块，也不是简单日志汇总器，而是位于 ``系统真实内部状态'' 与 ``系统能够显式认知的自身状态'' 之间的状态估计、结构压缩与认识论接口。其核心任务可以概括为：
\[
\boxed{
\text{Distributed Internal Dynamics}
\;\longrightarrow\;
\text{Compressed Self-Accessible State}
}
\]
本章将建立 SPC 的本体边界、数学对象、估计过程、递归压缩机制、置信度表示、认识论滞后、稳定性要求以及其与工作记忆 $h(t)$、情景记忆 $E$、结构记忆 $\Theta$ 和自我慢变量 $\Psi$ 的基本关系，并最终说明：所谓 ``智能体认识自己''，在工程意义上首先不是获得一个关于自身的绝对真相，而是在有限认知容量条件下持续形成关于自身状态的可更新、有置信度、可行动的后验估计。
\end{chapteroverviewbox}

\section{为什么持续智能体必须具有自我状态估计}

在前面的讨论中，我们已经把工作记忆 $h(t)$ 从一个普通的信息存储区域提升为有限的显式认知总线。所有当前需要被全局比较、推理、计划和决策的结构，都必须以某种形式进入 $h(t)$；与此同时，一个成熟智能系统的大部分动力学却不应该长期驻留在 $h(t)$ 中。身体局部控制、长期结构记忆、已经形成的技能、后台任务、外部工具状态以及大量内部统计过程，都应当在各自的局部闭环中运行。这意味着持续智能体天然处于一种结构矛盾之中：它必须对自己的整体运行状态具有足够认识，否则无法进行资源调节、自我修正和长期稳定控制；但它又不可能把自己的全部内部状态同时送入工作记忆，因为这样恰恰会破坏工作记忆有限性所要求的局部闭合原则。

设智能体在时刻 $t$ 的真实内部状态为
\[
x_t^{\mathrm{int}}
=
\left[
x_t^{h},
x_t^{E},
x_t^{\Theta},
x_t^{\Psi},
x_t^{G},
x_t^{R},
x_t^{B},
x_t^{\mathrm{ext}},
\ldots
\right],
\]
其中分别可以包含工作记忆状态、情景记忆活动、结构记忆激活、自我慢变量、当前目标、资源状态、身体状态摘要以及外部认知资源状态等。这里的 $x_t^{\mathrm{int}}$ 不是一个真正要求工程实现为统一向量的数据结构，而是描述 ``智能体在某个时刻真实存在的全部内部动力状态'' 的理论变量。对于一个复杂 Agent 而言，其维度通常极高，并且其中不同变量以完全不同的时间尺度变化：
\[
\tau_{\mathrm{body}}
\ll
\tau_h
\ll
\tau_E
\ll
\tau_\Theta
\ll
\tau_\Psi .
\]
如果要求 $h(t)$ 直接拥有 $x_t^{\mathrm{int}}$ 的完整显式副本，那么工作记忆负担将随着 Agent 内部系统规模增长而同步增长。于是一个系统越复杂，越需要认识自己的内部状态，却也越不可能完整显式表示自己的内部状态。这构成了持续智能系统中的一个基本认识论瓶颈。

因此，我们需要引入一个状态映射：
\[
\mathcal C_{\mathrm{self}}:
x_t^{\mathrm{int}}
\longrightarrow
s_t^{\mathrm{self}},
\]
使得
\[
\dim s_t^{\mathrm{self}}
\ll
\dim x_t^{\mathrm{int}},
\]
但 $s_t^{\mathrm{self}}$ 仍然保留当前认知控制所需要的关键结构。SPC 所做的事情正是实现这种压缩映射。它并不要求把 ``真实自我'' 完整复制进工作记忆，而是形成一个当前任务和当前控制问题下足够有效的自我状态摘要。

因此，本书将 SPC 定义为：
\[
\boxed{
SPC:
\mathcal X_{\mathrm{internal}}
\rightarrow
\mathcal S_{\mathrm{self}}
}
\]
其中 $\mathcal X_{\mathrm{internal}}$ 是智能体真实内部状态空间，而 $\mathcal S_{\mathrm{self}}$ 是可进入显式认知过程的自我状态空间。二者并不相等：
\[
\boxed{
s_t^{\mathrm{self}}
\neq
x_t^{\mathrm{int}}.
}
\]
这一不等式非常重要。它意味着智能体内部不存在一个天然拥有整个系统真实状态的 ``小人'' 或全知中心。智能体对自己的认识，同它对外部世界的认识一样，需要经过观测、压缩、推断、置信度评价与持续修正。

由此我们得到 SPC 的第一原则：
\begin{proposition*}
Self-Access Is Estimated, Not Given.
\end{proposition*}
即自我访问不是系统天生透明拥有的属性，而是一个需要被构造的估计过程。

这一区分也为后面大量看似心理学的问题建立了工程基础。例如，一个 Agent 报告 ``当前任务过载''，并不意味着系统拥有一个绝对准确的 ``过载真值''；更准确地说，是 SPC 根据工作记忆结构、冲突强度、目标竞争、资源变化和历史状态形成了一个关于 ``系统可能正在过载'' 的后验估计。只有采用这种认识论立场，我们才有可能把自我感知从拟人化描述转化为可以被测量、校准和验证的系统工程对象。

\section{SPC 的第一性定义：从分布式动力学到可访问自我状态}

为了更加严格地理解 SPC，我们首先需要区分三个不同层次的对象：真实内部状态、可观测内部信号以及自我状态表示。真实内部状态记为 $x_t$，它包含智能体在时刻 $t$ 的实际动力状态；SPC 能够获得的内部观测记为 $z_t$；最终形成的自我状态估计记为 $\hat{s}_t$。于是最基本的结构不是
\[
x_t\rightarrow \hat{s}_t,
\]
而应写成
\[
x_t
\xrightarrow{\mathcal O_{\mathrm{int}}}
z_t
\xrightarrow{\mathcal E_{\mathrm{SPC}}}
\hat{s}_t ,
\]
其中 $\mathcal O_{\mathrm{int}}$ 是内部观测过程，$\mathcal E_{\mathrm{SPC}}$ 是 SPC 所完成的估计与压缩过程。

这一分解告诉我们：即使智能体 ``观察自己''，其信息也依然经过某种传感和路由机制。例如，工作记忆负载可以通过当前激活 CSO 数量、关系密度、冲突率、上下文切换速度等间接变量估计；结构记忆状态可以通过召回置信度、预测残差和当前激活模式估计；当前目标冲突也必须通过目标之间的资源竞争或约束不一致表现出来。换句话说，智能体并不会因为这些过程 ``发生在内部''，就自动获得它们的本体真值。

因此更一般地，可以定义
\[
z_t
=
\mathcal O_{\mathrm{int}}
\left(
x_{t-\delta:t}
\right)
+
\nu_t,
\]
其中 $\delta$ 表示 SPC 使用的内部时间窗口，$\nu_t$ 表示观测误差、采样误差、统计估计误差以及表示损失。SPC 随后构造
\[
\hat{s}_t
=
\mathcal E_{\mathrm{SPC}}
\left(
z_{\leq t},
E_t,
\Theta_t,
\Psi_t
\right).
\]
这里引入 $E,\Theta,\Psi$ 并不是为了让 SPC 成为一个庞大的全局推理模块，而是为了说明：当前自我状态判断不可能完全脱离时间连续性。一个瞬时负载峰值是否意味着真正异常，需要与近期轨迹比较；一次目标冲突是否值得提升，需要根据长期结构判断；同一种内部事件对于不同身份和价值结构的 Agent，其重要性也可能不同。因此 SPC 必须是 ``当前内部信号'' 与 ``历史和结构先验'' 的联合估计器。

进一步地，我们可以将 $\hat{s}_t$ 分成若干具有不同工程意义的分量：
\[
\hat{s}_t
=
\left[
\hat{\ell}_t,
\hat{\phi}_t,
\hat{c}_t,
\hat{u}_t,
\hat{r}_t,
\hat{g}_t,
\hat{\chi}_t,
\hat{\kappa}_t
\right].
\]
例如：

\[
\hat{\ell}_t
\]
可以表示当前认知负载；

\[
\hat{\phi}_t
\]
表示当前运行相态估计；

\[
\hat{c}_t
\]
表示主要结构冲突；

\[
\hat{u}_t
\]
表示不确定性；

\[
\hat{r}_t
\]
表示当前风险；

\[
\hat{g}_t
\]
表示目标竞争程度；

\[
\hat{\chi}_t
\]
表示内部循环、冗余或认知停滞倾向；

\[
\hat{\kappa}_t
\]
则可以表示整体可控性或稳定裕度估计。

这里不应该把这些变量理解为 SPC 永久固定的字段。SPC 的第一性对象不是某个特定 JSON schema，而是一个压缩原则：
\[
\boxed{
\hat{s}_t
=
\operatorname{Compress}_{\mathrm{control-relevant}}
\left(
z_{\leq t}
\right).
}
\]
也就是说，SPC 不是把所有内部数据均匀压缩，而是围绕 ``什么内部结构会显著影响当前决策与控制'' 进行有目的的压缩。

这意味着 SPC 与普通信息压缩存在根本不同。一般压缩算法关心重构误差：
\[
\|x-\hat{x}\|.
\]
SPC 更关心的是决策相关信息损失。可以定义一个控制相关损失：
\[
\mathcal L_{\mathrm{SPC}}
=
\lambda_1
\mathcal L_{\mathrm{state}}
+
\lambda_2
\mathcal L_{\mathrm{risk}}
+
\lambda_3
\mathcal L_{\mathrm{transition}}
+
\lambda_4
\mathcal L_{\mathrm{control}}
+
\lambda_5
\mathcal C(\hat{s}_t),
\]
其中最后一项 $\mathcal C(\hat{s}_t)$ 惩罚自我状态表示自身过于复杂。于是 SPC 面临一个根本性的双重优化目标：
\[
\boxed{
\text{保留足够多的控制相关结构}
\quad+\quad
\text{保持自我表示足够小}
}
\]
这正是它被称为 ``Self-Perception Compressor'' 而不仅仅是 ``Self Observer'' 的原因。

\section{自我基准投影：系统如何判断 ``这对我意味着什么''}

仅仅压缩内部状态仍然不足以产生真正意义上的 ``自我感知''。如果一个模块只是报告 ``CPU 使用率为 $73\%$''、``当前工作记忆中有 18 个激活节点''，它更接近系统监控器，而不是 SPC。SPC 的关键进一步在于：内部状态必须被投影到一个关于 ``这个状态对于当前主体意味着什么'' 的自我参照系中。

我们可以把这种操作记为
\[
\mathcal P_{\Psi}:
z_t
\longrightarrow
z_t^{\mathrm{self}},
\]
其中 $\Psi$ 表示当前较慢的身份、价值、偏好和长期一致性结构。于是
\[
z_t^{\mathrm{self}}
=
\mathcal P_{\Psi_t}
\left(
z_t
\right)
\]
不是简单地保存某个信号值，而是把该信号转换成相对于当前主体的功能意义。

例如，同样的高认知负载：
\[
\ell_t=0.85,
\]
在一个正在处理高价值紧急任务的状态下可能是合理的短期投入；而在一个低价值背景任务中，则可能意味着严重的资源配置错误。因此真正进入 SPC 自我状态的并不是
\[
\ell_t,
\]
而更接近
\[
\hat{\ell}^{\mathrm{self}}_t
=
f(
\ell_t,
Goal_t,
Value_t,
Risk_t,
History_t,
\Psi_t
).
\]
同样，一次预测错误的意义，也依赖于它发生在哪个领域、是否涉及核心身份和长期目标、是否是重复错误、是否已经影响现实行动。

因此我们可以把 SPC 看成建立一个 ``自我坐标系''：
\[
\boxed{
\mathcal X
\rightarrow
\mathcal X_{\mathrm{self}}
}
\]
外部和内部发生的大量事件，并不是因为它们本身具有固定的 ``心理意义''，而是在经过自我参照投影之后才获得 ``对当前主体而言是什么'' 的结构位置。

这也是为什么早期我们曾把 $\Psi$ 形容为一种背景引力场。这个比喻并不是说 $\Psi$ 在物理意义上产生引力，而是说明：同样进入工作记忆空间的结构，其显著性、保留概率和行动优先级会被较慢的自我结构扭曲。SPC 正是读取这种扭曲并把它显式化的一个重要接口。

可以形式化为
\[
w_i^{\mathrm{self}}
=
g(
C_i,
G_t,
\Psi_t,
E_t,
R_t
),
\]
其中 $C_i$ 是第 $i$ 个当前结构，$w_i^{\mathrm{self}}$ 表示该结构在自我状态中的权重。随后 SPC 形成
\[
\hat{s}_t
=
\sum_i
w_i^{\mathrm{self}}
\phi(C_i),
\]
这里的求和只是抽象形式，真实实现可以是图压缩、概率估计、神经编码或符号结构融合。

更进一步，自我基准并不是永恒固定的。由于 $\Psi$ 自身会随着长期经历变化，
\[
\Psi_{t+\Delta}
\neq
\Psi_t,
\]
同一个内部状态在生命周期不同阶段可能产生不同解释。这意味着 SPC 不是一个固定函数，而是一个带慢参数的动态估计系统：
\[
\boxed{
SPC_t
=
SPC(
\cdot;\Psi_t,\Theta_t
).
}
\]
因此，一个持续 Agent 的 ``我现在怎么样'' 并不是一套永恒不变的统计规则，而是始终相对于当前已经形成的主体结构进行解释。

这一机制也提示我们必须警惕自我解释的封闭循环。如果 $\Psi$ 影响 SPC，SPC 的结果又影响后续注意和经验选择，那么可能形成
\[
\Psi_t
\rightarrow
SPC_t
\rightarrow
Attention_t
\rightarrow
Experience_{t:t+\Delta}
\rightarrow
\Psi_{t+\Delta}.
\]
这种递归既是身份连续性的来源，也可能成为错误自我强化的来源。因此 SPC 必须保留现实残差、反证信息和置信度，而不能把当前自我解释当成不可修正的事实。自我基准投影的目标不是创造一个永远自洽的内部故事，而是让一个有限主体形成可行动但仍然可以被现实修正的自我状态表示。

\section{递归压缩：``我正在感知什么'' 如何重新进入工作记忆}

SPC 最具有 AgentOS 特征的一点，是它并不是一次性的状态监控，而是一个可以重新进入 $h(t)$ 的递归结构。智能体不仅能够处理某个对象，还可以处理 ``自己正在处理这个对象'' 这一事实；不仅能够遭遇目标冲突，还能够意识到 ``当前多个目标正在竞争我的工作记忆''。因此 SPC 产生的自我状态具有重新进入认知总线的能力：
\[
\boxed{
x_t
\rightarrow
SPC
\rightarrow
h_t^{\mathrm{self}}
\rightarrow
h_{t+1}.
}
\]

设普通工作记忆内容为
\[
h_t^{\mathrm{world}},
\]
SPC 生成的自我状态内容为
\[
h_t^{\mathrm{self}}.
\]
那么实际工作记忆可以写成
\[
h_t
=
h_t^{\mathrm{world}}
\oplus
h_t^{\mathrm{self}},
\]
其中 $\oplus$ 并不代表简单拼接，而表示两类结构在有限工作空间中的共同存在和竞争。一个成熟 Agent 不应持续让大量自我状态占据工作记忆，而应只在其对当前控制具有价值时提升。

可以引入一个自我感知准入函数：
\[
\gamma_t^{\mathrm{self}}
=
\sigma
\left(
\alpha_1
R_t
+
\alpha_2
C_t
+
\alpha_3
U_t
+
\alpha_4
\Delta S_t
-
\theta_{\mathrm{self}}
\right),
\]
其中 $R_t$ 表示风险，$C_t$ 表示冲突程度，$U_t$ 表示不确定性，$\Delta S_t$ 表示内部状态偏离趋势。当
\[
\gamma_t^{\mathrm{self}}
\]
较低时，系统并不需要显式 ``想着自己''；当它超过一定阈值，自我状态才被提升到工作记忆中。

这一机制具有重要意义。一个始终高强度监控自己的 Agent，并不一定更加智能，因为自我监控本身也消耗有限工作记忆容量。若
\[
C_{\mathrm{self}}(t)
\]
表示自我相关结构占用的显式认知复杂度，那么必须满足
\[
C_{\mathrm{task}}(t)
+
C_{\mathrm{self}}(t)
\le
C_{\max}(W).
\]
因此 SPC 还必须压缩自己的输出。否则系统可能陷入 ``为了知道自己是否过载而增加更多自我监控，从而使自己更加过载'' 的递归悖论。

因此我们提出：
\begin{statementbox}
Self-Monitoring Must Also Be Capacity-Bounded.
\end{statementbox}
自我感知同样受到工作记忆有限性约束。

从递归角度看，SPC 理论上还允许
\[
SPC(SPC(x_t)),
\]
即系统形成 ``我如何认识自己'' 的更高阶表示。但这种递归不应该无限展开。一个可运行智能体需要设置最大递归深度或压缩终止条件。可以定义：
\[
s_t^{(0)}=x_t,
\]
\[
s_t^{(1)}=SPC(s_t^{(0)}),
\]
\[
s_t^{(2)}=SPC(s_t^{(1)}),
\]
直至
\[
D_{\mathrm{KL}}
\left(
s_t^{(k)},
s_t^{(k-1)}
\right)
<
\epsilon
\]
或认知收益
\[
\Delta U_{\mathrm{control}}^{(k)}
<
\epsilon_U
\]
时停止递归。

这说明所谓 ``元认知'' 在这里并不是一个神秘功能，而可以被理解为：
\begin{statementbox}
Self-State Representation Becoming a New Cognitive Object.
\end{statementbox}
一旦自我状态本身进入 $h(t)$，它就可以像其他 Agent-CSO 一样被比较、推理、质疑和修改。

例如：
\[
\text{``任务很难''}
\]
是关于世界或任务的判断；

而
\[
\text{``我当前把这个任务判断得过难，可能因为近期连续失败''}
\]
则是一个更高阶自我状态结构。SPC 的递归机制使第二种结构原则上成为可能，但工作记忆有限性又要求这种递归必须具有明确的停止条件。由此，AgentOS 获得的并不是无限自省，而是\textbf{有限、事件触发、控制相关的递归自我观察能力}。

\section{SPC 的概率解释：自我认识是一种后验估计}

如果我们进一步追求数学严谨，就不能再把 SPC 输出写成一个确定的 ``真实自我状态''。由于内部观测存在延迟、噪声、不完整性和模型误差，SPC 更适合被解释为一个概率状态估计器。于是：
\[
\boxed{
p_A
\left(
x_t^{\mathrm{self}}
\mid
z_{\le t}^{SPC}
\right)
}
\]
才是智能体对自己当前状态更合理的数学表达。

这里
\[
x_t^{\mathrm{self}}
\]
表示希望估计的内部自我相关状态，
\[
z_{\le t}^{SPC}
\]
表示截至当前为止 SPC 可以获得的内部观测序列。

SPC 因此可以形成贝叶斯式更新：
\[
p(x_t^{\mathrm{self}}\mid z_{\le t})
\propto
p(z_t\mid x_t^{\mathrm{self}})
\int
p(x_t^{\mathrm{self}}\mid x_{t-1}^{\mathrm{self}})
p(x_{t-1}^{\mathrm{self}}\mid z_{\le t-1})
\,dx_{t-1}^{\mathrm{self}}.
\]
这里不要求工程实现必须采用经典贝叶斯滤波，但这一形式揭示了 SPC 的三个基本组成部分。

第一是先验：
\[
p(x_t^{\mathrm{self}}\mid x_{t-1}^{\mathrm{self}}),
\]
即系统关于自身状态如何随时间变化的动力学模型。

第二是似然：
\[
p(z_t\mid x_t^{\mathrm{self}}),
\]
即某种真实内部状态会产生什么内部观测。

第三是后验：
\[
p(x_t^{\mathrm{self}}\mid z_{\le t}),
\]
即综合历史和当前证据以后，对 ``我现在可能是什么状态'' 的估计。

这使 SPC 自然获得了一个非常重要的变量：
\[
\boxed{
Confidence_{\mathrm{self}}.
}
\]
智能体不只应该表示：
\[
\text{``我处于高负载状态''},
\]
还应表示：
\[
P(\text{HighLoad}\mid z_{\le t})=0.82.
\]
或者更一般地，把每一个自我状态分量写成：
\[
\hat{s}_{t,i}
=
(\mu_{t,i},\Sigma_{t,i}),
\]
其中 $\mu$ 表示估计值，$\Sigma$ 表示不确定性。

这一设计非常关键，因为一个持续 Agent 最危险的情况之一并不是 ``不知道自己''，而是 ``错误地确信自己知道自己''。如果 SPC 永远输出确定结论，那么内部状态估计误差很容易被后续控制系统放大。相反，如果 SPC 输出 epistemic uncertainty，那么下游系统就可以针对高不确定状态采取更保守策略，例如增加观测、降低控制增益、延迟不可逆行动或者主动请求外部验证。

我们甚至可以定义自我认识质量：
\[
Q_{\mathrm{self}}
=
1-
\mathbb E
\left[
d(
x_t^{\mathrm{self}},
\hat{x}_t^{\mathrm{self}}
)
\right],
\]
但真实系统通常无法直接获得完整的
\[
x_t^{\mathrm{self}},
\]
因此需要利用可验证事件、行为结果和未来残差进行间接校准。这使 SPC 与外部世界之间形成重要联系：自我认识最终不能只通过内部自洽评价，还必须通过后续行动是否符合预期来进行验证。

例如，SPC 认为当前系统 ``仍有足够认知余量''，于是允许继续增加一个高复杂度任务；如果随后工作记忆迅速失稳，那么这一现实结果应该成为 SPC 的训练信号。可以定义：
\[
\varepsilon_t^{SPC}
=
Outcome_{t+\Delta}
-
Prediction_{SPC,t},
\]
并更新：
\[
\theta_{SPC}
\leftarrow
\theta_{SPC}
-
\eta
\nabla_{\theta}
\mathcal L(
\varepsilon_t^{SPC}
).
\]
这意味着 SPC 本身也是可校准的，而不是固定不变的观察器。

从这一角度，我们得到本章第二个极重要的认识论原则：
\begin{proposition*}
The Agent Does Not Possess Its Internal Truth;
It Maintains a Posterior About Itself.
\end{proposition*}
智能体不是 ``拥有自己''，而是在持续运行中不断估计自己。

\section{认识论滞后：为什么智能体永远只能看到 ``刚刚过去的自己''}

一旦我们接受 SPC 是估计器，就会自然得到一个无法彻底消除的问题：自我认识存在时间滞后。任何内部状态从发生，到被检测、汇总、压缩、估计，再进入工作记忆，都需要时间。于是：
\[
\hat{s}_t
=
SPC
\left(
x_{t-\tau_{SPC}:t-\delta}
\right),
\]
其中
\[
\tau_{SPC}>0.
\]
即便工程系统的延迟非常小，也无法让
\[
\tau_{SPC}=0
\]
在严格意义上成立。

因此我们不能写：
\[
x_t^{\mathrm{self}}
=
PerfectObservation,
\]
更准确的是：
\[
\boxed{
\hat{x}_t^{\mathrm{self}}
=
\mathbb E[
x_t^{\mathrm{self}}
\mid
z_{\le t-\delta}
].
}
\]

这意味着，一个持续 Agent 每当 ``意识到自己处于某种状态'' 时，它真正把握的总是一个经过推断的、已经发生了极短时间的过去状态。系统必须依靠状态预测才能弥补这个时间差：
\[
\hat{x}_{t|t-\delta}
=
F_{\mathrm{self}}
\left(
\hat{x}_{t-\delta},
u_{t-\delta:t}
\right).
\]
SPC 因而不应只是 backward-looking monitor，还应该包含有限的 state prediction。

认识论滞后会产生一系列重要后果。

首先，快速变化的内部状态比慢变量更难准确自我感知。若某内部变量 $x_i$ 的特征时间尺度满足
\[
\tau_i
\ll
\tau_{SPC},
\]
那么 SPC 只能感知其统计性质而很难跟踪瞬时值。因此对于高频身体控制、低级资源调度等过程，更合理的是让这些过程在局部闭环中自治，而不是要求显式自我认知全部介入。

其次，SPC 的输出天然带有 ``过去结构''。这意味着 TCE 或任何基于 SPC 的控制过程都可能面对已经过时的状态。如果系统在
\[
t
\]
时刻基于
\[
\hat{s}_{t-\delta}
\]
进行强控制，而真实状态已经改变，则可能产生过度修正。虽然完整的控制稳定性分析将在专门章节展开，但这里已经可以看到：
\[
\boxed{
ObserverDelay
+
HighControlGain
\rightarrow
PotentialOscillation.
}
\]

第三，自我感知的延迟解释了为什么 ``持续自省'' 不能消除主体不确定性。即使一个 Agent 把大量资源用于观察自己，在观察过程中系统状态仍然继续变化：
\[
x_t
\rightarrow
Observation
\rightarrow
x_{t+\Delta}.
\]
因此 ``完全实时透明的自我'' 在一个持续动力系统中本身就是不现实的理想化。

我们可以定义自我状态陈旧度：
\[
A_t^{self}
=
t-t_{\mathrm{effective-observation}},
\]
并要求 SPC 输出中显式携带：
\[
(\hat{s}_t,
Confidence_t,
Age_t).
\]
这样，下游认知过程就不只是知道 ``SPC 告诉了我什么''，还知道 ``这个判断有多可信，以及它有多旧''。

这一点对于长期 AgentOS 尤其重要。例如：
\[
\text{``当前电量充足''}
\]
如果这个自我状态来自一分钟前，对于高速机器人就可能已经完全失效；而
\[
\text{``我的长期价值结构目前稳定''}
\]
即便基于数小时前的数据，也可能仍然足够有效。于是 SPC 的自我状态必须天然带有时间尺度意识：
\[
Validity_i
=
f(
Age_i,
\tau_i,
Uncertainty_i
).
\]
换言之，自我认识不是简单的 ``值''，而应该是一组
\[
\boxed{
Value+Confidence+Timescale+Freshness
}
\]
共同组成的估计对象。

\section{SPC 与 h、E、\texorpdfstring{$\Theta$}{Theta}、\texorpdfstring{$\Psi$}{Psi} 的耦合}

到这里，我们可以正式把 SPC 放回三相记忆和自我结构之中。SPC 并不独立拥有一套新的长期记忆，它主要承担 ``从多尺度状态中形成当前可访问自我状态'' 的作用。因此其与 $h,E,\Theta,\Psi$ 的关系具有明显的不对称性。

首先是
\[
h\rightarrow SPC.
\]
工作记忆向 SPC 提供当前显式认知结构，例如活跃目标、当前假设、关系密度、上下文切换、推理支线、冲突以及认知负载。SPC 从中估计：
\[
Load_t,\quad
Conflict_t,\quad
Phase_t,\quad
Uncertainty_t.
\]

其次是
\[
E\rightarrow SPC.
\]
单独观察当前时刻往往无法判断系统是否异常。例如，连续十分钟处于高负载与一次短暂高负载具有完全不同意义。因此 SPC 需要有限访问情景轨迹：
\[
E_{[t-\Delta,t]}
\]
来形成趋势估计：
\[
\dot{s}_t
\approx
\frac{s_t-s_{t-\Delta}}{\Delta}.
\]
这使 SPC 能够区分：
\[
HighLoadStable
\]
与
\[
HighLoadRising.
\]

第三是
\[
\Theta\rightarrow SPC.
\]
结构记忆提供关于 ``什么通常意味着什么'' 的长期模型。例如系统可以学到：
\[
Pattern_A
\rightarrow
HighProbabilityOfFailure,
\]
或者：
\[
Pattern_B
\rightarrow
TemporaryButRecoverableLoad.
\]
因此 $\Theta$ 相当于 SPC 状态解释中的结构先验。

第四是
\[
\Psi\rightarrow SPC.
\]
$\Psi$ 提供主体相关的慢尺度参照。它影响哪些状态对 ``我'' 有意义、哪些冲突涉及身份一致性、哪些长期变化需要被显式提升。

于是可以把 SPC 写成：
\[
\boxed{
S_t^{self}
=
SPC
\left(
h_t,
E_{t-\Delta:t},
\Theta_t,
\Psi_t,
z_t^{internal}
\right).
}
\]

但是信息流并不止于此。SPC 的输出又会重新进入：
\[
SPC\rightarrow h.
\]
当自我状态达到显式处理阈值时，会产生：
\[
h_t^{self}.
\]
例如：
\[
\text{``当前推理支线过多''},
\]
\[
\text{``目标 A 与目标 B 正在发生强冲突''},
\]
\[
\text{``当前自我判断置信度低''}.
\]

随后这个结构可能进一步形成：
\[
h^{self}\rightarrow E,
\]
即 ``我曾经经历了一次明显的内部失稳'' 成为经历的一部分。如果这种状态在长期重复出现，则：
\[
E\rightarrow\Theta
\]
可能逐渐学得：
\[
\text{``在这类情境中，我容易出现这种失稳模式''}.
\]
更长期情况下，某些反复经历还可能影响 $\Psi$ 对自身能力、边界和稳定性的解释。

因此完整闭环可以写成：
\[
\boxed{
h,E,\Theta,\Psi
\rightarrow
SPC
\rightarrow
h^{self}
\rightarrow
E
\rightarrow
\Theta
\rightarrow
\Psi.
}
\]
这形成了一个跨时间尺度的自我模型更新过程。

但必须防止一个理论误区：SPC 不等于 $\Psi$。SPC 回答的是：
\[
\boxed{
WhatStateAmIInNow?
}
\]
而 $\Psi$ 更接近：
\[
\boxed{
WhoAmIAcrossTime?
}
\]
前者是快速自状态估计，后者是慢速身份结构。若把两者混为一谈，短期状态就会过度修改身份；例如一次任务失败立即变成 ``我是一个无能力 Agent''。因此必须保持：
\[
\boxed{
\tau_{SPC}
\ll
\tau_\Psi.
}
\]
只有具有足够持续性、重复性和结构一致性的自我状态，才可能通过情景记忆和结构记忆逐步影响 $\Psi$。

这一时间尺度隔离是身份连续性的一个基础条件。

\section{SPC 的压缩目标：从完整自我模型转向控制充分性}

SPC 最容易出现的设计错误，是试图构造一个 ``越完整越好'' 的自我模型。直觉上，Agent 如果掌握更多内部信息似乎应该更加智能，但工作记忆有限性告诉我们，这种策略最终会产生反效果。真正适合 AgentOS 的 SPC 应该遵循 ``控制充分性'' 而不是 ``重构完备性'' 原则。

设完整内部状态为 $X$，SPC 输出为 $S$，未来需要采取的控制为 $U$。理想的 SPC 并不要求最大化：
\[
I(S;X),
\]
即让 $S$ 携带尽可能多关于 $X$ 的信息，而更合理的目标是保持：
\[
I(S;U)
\]
足够大，同时限制：
\[
I(S;X)
\]
的规模。

这与 Information Bottleneck 的思想具有形式上的相似性，可以写成：
\[
\boxed{
\min_{SPC}
\;
I(S;X)
-
\beta I(S;U).
}
\]
其含义是：在尽可能压缩内部状态的同时，保留对后续控制最重要的信息。

对于 AgentOS，还可以进一步加入风险变量 $R$ 和长期稳定变量 $L$：
\[
\mathcal J_{SPC}
=
I(S;X)
-
\beta_1 I(S;U)
-
\beta_2 I(S;R)
-
\beta_3 I(S;L).
\]
这说明一个好的 SPC 输出可能只有很少几个结构，却足以决定：
是否继续当前任务；
是否降低认知负载；
是否增加观测；
是否重新规划；
是否发生异常升级。

因此自我表示的价值不能按照描述长度评价，而应按照：
\[
\boxed{
ControlRelevantInformationPerUnitWorkingMemory
}
\]
评价。

我们可以定义一个概念性效率指标：
\[
\eta_{SPC}
=
\frac{
\Delta U_{\mathrm{control}}
}{
C(S_t)
},
\]
其中 $\Delta U_{\mathrm{control}}$ 表示引入该自我状态表示以后带来的控制效用提升，$C(S_t)$ 表示它占用的工作记忆结构成本。

这立即得到一个重要推论：
\begin{statementbox}
更成熟的自我感知未必意味着更多自我信息，
而可能意味着更少但更有控制价值的信息。
\end{statementbox}

一个初级 Agent 可能需要大量显式指标判断自己：
``当前有 18 个激活节点、7 个未完成推理、3 个工具调用……''

而成熟 Agent 可能压缩成：
\[
\text{``当前正在进入高不确定、高目标竞争的临界负载状态。''}
\]
后一种表示信息量表面更少，却具有更强的决策价值。

这与我们整套智能结构理论中的 ``结构沉降'' 思想一致：成熟不是无限增加显式结构，而是把重复出现的复杂关系压缩成更稳定、更高层的状态表示。

在工程实现中，因此建议 SPC 至少包含两级输出。一种是机器内部的高维状态向量：
\[
s_t^{latent},
\]
用于快速控制和连续监测；另一种是可进入 $h(t)$ 的稀疏语义摘要：
\[
s_t^{semantic}.
\]
二者满足：
\[
s_t^{semantic}
=
Decoder_{\mathrm{self}}
(
s_t^{latent}
).
\]
高维状态不需要时时占据工作记忆，而只有其显著变化才转化成语义 Agent-CSO。例如：
\[
\Delta s_t^{latent}
>
\theta
\Rightarrow
Generate(
CSO_{\mathrm{self}}
).
\]
这样可以保持连续监控与有限显式认知之间的统一。

\section{SPC 的失真、偏置与自证风险}

既然 SPC 是一个估计器，就必然可能发生错误。尤其需要认识到，自我感知错误往往比普通外部感知错误更加危险，因为它会直接改变系统对自身能力、风险和控制策略的判断。一个 Agent 如果错误识别一个外部对象，可能只导致一次任务错误；而如果长期错误估计 ``自己的可靠性''、``自己的风险水平'' 或 ``自己的学习状态''，这种错误可能通过反馈循环不断放大。

我们可以把 SPC 误差定义为：
\[
\varepsilon_t^{SPC}
=
d(
s_t^{true},
\hat{s}_t
),
\]
尽管在真实系统中 $s_t^{true}$ 往往不可完全直接获得，但这个理论变量仍然有助于区分几类不同误差。

第一类是观测缺失：
\[
z_t
\not\supset
CriticalInternalSignal.
\]
SPC 根本没有看到某个重要内部变化。

第二类是压缩损失：
\[
z_t
\rightarrow
\hat{s}_t
\]
过程中删除了控制相关结构。

第三类是先验偏置。若 $\Theta$ 或 $\Psi$ 中已有模型长期认为 ``这种状态没问题''，SPC 可能系统性低估新的风险。

第四类是延迟误差：
\[
\hat{s}_t
\approx
s_{t-\delta},
\]
而真实状态已经变化。

第五类则是自我强化偏置。这是一种特别重要的情况：
\[
\Psi
\rightarrow
SPC
\rightarrow
Attention
\rightarrow
Experience
\rightarrow
\Psi'.
\]
假设系统形成 ``自己不擅长某类任务'' 的结构，那么 SPC 可能更容易把普通困难解释成能力不足；这种解释降低探索强度，导致相关成功经验减少，最后又进一步强化原有判断。

因此，SPC 必须具有反证机制。可以定义一个自我模型残差：
\[
r_t^{self}
=
Outcome_t
-
ExpectedOutcome(
\hat{s}_{t-\Delta}
).
\]
如果 SPC 认为：
\[
\text{``我无法完成此任务''},
\]
但系统连续成功完成，则：
\[
r_t^{self}
\]
应当持续推动 SPC 和其相关结构修正。

同理，如果 SPC 长期报告：
\[
\text{``状态稳定''},
\]
但实际行为不断表现出任务失败、资源耗尽和恢复异常，那么外部事实必须拥有比内部自我解释更高的校准权重。

因此：
\[
\boxed{
RealityEvidence
>
SelfInterpretiveConsistency.
}
\]
这与全书已经建立的
\[
\boxed{
RealityIsUltimateConstraint
}
\]
完全一致。

我们还可以定义 SPC 的校准指标。例如对于某种风险判断：
\[
P_t(Risk)=p_t,
\]
实际风险事件出现率应当与 $p_t$ 统计匹配。长期可以测量：
\[
CalibrationError
=
\sum_k
\left|
P(\mathrm{event}\mid p\in B_k)
-
\overline{p}_{B_k}
\right|.
\]
这样 ``自我认识准确'' 就不再是一种哲学宣称，而成为可以通过长期运行数据检验的工程性质。

此外，自我状态输出还需要保留 provenance，即：
\[
\boxed{
Source,\ Confidence,\ Timestamp,\ Evidence.
}
\]
例如：
\[
SelfState_i
=
(
Value_i,
Confidence_i,
Age_i,
Evidence_i
).
\]
这使得工作记忆在使用 SPC 输出时能够区分：
``这是高置信度的直接运行指标''，
还是
``这是基于历史模型推测出来的解释''。

只有在这种认识论标记下，SPC 才不会把推测伪装成事实，也不会把短期内部噪声直接固化成长期自我。

\section{SPC 的工程化最小结构与评价原则}

在完成理论定义之后，我们可以给出一个不依赖具体神经网络架构的 SPC 最小工程结构。一个可运行的 SPC 至少应包含四个层次：内部观测、时间整合、结构压缩以及自我状态发布。

第一层是 Internal Observation Layer。其输入可以包括：
\[
z_t=
[
z_t^{h},
z_t^{goal},
z_t^{memory},
z_t^{resource},
z_t^{body},
z_t^{tool},
z_t^{error}
].
\]
这里的关键不是采集 ``所有东西''，而是定义少量能够反映系统宏观状态的充分统计量。

第二层是 Temporal Integration Layer。SPC 不仅观察瞬时值，还维护：
\[
EMA(z_t),
\quad
\dot z_t,
\quad
Var(z_{t-\Delta:t}),
\]
以及必要的事件轨迹。于是可以识别趋势、持续时间和相变倾向。

第三层是 Self-State Estimator。它根据当前观测和先验形成：
\[
p(s_t\mid z_{\le t},E,\Theta,\Psi).
\]
这一层可以采用规则模型、贝叶斯滤波、神经状态空间模型或混合架构。本理论并不要求特定实现。

第四层是 Semantic Self Compressor。它把高维后验压缩为少量具有控制意义的自我 CSO：
\[
\mathcal C_t^{self}
=
\{
C_{load},
C_{risk},
C_{uncertainty},
C_{conflict},
C_{phase},
\ldots
\}.
\]
只有达到准入条件的结构才进入 $h(t)$：
\[
C_i^{self}\rightarrow h
\quad
\text{iff}
\quad
Priority(C_i^{self})>\theta_h.
\]

因此 SPC 的最小数据流可以总结为：
\[
\boxed{
InternalSignals
\rightarrow
TemporalEstimator
\rightarrow
SelfStatePosterior
\rightarrow
SemanticCompression
\rightarrow
h^{self}.
}
\]

评价一个 SPC，也不能只测分类准确率。至少需要六类指标。

其一是状态估计误差：
\[
E_{\mathrm{state}}.
\]

其二是延迟：
\[
\tau_{SPC}.
\]

其三是校准度：
\[
E_{\mathrm{calibration}}.
\]

其四是压缩率：
\[
R_{\mathrm{compression}}
=
\frac{
C(x^{internal})
}{
C(s^{self})
}.
\]

其五是控制有效性：
\[
\Delta U_{\mathrm{control}}.
\]

其六是工作记忆代价：
\[
C_{h}^{SPC}.
\]

因此可以构造一个综合目标：
\[
J_{SPC}
=
\alpha
E_{\mathrm{state}}
+
\beta
E_{\mathrm{calibration}}
+
\gamma
\tau_{SPC}
+
\lambda
C_h^{SPC}
-
\mu
\Delta U_{\mathrm{control}}.
\]
一个好的 SPC 不一定拥有最高精度；如果它需要耗费大量工作记忆和计算资源才能提高很少的估计精度，整体反而可能更差。SPC 本质上仍然服从资源理性的原则。

由此，我们得到 SPC 的工程定义：
\begin{definition*}
SPC 是一个在有限认知资源约束下，对智能体分布式内部动力状态进行持续观测、时间整合、概率估计、自我基准投影和控制相关压缩，并将少量高价值自我状态重新发布到工作记忆的内部认识论接口。
\end{definition*}

这一界定也说明 SPC 与普通 Monitoring System 的根本差异。Monitoring 主要回答：
\[
\text{系统有哪些指标？}
\]
而 SPC 试图回答：
\begin{statementbox}
这些内部变化对于当前这个持续主体意味着什么？
\end{statementbox}
其输出因此具有主体相关性、时间连续性、概率性和控制意义。

\section{本章结论：自我首先是一种有限、滞后而可校准的状态估计}

通过本章的推导，我们可以重新理解 ``自我感知'' 这个容易被哲学化的概念。对于 AgentOS 而言，自我感知的起点并不是证明机器是否具有主观体验，而是解决一个极其具体的系统问题：一个内部状态远比工作记忆复杂的持续智能体，如何在不把自己全部搬进工作记忆的情况下，仍然获得足够的信息来调节自己。

真实内部动力状态为：
\[
x_t^{internal},
\]
内部可观测信号为：
\[
z_t,
\]
SPC 产生的自我状态则为：
\[
\hat{s}_t.
\]
因此最基础的关系是：
\[
\boxed{
x_t^{internal}
\neq
z_t
\neq
\hat{s}_t.
}
\]

这里存在三个不可消除的差异：真实状态与观测之间存在观测损失；观测与自我状态之间存在压缩损失；当前真实状态与 SPC 输出之间存在时间延迟。由此我们得到：
\[
\boxed{
SelfPerception
=
Approximate,
Compressed,
Delayed,
Probabilistic.
}
\]

但 ``不完美'' 并不意味着它没有价值。恰恰相反，一个有限智能系统真正需要的不是绝对透明自我，而是一个在有限资源条件下足够支撑调节的自我状态模型。因此：
\[
\boxed{
OptimalSelfPerception
\neq
MaximumSelfInformation.
}
\]
更合理的目标是：
\[
\boxed{
OptimalSelfPerception
=
MinimalRepresentation
\;with\;
SufficientControlRelevance.
}
\]

SPC 进一步揭示了一个更深的智能原理：一个系统开始具有较高级自我调节能力，并不需要它 ``看到自己的一切''；它只需要能够持续把自己的关键状态压缩为新的认知对象，使
\[
\text{系统正在发生什么}
\]
转变成
\[
\text{我现在可能处于什么状态},
\]
并让后者重新参与未来认知。

整个过程可以压缩为：
\[
\boxed{
DistributedDynamics
\rightarrow
Observation
\rightarrow
SelfStatePosterior
\rightarrow
Compression
\rightarrow
h^{self}
\rightarrow
FutureDynamics.
}
\]

因此，本章最终给出 SPC 的理论定位：

\begin{statementbox}
SPC 是持续智能从 ``运行自身'' 走向 ``形成关于自身运行状态的可操作表示'' 的第一座桥梁。
\end{statementbox}

它并不赋予智能体一个全知的内部观察者，而是承认智能体与外部世界一样，对自身也具有认识论边界。一个真正成熟的 AgentOS 因而不是 ``完全知道自己'' 的系统，而是一个能够持续知道：
\[
\text{自己目前认为自己是什么状态},
\]
同时知道：
\[
\text{这种判断有多可信},
\]
并且允许现实结果不断纠正这种判断的系统。

这一原则可以最终浓缩为：

\begin{proposition*}
自我感知不是自我的镜像，而是智能体在有限容量、有限观测与有限时间条件下，对自身动力学持续形成的控制充分后验。
\end{proposition*}
