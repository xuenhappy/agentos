\section{预测不是现实：智能系统中的认识论权限分层}

在建立具备长期世界模型的 Agent 时，我们首先必须克服一个非常容易被工程实现掩盖的认识论错误：由于预测状态和观测状态最终都以数字表示存在于计算机中，因此系统很容易在数据结构层面把两者当成同一种东西。例如，BPCC 可以根据身体当前状态预测未来 $50\,\mathrm{ms}$ 后机械臂末端的位置，Agent Kernel 也可以根据长期世界模型预测数分钟以后任务可能达到的状态。从纯计算角度看，这些预测都可以表示成一个状态向量：
\[
\hat{x}_{t+\Delta}
\]
而传感器融合之后得到的现实状态同样可以表示为：
\[
x^{obs}_{t+\Delta}.
\]
如果我们只观察数据类型，它们似乎都是``状态''；然而在认识论意义上，两者拥有完全不同的权限。前者描述：
\[
\text{WhatMayBe},
\]
后者试图描述：
\[
\text{WhatHasBeenObserved}.
\]
因此，本书将二者严格区分为：
\[
\boxed{
\hat{x}_{t+\Delta}\in\mathcal X^{pred}
}
\]
与
\[
\boxed{
x^{obs}_{t+\Delta}\in\mathcal X^{obs}.
}
\]
这不是一个简单的软件工程类型区分，而是 AgentOS 认识论结构的基础。

我们可以进一步定义一个状态命题 $s$ 的认识论标签：
\[
\eta(s)\in
\{
Observed,\,
Derived,\,
Predicted,\,
Counterfactual,\,
Assumed
\}.
\]
其中 $Observed$ 表示该结构直接或间接来源于现实观测链；$Derived$ 表示它从观测事实经过确定或概率推理得到；$Predicted$ 表示它来自模型对未来的生成；$Counterfactual$ 表示它属于未实际发生的反事实分支；$Assumed$ 则表示系统为了继续推理而暂时接受的工作假设。我们可以把这些状态统一存储在 SGC 或 Agent-CSO 图中，却不能因此抹去它们之间的认识论等级。换句话说：
\[
SameRepresentationFormat
\not\Rightarrow
SameEpistemicAuthority.
\]

这一点对 AgentOS 极其重要。因为随着 $\Theta$、$\Psi$、$\Omega$ 等慢结构逐渐成熟，Agent 将形成越来越强的先验。长期世界模型可能非常稳定，自我解释可能高度一致，BPCC 的短时预测也可能在绝大多数情况下正确。如果没有 Reality Authority 原则，系统会自然产生一种危险倾向：当内部预测与外部观测冲突时，优先相信内部模型。这种机制在短期内甚至可能提升稳定性，因为系统不会受到偶然噪声影响；但如果这种偏置失去边界，它最终会把智能系统从``具有稳健先验的观察者''变成``以自身预测覆盖现实的封闭动力系统''。

因此，我们需要建立认识论优先关系。若记：
\[
\prec_E
\]
表示``在现实状态确认问题上认识论权限低于''，那么通常应有：
\[
Prediction
\prec_E
DerivedEvidence
\prec_E
ValidatedObservation.
\]
这里并不是说所有传感器观测永远正确。观测同样存在噪声、遮挡、故障和欺骗，因此 $Observed$ 不是``绝对真理''。真正关键的是，现实权威意味着系统必须保留一条\textbf{能够被现实证据持续修正的路径}，而不是规定某一个传感器值永远拥有绝对正确性。更严格地说，我们可以把现实权威定义为：
\[
\boxed{
\lim_{n\rightarrow\infty}
Belief_A(C\mid O_{1:n})
}
\]
必须能够随着新的现实证据 $O_{1:n}$ 更新，而不能被内部先验冻结为：
\[
Belief_A(C\mid O_{1:n})
=
Belief_A(C\mid \Theta,\Psi),
\qquad
\forall n.
\]

从 CSO 理论角度看，这一点更加清楚。宇宙中的实际结构记为：
\[
C_U(t),
\]
而 Agent 内部对它的承载为：
\[
C_A(t)=\pi_A(C_U(t)).
\]
我们从来没有假设：
\[
C_A(t)=C_U(t).
\]
Agent-CSO 是现实结构经过有限观测、压缩、解释和历史先验以后形成的内部结构。因此它必然可能产生偏差：
\[
\varepsilon_C(t)
=
D\left(
C_U(t),
C_A(t)
\right).
\]
真正智能的系统并不是令 $\varepsilon_C(t)\equiv0$，这是对有限 Agent 不现实的要求，而是要求：
\[
\boxed{
\varepsilon_C(t)
\text{能够通过新的 World--Agent 闭环持续受到约束。}
}
\]

由此我们得到本章第一条原则：

\[
\boxed{
LearnedDynamics\neq RealityAuthority.
}
\]

模型可以比瞬时传感器更加可靠，长期先验也可以用来拒绝明显异常的观测，但模型本身没有权利宣布现实已经按照自己的预测发生。预测只能生成对未来的结构约束；现实是否进入该状态，必须经过新的观测事件确认。正是在这个意义上，我们将 Reality Authority 作为 AgentOS 的最终认识论锚点：不是因为 Agent 能直接获得``绝对现实''，而是因为\textbf{内部世界必须永远保留向外部现实重新开放的纠错通道}。

\section{行动发出不等于行动成功：从意图状态到现实状态}

在普通软件系统中，一个函数调用返回成功往往意味着操作已经完成。然而具身智能进入真实世界以后，这一假设不再成立。Agent 可以发出一个动作命令，却无法仅凭命令本身判断世界已经按照该命令发生变化。因此：
\[
\boxed{
ActionIssued
\neq
ActionSucceeded.
}
\]
这条看似简单的原则实际上决定了 AgentOS 是否真正拥有现实闭环。

设 Agent Kernel 在时刻 $t$ 形成目标：
\[
g_t,
\]
并进一步生成控制意图：
\[
u_t^{ref}.
\]
KRA 与 BPCC 将其转换成具体身体控制量：
\[
u_t^{body}.
\]
如果我们采用一个错误的软件中心主义模型，系统可能写成：
\[
u_t^{body}
\Rightarrow
x_{t+1}=x^{target}_{t+1}.
\]
也就是说，一旦动作已经发出，就在内部状态中直接把目标状态写成``已完成状态''。这种结构在纯数字软件中偶尔可以成立，例如某些事务具有可靠的原子提交语义；但在现实环境中，它普遍是不成立的。真实世界应写为：
\[
x_{t+1}
=
F_U
\left(
x_t,
u_t^{body},
w_t
\right),
\]
其中 $w_t$ 表示所有 Agent 无法完全控制的外部扰动。于是即使：
\[
u_t^{body}=u_t^{ideal},
\]
仍然可能：
\[
x_{t+1}\neq x^{target}_{t+1}.
\]

例如，机械臂收到``抓住杯子''的命令并不意味着杯子已经被抓住；浏览器 Agent 发送点击事件也不意味着服务器已经接受操作；机器人发出向前运动指令也不意味着轮胎没有打滑；文件写入请求返回也不必然代表最终远端数据副本已经完成一致性。所有这些问题都具有相同的结构：

\[
Intent
\rightarrow
Action
\rightarrow
RealityDynamics
\rightarrow
ObservedOutcome.
\]

所以，一个 Agent 的内部任务状态不能直接由：
\[
ActionCommand
\]
更新为：
\[
Success.
\]
更合理的状态转换是：
\[
Requested
\rightarrow
Issued
\rightarrow
Executing
\rightarrow
Observed
\rightarrow
Verified
\rightarrow
Closed.
\]
这里的每一步代表不同的认识论状态。尤其是：
\[
Verified
\]
要求系统重新获得现实证据。

我们可以形式化定义动作 $a_t$ 的成功谓词：
\[
Success(a_t)
=
\mathbf 1
\left[
V
\left(
O_{t:t+\Delta},
G_t
\right)
\geq\theta_V
\right],
\]
其中 $O_{t:t+\Delta}$ 是行动以后重新获得的现实观测，$G_t$ 是目标约束，$V$ 是验证函数。于是：
\[
ActionIssued(a_t)=1
\]
并不能推出：
\[
Success(a_t)=1.
\]
只有经过：
\[
Observation+Verification
\]
后，系统才可以更新任务闭合状态。

这一结构直接改变了我们对 ``Action'' 的理解。在很多早期 Agent 架构中，Action 被视为认知过程的终点：
\[
Perception\rightarrow Reasoning\rightarrow Action.
\]
但对于持续 Agent，这条链必须闭合：
\[
\boxed{
Perception
\rightarrow
Reasoning
\rightarrow
Action
\rightarrow
World
\rightarrow
Perception'.
}
\]
行动不是认知流程的终点，而是下一轮现实观测的起点。

这同时解释了为什么 AgentOS 不能只保存``我做了什么''，而必须保存：
\[
\text{我尝试做什么},
\]
\[
\text{现实发生了什么},
\]
以及：
\[
\text{二者之间的差异是什么}.
\]
若记计划结果为：
\[
\hat{y}_{t+1},
\]
现实结果为：
\[
y^{obs}_{t+1},
\]
那么：
\[
\varepsilon^{act}_{t+1}
=
y^{obs}_{t+1}
-
\hat{y}_{t+1}
\]
就是非常重要的行动残差。

这一残差不能简单理解为控制误差。它可能来自多个来源：
\[
\varepsilon^{act}
=
\varepsilon_{model}
+
\varepsilon_{control}
+
\varepsilon_{environment}
+
\varepsilon_{observation}
+
\varepsilon_{interface}.
\]
因此，当行动失败时，高层 Agent 不应立刻得出``我的世界模型错误''，也不能立即认为``Body Runtime 控制失败''。正确机制是逐层归因：首先由 BPCC 判断局部动力学偏差；KRA 判断 Kernel--Body 语义或动力映射是否发生失配；必要时才把结构性残差提升给更高认知层重新解释。

这里体现了我们一直强调的：
\[
\boxed{
PredictLocally,\ EscalateResidualGlobally.
}
\]
正常行为尽可能在局部闭环中完成，异常才向更高层升级。但是无论异常由哪一级处理，最终成功状态仍然不能由局部模型直接写回现实状态，而必须重新进入现实验证链。

因此，本节得到第二条原则：

\[
\boxed{
\text{意图具有控制权，但只有现实结果具有完成权。}
}
\]

这个区分看似语义细节，却直接决定长期记忆是否可靠。因为如果 Agent 把``已经发出的行动''写入 E 为``已经完成的事实''，错误将沿着：
\[
h\rightarrow E\rightarrow\Theta\rightarrow\Psi
\]
逐渐沉降，最终让一次短暂的行动误判变成长期世界模型甚至身份历史的一部分。Reality Authority 的意义，正是阻止这种错误跨尺度沉降。

\section{现实重入原则：所有行动结果必须重新经过 World--Body--Agent 链}

既然行动发出并不意味着行动成功，那么 AgentOS 必须进一步规定：\textbf{行动之后的世界状态不能通过内部捷径写回认知系统，而必须经过现实重入。}我们将这一要求称为 Reality Re-entry Principle：

\[
\boxed{
Control
\rightarrow
Reality
\rightarrow
BodyRuntime
\rightarrow
SGC^{obs},FCS^{obs}
\rightarrow
AgentKernel.
}
\]

这条原则是本章最重要的系统架构约束之一。

为了理解为什么现实必须``重新进入''，我们考虑一个具有预测能力的 BPCC。假设 BPCC 在 $t$ 时刻预测：
\[
\hat{x}_{t+\Delta}^{BPCC}.
\]
与此同时，Kernel 可能还形成一个更高层的预测：
\[
\hat{X}_{t+\Delta}^{Kernel}.
\]
如果系统为了降低感知延迟，允许 BPCC 在动作执行后直接把：
\[
\hat{x}_{t+\Delta}^{BPCC}
\]
写入：
\[
SGC^{obs}_{t+\Delta},
\]
那么预测和观测之间的边界就被破坏了。系统从此可能进入：
\[
Prediction
\rightarrow
PredictionAsObservation
\rightarrow
NewPrediction
\]
的封闭链，而现实只在偶尔异常时才重新介入。随着模型精度提高，这种设计甚至可能看起来越来越稳定，因为绝大多数情况下预测与现实接近；但它同时失去了一个关键能力：发现自己什么时候已经脱离现实。

因此，AgentOS 必须严格规定：
\[
\boxed{
\hat{SGC}^{pred}
\not\rightarrow
SGC^{obs}
}
\]
以及：
\[
\boxed{
\hat{FCS}^{pred}
\not\rightarrow
FCS^{obs}.
}
\]
预测状态只能进入对应的 predicted layer：
\[
SGC^{pred},\qquad FCS^{pred},
\]
而真实观测只能由经过感知链、状态估计和证据融合得到的 observation pipeline 更新。

我们可以因此将 SGC 状态表示为：
\[
SGC_t
=
\left\{
G_t^{obs},
G_t^{derived},
G_t^{pred},
G_t^{cf}
\right\},
\]
其中：
\[
G_t^{obs}
\]
是观测层，
\[
G_t^{derived}
\]
是由观测推导出的结构，
\[
G_t^{pred}
\]
是预测层，
\[
G_t^{cf}
\]
是反事实结构。类似地：
\[
FCS_t
=
\left\{
F_t^{obs},
F_t^{derived},
F_t^{pred}
\right\}.
\]
这些层可以相互比较，却不能失去来源标签。

于是系统可以定义现实残差：
\[
\varepsilon_{SGC}
=
D_G
\left(
SGC^{obs},
SGC^{pred}
\right),
\]
以及：
\[
\varepsilon_{FCS}
=
D_F
\left(
FCS^{obs},
FCS^{pred}
\right).
\]
再结合身体控制残差：
\[
\varepsilon_{ctrl},
\]
形成：
\[
\boxed{
\varepsilon_B
=
\left(
\varepsilon_{ctrl},
\varepsilon_{SGC},
\varepsilon_{FCS}
\right).
}
\]
这一 $\varepsilon_B$ 就成为 Body Runtime 与 Kernel 之间最重要的现实校准信号之一。

值得强调的是，现实重入并不意味着高层 Kernel 必须读取所有原始传感器数据。实际上，这会重新制造工作记忆过载问题。Reality Re-entry 所要求的是\textbf{因果来源经过现实}，而不是\textbf{所有数据必须直接进入高层认知}。例如：
\[
RawSensor
\rightarrow
BodyRuntime
\rightarrow
SensorFusion
\rightarrow
SGC^{obs}
\]
完全可以由高速局部系统完成。Kernel 最终只接受压缩后的语义结构：
\[
SemanticReality.
\]
因此：
\[
RealityReentry
\neq
RawDataReentry.
\]
更准确的是：
\[
\boxed{
RealityReentry
=
RealityGroundedSemanticReentry.
}
\]

这也解释了为什么 Body Runtime 在整个 AgentOS 中是第一道现实压缩层。对于 Kernel 来说，现实不是数百万像素、数万个传感器采样点和连续设备寄存器，而是：
\[
SGC+FCS+Residual+Exception.
\]
但是这些语义结构必须能够追溯到现实证据，而不能仅仅来自生成模型内部的自洽预测。

我们可以进一步定义 provenance 函数：
\[
\Pi(s)
=
\left(
source,
time,
confidence,
derivation,
revision
\right).
\]
对于任何关键 Agent-CSO $s$，系统应能够知道：
\[
source(s)
=
Observation?
Prediction?
Memory?
Inference?
ExternalAgent?
\]
这样的来源结构不是为了建立一个庞大形式逻辑系统，而是为了防止长期 Agent 在多次记忆重构、预测和语言生成以后逐渐失去``什么是自己推测的，什么是真正观察到的''之间的边界。

因此，Reality Re-entry Principle 实际上同时承担三个功能。

第一，它是\textbf{控制闭环原则}：动作必须通过现实反馈闭合。

第二，它是\textbf{认识论原则}：Prediction 与 Observation 必须保持来源区分。

第三，它是\textbf{长期记忆保护原则}：只有经过足够现实验证的结构，才应获得更高权重沉降到慢记忆。

所以，在三相记忆中可以进一步定义：
\[
P(E\leftarrow h)
=
f(
Salience,
Value,
RealityConfidence,
Novelty
),
\]
其中：
\[
RealityConfidence
\]
应成为事件写入和结构固化的重要权重。如此一来，现实权威不再只存在于 Body Runtime，而真正贯穿：
\[
h\rightarrow E\rightarrow\Theta.
\]

\section{观测也不是现实本身：有限智能体的现实接近问题}

当我们强调 Reality Authority 时，很容易走向另一个错误极端：把传感器观测直接等同于现实本身。事实上，这与把预测等同于现实同样危险。Agent 不可能直接获得 Universe-CSO 的全部真实状态；它只能通过有限身体、有限传感器、有限表示和有限计算能力形成：
\[
AgentCSO(C_U).
\]
因此，本章所谓``现实权威''并不是：
\[
Observation=Reality,
\]
而是：
\[
\boxed{
Reality
>
Observation
>
Prediction
}
\]
在认识论结构上形成一种方向性约束。

设宇宙实际状态为：
\[
x_t^U,
\]
传感器过程为：
\[
z_t
=
H(x_t^U)+v_t,
\]
其中 $v_t$ 为观测噪声。Body Runtime 再通过状态估计器：
\[
\hat{x}^{obs}_t
=
\mathcal E(z_{\leq t})
\]
形成 Agent 可用的现实估计。因此即使标记为：
\[
Observed,
\]
它本质上仍然是：
\[
\boxed{
RealityGroundedEstimate.
}
\]
这与：
\[
ModelGeneratedPrediction
\]
的区别不在于前者绝对没有误差，而在于前者的更新因果链最终连接到外部现实。

\[
\boxed{
\begin{aligned}
\text{Intelligence}
&=
\text{Prediction}
+
\text{Representation}
+
\text{Control}
+
\text{Memory}
+
\text{Self}
\\
&\qquad
\Big|\_{\text{continuously constrained by Reality}}
\end{aligned}
}
\]

或者用本书更统一的 CSO 语言表达：

\[
\boxed{
UniverseCSO_t

Action_t

}
\]

真正的智能并不是内部模型越来越能够取代现实，而是随着模型、记忆和自我越来越强，它仍然能够不断回到现实、发现差异、重新解释自己，并把现实产生的残差转化成新的结构。

\[
\boxed{
\textbf{
Reality does not merely provide data to intelligence;
it is the final boundary condition that prevents intelligence from becoming a closed world of its own.
}
}
\]

在 AgentOS 中，这条边界不是智能能力的限制，而恰恰是持续学习、长期稳定与真正自主性的必要前提。
