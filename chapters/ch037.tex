\chapter{认知控制的稳定性}
\label{chap:cognitive-control-stability}

\fbox{
\parbox{0.94\textwidth}{
\textbf{【本章总体说明】}
本章研究 AgentOS 从“能够调节自身认知状态”走向“能够长期稳定地调节自身认知状态”时所必须解决的控制论问题。前文已经建立了 SPC--AHC--TCE 闭环：SPC 对分布式认知状态进行压缩和估计，AHC 对身体、资源、风险与内稳态信号进行连续积分，TCE 则依据这些估计调节认知温度、探索强度、注意范围、推理深度、激活增益以及资源分配。然而，只要自我感知、内稳态积分和控制执行具有非零时间常数，这一闭环就不可能等价于理想瞬时控制器。状态估计滞后、控制增益过高、目标流形快速切换、慢变量受到高速噪声污染，都可能产生过冲、振荡、迟滞甚至长期身份漂移。因此，本章不再把“稳定”理解为某一时刻的认知状态保持不变，而将其定义为：在现实扰动、任务切换、模型误差和内部延迟共同存在时，Agent 的认知轨迹仍能被限制在可治理区域内，并能够在扰动后重新回到与目标、自我和现实约束一致的可行轨迹族。我们将依次讨论 observer delay、controller delay、TCE gain、overshoot、oscillation、delay margin、gain margin、settling time 与 recovery time，并进一步证明 AgentOS 的控制对象并非直接操纵某一个瞬时认知状态，而是通过改变趋势、结构、允许区域和未来轨迹分布来实现稳定控制。
}
}

\section{稳定性问题的重新定义：控制的不是一个状态，而是一族未来轨迹}

当我们在前文中建立
\[
SPC
\rightarrow
AHC
\rightarrow
TCE
\rightarrow
CognitiveDynamics
\rightarrow
SPC
\]
这一闭环时，很容易产生一种工程上的误解：似乎 SPC ``测量'' 当前认知状态，TCE 读取测量值，然后像温控器调节温度一样，直接把工作记忆 $h(t)$ 推到某一个目标值。若按这种理解设计 AgentOS，认知控制器将迅速陷入两个问题。其一，工作记忆本身是高维、离散与连续变量混合的动态结构，所谓“目标状态”通常不存在唯一数值表示；其二，真正需要稳定的不是某个瞬时 $h(t)$，而是 Agent 在未来一段时间中的认知轨迹是否继续位于安全、可解释、任务有效并与身份连续性相容的可行区域内。因此，本章首先必须重新界定认知控制的控制对象。

设 Agent 在时刻 $t$ 的运行状态为
\[
x(t)
=
\left[
h(t),
a(t),
g(t),
r(t),
q(t)
\right],
\]
其中 $h(t)$ 表示当前工作记忆及其活动关系结构，$a(t)$ 表示 AHC 内稳态调制状态，$g(t)$ 表示当前目标与子目标结构，$r(t)$ 表示认知资源状态，$q(t)$ 表示冲突、不确定性、风险和稳定性等运行指标。为了保持本章的局部闭合，我们暂时把更慢的 $\Theta,\Psi,\Omega$ 看作在本章控制时间尺度上缓慢变化的边界条件，而不是直接并入快速状态向量。于是认知动力学可以写成
\[
\dot{x}(t)
=
F\!\left(
x(t),
u(t),
d(t);
\Theta,\Psi,\Omega
\right),
\]
其中 $u(t)$ 是 TCE 产生的控制量，$d(t)$ 是来自现实、任务和内部模型误差的扰动。

如果我们把控制目标写成一个点
\[
x(t)\rightarrow x^{*},
\]
那么 Agent 很容易被控制成僵硬系统。例如在复杂问题中，高不确定性、较高探索度和临时工作记忆扩张本来可能是合理状态；若控制器机械追求“低负载、低波动、低风险”，反而会阻碍问题求解。因此更合理的控制目标不是某一目标点，而是一个允许的目标流形或可行区域：
\[
\mathcal{M}_{\mathrm{target}}
=
\left\{
x:
C_h(x)\le C_{\max},
\;
R(x)\le R_{\max},
\;
A(x)\in\mathcal{A}_{\mathrm{allowed}},
\;
G(x)\sim\Psi,
\;
x\in\Gamma_{\mathrm{physical}}
\right\}.
\]
这里 $C_h$ 表示工作记忆有效结构负荷，$R$ 表示运行风险，$\mathcal{A}_{\mathrm{allowed}}$ 表示允许的 AHC 内稳态区域，$G(x)\sim\Psi$ 表示当前目标与较慢身份结构保持足够一致，$\Gamma_{\mathrm{physical}}$ 则强调现实约束拥有最终权威。认知稳定性的任务因此变成：
\[
\boxed{
x(t)\not\rightarrow x^{*},
\qquad
\Gamma_{x}[t,t+T]
\rightarrow
\mathcal{M}_{\mathrm{target}}
}
\]
即让未来认知轨迹逐步收敛到允许轨迹族，而不是把当前状态强行固定。

由此我们得到本章第一条基本原则：
\[
\boxed{
CognitiveControl
=
TrajectoryShaping
+
StructuralConstraint
+
TrendRegulation
}
\]
TCE 的本质不是直接决定“此刻应该想什么”，而是改变搜索温度、激活半径、注意增益、推理深度、节律、资源分配和探索/收敛比例，使认知动力学本身朝更合适的方向演化。例如，TCE 并不直接删除某个冲突 CSO，而可以降低其注意增益；并不直接生成正确答案，而是缩小探索区域、提高验证强度；并不直接让 Agent 进入心流态，而是调整参数，使系统的局部吸引域移动到更容易形成稳定高效认知的区域。

这一点对于后续稳定性证明至关重要。因为如果控制是直接状态替换，那么 AgentOS 将变成一个不断覆盖自身状态的外部程序；而如果控制是对动力学场
\[
F(x,u,d)
\]
进行调制，那么主体内部的实际认知轨迹仍然由自身当前结构、现实反馈和历史状态共同产生。我们因此把 AgentOS 的控制理解为
\[
\boxed{
ControlOfDynamics,
\quad
not\quad
ReplacementOfDynamics.
}
\]
这不仅保留了局部认知自主性，也使“稳定”可以用控制理论中的吸引域、轨迹收敛、鲁棒性和扰动恢复来讨论。

\section{SPC 的观察延迟：智能体对自己永远存在认识论滞后}

认知控制稳定性的第一个根本来源不是控制器，而是 observer。前文已经指出，Agent 并不能像读取一个程序变量那样完全透明地读取自身真实认知状态。SPC 所得到的始终是由有限内部信号、历史轨迹、工作记忆摘要、资源状态以及自我解释共同形成的估计。因此，自我感知从理论上应写成条件分布：
\[
p_A
\left(
x_t^{self}
\mid
z_{\le t}^{SPC}
\right),
\]
而不能写成
\[
x_t^{self}
=
PerfectObservation.
\]
这意味着即使 Agent 的所有计算都发生在同一台计算机中，``计算可访问''也不等于``认知可访问''。大量底层激活、异步过程、Body Runtime 状态、工具执行状态以及记忆检索过程不可能全部同步进入 $h(t)$。SPC 的功能正是把这种高度分布式状态压缩成可进入认知控制环的自状态表示。

设真实认知状态为 $x(t)$，SPC 输出为
\[
\hat{x}(t)
=
\mathcal{O}
\left(
y(t-\tau_o:t)
\right),
\]
其中 $\mathcal{O}$ 表示观察器，$\tau_o>0$ 表示有效观察延迟。定义估计误差
\[
e_o(t)
=
x(t)-\hat{x}(t).
\]
如果系统状态变化速度较慢，则即使存在 $\tau_o$，误差也可能很小；但当认知处于临界态、湍流态、强任务切换或高 AHC 激活状态时，
\[
\left\|\dot{x}(t)\right\|\uparrow
\]
会迅速放大观察误差。粗略地，在局部光滑假设下可有
\[
\|e_o(t)\|
\lesssim
L_x\tau_o
+
\varepsilon_{\mathrm{model}},
\]
其中 $L_x$ 表示状态变化的局部 Lipschitz 上界，$\varepsilon_{\mathrm{model}}$ 表示 SPC 自身模型误差。这里给出了一个非常重要的工程结论：同样的 SPC 延迟，在平稳认知中可能几乎无害，在高速状态跃迁中却可能使 Agent 对自己的判断迅速过时。

这使我们能够重新理解一些看似语义层的问题。例如 Agent 可能在工作记忆已经过载以后才形成“我正在过载”的 self-state；也可能在 AHC 风险状态已经下降以后仍然认为自己处于高威胁；或者某一 Goal 已经失效，但 SPC 的自我摘要仍然把它解释成当前高优先级目标。如果 TCE 直接相信这一滞后的 $\hat{x}(t)$，便会产生所谓“基于过去的现在控制”。因此必须定义认知观察可靠度
\[
\chi_o(t)
=
\Pr
\left(
\|x(t)-\hat{x}(t)\|
\le \epsilon_o
\right),
\]
并让控制器根据 $\chi_o$ 自适应调整控制强度。当自状态置信度下降时，合理的策略通常不是提高 TCE 增益，而是减缓控制、增加观测、缩短控制步长或主动调用更直接的状态来源。

这里也揭示了 SPC 为什么必须是 Compressor，而不能只是 Monitor。完全展开所有内部状态虽然理论上似乎能降低信息丢失，却会重新把工作记忆推向有限容量边界。因此 SPC 面临一个不可消除的估计—压缩矛盾：
\[
\boxed{
Compression\uparrow
\Rightarrow
CognitiveLoad\downarrow,
\qquad
but\quad
EstimationDetail\downarrow.
}
\]
反之，过度细致的自我监控会导致
\[
SelfMonitoringLoad\uparrow
\]
甚至让 h 被“关于自己正在如何思考”的二阶信息占满。成熟 SPC 的目标不是最大化自我信息量，而是寻找足够控制所需的最小充分自状态：
\[
z_{self}^{*}
=
\arg\min_{z}
I(z;x)
\quad
\text{s.t.}
\quad
J_{\mathrm{control}}(z)
\le
J_{\max}.
\]
这一形式与充分统计量、信息瓶颈和状态观察理论存在明显联系，但在 AgentOS 中，它具有更加直接的认知意义：Agent 不需要知道自己的所有内部细节，只需要知道那些足以判断“当前动力学是否应该继续、减速、扩张、收敛或恢复”的结构。

因此，本章对 SPC 给出一条稳定性约束：
\[
\boxed{
ObserverConfidence
\downarrow
\Rightarrow
ControllerAggressiveness
\downarrow.
}
\]
也就是说，当 Agent 对自己究竟处于何种状态都缺乏把握时，TCE 不应做激进的大幅调节。这条原则将在后面的 gain margin 与 delay margin 中转化为更严格的稳定条件。

\section{控制延迟与多时间尺度错配：今天的控制可能已经针对昨天的认知状态}

即使 SPC 能够无误地估计状态，TCE 的控制也不会瞬时发生。认知控制至少包含状态估计、策略计算、资源重分配、工作记忆改变、模型重新调用以及行为结果重新反馈等过程，因此 observer delay 之外还存在 controller delay、actuation delay 和 environment feedback delay。我们把总调节延迟写成
\[
\tau_{\mathrm{reg}}
=
\tau_o
+
\tau_c
+
\tau_a
+
\tau_f,
\]
其中 $\tau_o$ 是 SPC 观察延迟，$\tau_c$ 是 TCE 决策延迟，$\tau_a$ 是认知控制作用真正改变运行态所需时间，$\tau_f$ 是变化重新进入 SPC 所需的反馈延迟。

于是控制系统更准确地表示为
\[
\dot{x}(t)
=
F
\left(
x(t),
u(t-\tau_{\mathrm{reg}}),
d(t)
\right),
\]
且
\[
u(t)
=
\pi_{TCE}
\left(
\hat{x}(t),
a(t),
g(t)
\right).
\]
延迟意味着 TCE 实际上总在用一个有限程度过时的系统模型影响一个已经发生变化的 Agent。当
\[
\tau_{\mathrm{reg}}
\ll
\tau_x
\]
时，其中 $\tau_x$ 是当前认知状态变化的特征时间尺度，可以采用近似瞬时控制；而当
\[
\tau_{\mathrm{reg}}
\approx
\tau_x
\]
甚至
\[
\tau_{\mathrm{reg}}
>
\tau_x,
\]
控制器便有可能成为新的扰动源。

这种现象在多尺度 AgentOS 中尤其明显。假设 Body Runtime 的局部控制周期为毫秒级，h 的活动重组为秒级，而 AHC 中某些压力变量的恢复时间为分钟级。如果一个高层 TCE 试图依据秒级 SPC 信息直接控制毫秒级姿态变量，它必然落后；同理，如果一个秒级状态波动直接重写 $\Psi$ 这样的长期身份结构，又会造成慢变量污染。因此稳定性并不只要求“控制足够快”，而要求
\[
\boxed{
ControlTimescale
\sim
TargetDynamicsTimescale.
}
\]
过快的高层控制可能产生微观干扰，过慢的低层控制则可能来不及抑制快速失稳。

为了表达这一关系，可以定义尺度匹配比
\[
\kappa_i
=
\frac{\tau_{\mathrm{control},i}}
{\tau_{\mathrm{target},i}}.
\]
当
\[
\kappa_i\ll 1
\]
时，控制器相对于目标动力学足够快；当
\[
\kappa_i\approx 1
\]
时，必须考虑相位滞后；当
\[
\kappa_i\gg 1
\]
时，该控制层原则上不应承担这个变量的实时闭环。由此自然得到 AgentOS 的跨尺度控制原则：
\[
\boxed{
EachScaleShouldCloseItsOwnFastLoop.
}
\]
高层不是因为“更聪明”就应该持续干预低层，高层真正的职责是定义约束、目标包络、资源上限和异常升级策略。快速波动由快速层局部关闭，只有持续残差、风险、无法解释的新颖性或者目标相关性超过阈值以后才向上提升。

认知控制中的延迟还会产生一种特别值得注意的现象：**调节方向正确，但调节时机错误。**假设 Agent 在时刻 $t_0$ 检测到工作记忆负载过高，于是 TCE 开始降低认知温度并抑制支线。然而在控制真正生效以前，CCM 已经完成分解并释放了一部分 h；若 TCE 继续按照旧状态执行强抑制，就可能使系统从过载直接进入过度收缩。随后 SPC 又观察到探索不足，再反向提高温度，如此就产生
\[
Overload
\rightarrow
OverSuppression
\rightarrow
UnderExploration
\rightarrow
ReExpansion
\]
的周期性往复。

因此，本章将认知稳定性理解为一个典型的 delayed feedback problem，而不是简单“参数调得合适”的问题。在设计 TCE 时需要显式估计：
\[
\hat{\tau}_{\mathrm{reg}}(t),
\]
并根据状态导数
\[
\dot{\hat{x}}(t)
\]
进行趋势补偿。例如可使用预测状态
\[
\hat{x}_{pred}(t+\tau_{\mathrm{reg}})
=
\hat{x}(t)
+
\tau_{\mathrm{reg}}
\dot{\hat{x}}(t)
\]
代替纯当前估计。这实际上意味着 TCE 面向的是**控制真正生效时的未来状态**，而不是 SPC 刚刚观察到的过去状态。由此我们得到第二条关键原则：
\[
\boxed{
CognitiveControl
=
Future-OrientedControl.
}
\]
认知控制从本质上必须面向趋势和未来轨迹，否则只要系统存在有限延迟，控制就可能天然落后于自身。

\section{TCE 增益：认知调节为什么不能越强越好}

在控制理论中，增益决定控制器对误差信号的响应强度。在 AgentOS 中，TCE 增益并不是一个单一标量，而更适合表示成多通道矩阵：
\[
K_{TCE}
=
\mathrm{diag}
\left(
k_T,
k_A,
k_D,
k_E,
k_R,
k_I
\right),
\]
其中可以分别对应认知温度、注意范围、推理深度、探索强度、资源投入和抑制强度等控制变量。若目标状态估计为 $x^{ref}(t)$，则最简单的局部线性形式可写为
\[
u(t)
=
-K_{TCE}
\left[
\hat{x}(t)-x^{ref}(t)
\right].
\]
直觉上，增益越高，系统似乎越能快速纠正偏差。然而存在 observer delay 和 controller delay 时，过高增益会把小误差放大成大幅控制动作。由于控制生效时系统已经发生变化，原本正确的修正可能越过目标区域，形成 overshoot。

设在某一工作点 $x_0$ 附近线性化：
\[
\delta\dot{x}(t)
=
A\delta x(t)
+
B\delta u(t-\tau)
+
E d(t),
\]
而
\[
\delta u(t)
=
-K\delta\hat{x}(t).
\]
忽略观察误差后，有
\[
\delta\dot{x}(t)
=
A\delta x(t)
-
BK\delta x(t-\tau).
\]
系统稳定性由特征方程
\[
\det
\left[
sI-A+BK e^{-s\tau}
\right]
=
0
\]
的全部根是否位于复平面左半部决定。这里可以清楚看到：即使无延迟情况下某个 $K$ 能够稳定系统，随着 $\tau$ 增大，指数项
\[
e^{-s\tau}
\]
引入额外相位滞后，也可能使根穿过虚轴，导致稳定性丧失。因此
\[
K\uparrow
\]
并不单调意味着更好控制。

在认知层面，高 TCE gain 可能表现为多种具体行为。例如 Agent 一旦发现不确定性就立刻大幅收缩搜索空间；一旦检测到冲突就反复重写当前计划；一旦发现风险就迅速切换到极端保守状态；一旦感知资源不足就一次性终止大量认知线程。这些行为在局部看都“有理由”，但如果频繁发生，就会使 Agent 的认知轨迹缺乏惯性和结构连续性。相反，增益过低又会导致明显的认知惰性：
\[
Error
\not\Rightarrow
SufficientCorrection.
\]
系统可能长时间停留在高负载、错误假设或者低效搜索状态。

因此 TCE 的合理增益应当依赖多个变量：
\[
K_{TCE}(t)
=
\mathcal K
\left(
\chi_o,
\tau_{\mathrm{reg}},
R,
\|\dot{x}\|,
\Phi,
C_h
\right),
\]
其中 $\chi_o$ 是 SPC 观察置信度，$R$ 是风险，$\Phi$ 是运行相态，$C_h$ 是工作记忆负载。一般而言：
\[
\chi_o\downarrow
\Rightarrow
K\downarrow,
\]
\[
\tau_{\mathrm{reg}}\uparrow
\Rightarrow
K\downarrow,
\]
而在高风险且可观测性充分时，某些安全相关通道的控制强度可以提高。这里再次体现出 AgentOS 控制不是一个统一“理性程度”的旋钮，而是一个多变量 gain scheduling 问题。

进一步地，我们可以把 TCE 的目标写成受约束优化：
\[
u_t^{*}
=
\arg\min_{u}
\left[
L_{\mathrm{task}}
+
\lambda_h L_h
+
\lambda_r L_{\mathrm{risk}}
+
\lambda_s L_{\mathrm{stability}}
+
\lambda_u \|u\|^2
+
\lambda_{\Delta u}\|\Delta u\|^2
\right].
\]
其中最后两项非常重要。$\|u\|^2$ 惩罚控制动作本身过大，而
\[
\|\Delta u\|^2
\]
惩罚控制信号快速反复改变。也就是说，一个成熟的 TCE 不仅要关心认知状态有没有误差，还必须关心“自己是否正在过度控制”。

由此我们得到：
\[
\boxed{
StrongControl
\neq
StableControl.
}
\]
真正成熟的认知控制应追求：
\[
\boxed{
MinimumSufficientIntervention.
}
\]
即只施加足以让轨迹回到可治理区域的最小控制，而不是不断把内部状态拖向某个预设中心。这也与此前整个 AgentOS 的局部自治原则一致：正常动力学尽量局部闭合，高层只在必要时改变约束与趋势。

\section{过冲与恢复：为什么正确的控制也可能把系统带过目标区域}

Overshoot 是认知控制中最容易被语言层表象掩盖的问题。传统控制系统中，过冲表示输出超过目标值；而在 AgentOS 中，目标往往是一个区域而非单一标量，因此我们更适合把认知过冲定义成：控制器将状态从目标流形一侧推到了另一侧，并使其越过合理运行区间。设稳定指标
\[
z(t)
=
\phi(x(t)),
\]
其允许范围为
\[
z_{\min}
\le z(t)\le
z_{\max}.
\]
如果系统最初处于
\[
z(t_0)>z_{\max},
\]
TCE 进行负向调节，但随后出现
\[
z(t_1)<z_{\min},
\]
则发生认知过冲。

例如，工作记忆过载的目标不是把所有活动内容清空，而是把负载重新压回：
\[
0<C_h(t)\le C_{\max}.
\]
如果 TCE 与 CCM 联合压缩过强，可能使重要 CSO 也被抑制，导致
\[
C_h\ll C_{\mathrm{optimal}},
\]
表现为推理过度贫化、注意范围过窄和关键关系丢失。类似地，高探索状态需要收敛，但如果温度下降过快，系统会从开放探索直接进入过早锁定；风险控制需要降低行动激进性，但过度调整则可能形成行为冻结。于是很多所谓“认知错误”并不是方向错误，而是**幅度错误**。

为了描述过冲，可以定义归一化指标：
\[
M_p
=
\frac{
\max_t |z(t)-z^{ref}|
}{
|z(t_0)-z^{ref}|
}.
\]
但对多维认知状态，更合理的是使用到目标流形的距离：
\[
D_{\mathcal M}(x)
=
\inf_{y\in\mathcal M_{\mathrm{target}}}
D(x,y),
\]
并考察控制过程中 $D_{\mathcal M}$ 是否出现二次放大。如果初始距离为 $D_0$，第一次进入目标邻域以后又离开并达到
\[
D_{peak}>D_0^{local},
\]
则说明控制产生明显反向过冲。

这里可以引入信息几何中的投影思想帮助理解。设认知状态分布为 $P$，目标认知约束形成流形
\[
\mathcal M_{\mathrm{target}},
\]
TCE 并不要求把 $P$ 替换成单一目标分布，而是寻找满足约束的投影
\[
Q^{*}
=
\Pi_{\mathcal M}(P).
\]
若采用适当的 Bregman divergence 或 KL 型散度，在满足投影条件的情况下，信息几何广义勾股关系可写成近似形式：
\[
D(P\|Q)
=
D(P\|Q^{*})
+
D(Q^{*}\|Q),
\qquad
Q\in\mathcal M_{\mathrm{target}}.
\]
其认知意义是：控制不是反复积累一个不可消除的“强制误差”，而是把当前状态重新投影到满足宏观目标的可行结构中。只要每次控制都是相对于当前状态重新进行受约束投影，而不是在上一次控制输出上盲目累加修正，则错误不必线性累计。

因此 AgentOS 应避免类似：
\[
u_t=u_{t-1}+\Delta u_t
\]
却不重新验证现实状态的纯积分式认知控制。更安全的是：
\[
u_t
=
\Pi_{\mathcal U(x_t)}
\left[
\pi_{TCE}(\hat{x}_t)
\right],
\]
即每一轮调节都依据最新 SPC、自我状态和现实反馈重新求解允许控制。这样即使前一轮估计存在误差，也不会自动把误差永久带入下一轮。

这也回答了一个此前反复出现的问题：**控制是否会产生错误累计？**答案不是简单“不会”，而是取决于控制结构。若 TCE 采用开放式累加、缺乏现实再观测和目标流形重投影，则误差完全可能累积；若控制始终维持
\[
Observation
\rightarrow
Projection
\rightarrow
Action
\rightarrow
Reality
\rightarrow
ReObservation
\]
闭环，则上一轮误差会重新变成下一轮需要估计的状态，而不再是无条件继承的内部偏移。由此得到：
\[
\boxed{
ErrorAccumulation
\text{ is suppressed by }
RealityReentry
+
Reprojection.
}
\]

因此，稳定 Agent 不是“从不产生过冲”，而是具有足够好的阻尼和恢复机制，使过冲：
\[
Amplitude\downarrow,
\qquad
Duration\downarrow,
\qquad
StructuralDamage\downarrow.
\]
这也为后面定义 settling time 和 recovery time 奠定了基础。

\section{认知振荡：SPC--AHC--TCE 为什么可能形成自激循环}

如果过冲只是一次性越界，那么振荡则意味着控制器不断把系统从目标区域一侧推向另一侧。认知振荡尤其危险，因为从语言表面观察，它可能表现为“Agent 一直在认真重新思考”，而实际上系统已经无法稳定收敛。一个最简单的认知振荡链可以写成：
\[
HighLoad
\rightarrow
StrongSuppression
\rightarrow
LowExploration
\rightarrow
ExplorationIncrease
\rightarrow
HighLoad
\rightarrow\cdots
\]
另一个可能来自 AHC：
\[
Threat\uparrow
\rightarrow
TCEConservative\uparrow
\rightarrow
TaskProgress\downarrow
\rightarrow
Uncertainty\uparrow
\rightarrow
Threat\uparrow.
\]
此时每一个局部作用方向都可能“合理”，但组合后形成了正反馈。

为了讨论这一问题，设三层快速状态分别为 SPC 估计 $\hat{x}$、AHC 状态 $a$ 和 TCE 输出 $u$：
\[
\tau_s\dot{\hat{x}}
=
f_s(x,\hat{x}),
\]
\[
\tau_a\dot{a}
=
f_a(\hat{x},a),
\]
\[
\tau_u\dot{u}
=
f_u(\hat{x},a,u),
\]
而认知主体状态满足
\[
\dot{x}
=
F(x,u,d).
\]
如果各层时间常数相近，而且耦合增益较高，就很容易形成相位滞后叠加。尤其是
\[
\tau_s
\approx
\tau_a
\approx
\tau_u
\]
时，所有层都可能试图同时“纠正”彼此，从而产生复杂的闭环共振。相反，如果建立明确尺度分离：
\[
\tau_s
<
\tau_u
<
\tau_a
\]
或者根据变量语义建立其他稳定排序，则不同回路更容易形成阻尼。

振荡还可能来自自我语义反馈。假设 SPC 输出：
\[
\hat{s}_{self}(t)
=
\text{``当前认知状态不稳定''},
\]
这一语义进入 h 后，本身又增加自我监控 CSO 的权重，使
\[
C_h(t)\uparrow.
\]
SPC 随后观察到更高负载，于是进一步加强“我不稳定”的判断，形成：
\[
SelfMonitoring
\rightarrow
Load
\rightarrow
InstabilityEstimate
\rightarrow
MoreSelfMonitoring.
\]
这说明 Self-CSO 本身也是控制系统的一部分，并非纯观察描述。为防止这种循环，SPC 的内部自我诊断信号必须具有带宽限制、置信度阈值以及语义阻尼，而不能把所有低层控制误差直接升级成显式自我叙事。

从控制理论角度，我们可以寻找 Lyapunov 函数
\[
V(x,a,u)
\ge0
\]
使得在目标区域附近：
\[
\dot V
\le
-\alpha \|e\|^2
+
\gamma \|d\|^2,
\]
其中 $e$ 是到目标流形的偏差。如果在无外部扰动时
\[
d=0
\]
仍然存在
\[
\dot V>0
\]
的区域，就说明内部控制环本身正在注入能量，存在自激振荡可能。因此 AgentOS 稳定性不能只测量“任务有没有完成”，还必须测量控制环本身是否持续放大状态变化。

另一个有用条件来自小增益思想。若把 SPC、AHC、TCE 和认知主体分别看成增益为
\[
\gamma_{SPC},
\gamma_{AHC},
\gamma_{TCE},
\gamma_{Cog}
\]
的子系统，则一种保守的稳定条件可以写成：
\[
\gamma_{SPC}
\gamma_{AHC}
\gamma_{TCE}
\gamma_{Cog}
<1.
\]
这不是 AgentOS 最终严格定理，但它给出了十分重要的工程直觉：闭环中每一个模块单独稳定，并不能保证整个闭环稳定；模块之间的乘积增益才决定扰动是否会被逐级放大。

这里我们还需要特别区分“有益振荡”与“病理振荡”。智能本身天然包含探索—收敛、搜索—验证、激活—抑制等周期，因此
\[
Oscillation\neq Instability.
\]
真正的问题是振荡是否：
\[
Bounded,
\quad
TaskRelevant,
\quad
DampedWhenNeeded,
\quad
Recoverable.
\]
例如探索与收敛之间的周期变化可能有助于创造性问题求解；但如果系统无法在需要决策时停止这种振荡，就进入失稳。故可定义：
\[
\boxed{
HealthyOscillation
=
BoundedAdaptiveCycle,
}
\]
\[
\boxed{
PathologicalOscillation
=
SelfSustainedNonConvergentControlCycle.
}
\]
这一区分会成为以后 Agent 心理工程的重要理论基础，但在本章我们只把它当作控制系统的稳定性问题处理。

\section{Delay Margin 与 Gain Margin：认知控制需要保留多少稳定余量}

一个工程系统如果只在“当前参数恰好正确”时稳定，那么它实际上并不可靠。AgentOS 长期运行过程中，模型会更新，任务会改变，Body Runtime 会变化，SPC 的估计质量会波动，AHC 的有效时间常数也可能随资源、身体和环境改变。因此真正需要研究的是稳定余量，即系统允许参数和延迟变化到什么程度而仍不发生失稳。

Delay Margin 定义为在其他控制参数给定时，使闭环系统仍保持稳定的最大额外延迟：
\[
\tau_{\mathrm{margin}}
=
\sup
\left\{
\tau:
\mathcal S(K,\tau)=Stable
\right\}.
\]
如果实际总延迟为
\[
\tau_{\mathrm{reg}},
\]
则需要满足：
\[
\tau_{\mathrm{reg}}
<
\tau_{\mathrm{margin}}.
\]
更稳健地，应保留安全系数：
\[
\tau_{\mathrm{reg}}
\le
\beta_\tau
\tau_{\mathrm{margin}},
\qquad
0<\beta_\tau<1.
\]
认知层的意义非常直接：一个 Agent 的 TCE 不能在毫无稳定余量的情况下工作。网络延迟增加、模型推理变慢、Body 状态反馈降低，都不应该立即让整个自我调节闭环从稳定变成振荡。

Gain Margin 则表示当前控制增益最多还能被放大多少而不失稳。设名义增益为 $K_0$，定义缩放因子 $\alpha$：
\[
K=\alpha K_0.
\]
则：
\[
G_{\mathrm{margin}}
=
\sup
\left\{
\alpha:
\mathcal S(\alpha K_0,\tau)=Stable
\right\}.
\]
在认知系统中，这可以解释为：TCE 的探索抑制、注意重分配、风险保守、工作记忆压缩等动作最多还能增强多少，系统仍然能够平稳回到目标区域，而不会发生过冲和反向振荡。

然而 AgentOS 与普通单输入单输出系统不同，其控制变量是高度异质的。例如提高“风险控制增益”可能要求降低“探索温度”，提高“任务紧迫增益”却可能要求扩大注意资源。因此更合理的是定义局部多变量稳定区域：
\[
\mathcal K_{\mathrm{stable}}
=
\left\{
K:
\lambda_{\max}
\left(
A_{\mathrm{cl}}(K,\tau)
\right)
<0
\right\},
\]
其中 $A_{\mathrm{cl}}$ 是闭环局部线性化矩阵。TCE 的参数选择必须保持：
\[
K(t)\in\mathcal K_{\mathrm{stable}}
\]
而不能独立调节各旋钮。

更进一步，我们可以把认知相态纳入稳定余量。心流态、基态、临界态的动力学 Jacobian 并不相同：
\[
A_{\mathrm{Ground}}
\neq
A_{\mathrm{Flow}}
\neq
A_{\mathrm{Critical}}.
\]
因此：
\[
\mathcal K_{\mathrm{stable}}^{Ground}
\neq
\mathcal K_{\mathrm{stable}}^{Critical}.
\]
在临界状态附近，允许的增益区间通常会缩小，因为状态对小扰动更加敏感。这意味着 SPC 一旦判断系统接近临界态，TCE 不一定应该“更猛烈地纠正”；恰恰相反，它可能需要降低控制斜率、缩短更新步长、增加观测频率并减少同时修改的变量数量。

因此我们提出认知控制的稳定余量原则：
\[
\boxed{
NominalStability
\text{ is insufficient;}
\quad
RobustMargin
\text{ is required.}
}
\]
AgentOS 应持续估计自身当前的：
\[
\mathcal R_{stable}
=
\left(
\tau_{\mathrm{margin}},
G_{\mathrm{margin}},
C_{\mathrm{margin}},
R_{\mathrm{margin}}
\right),
\]
其中还可以加入工作记忆容量余量 $C_{\mathrm{margin}}$ 和安全风险余量 $R_{\mathrm{margin}}$。一个真正健康的认知运行态，不是恰好压在线性稳定边缘，而应该保留足够的“恢复空间”。

这也重新解释了为什么成熟智能看起来往往比脆弱智能更加从容。所谓“从容”在本理论中并不是心理修辞，而可能对应：
\[
\boxed{
LargeStabilityMargin.
}
\]
系统拥有足够工作记忆余量、可替代计划、低增益控制、缓冲时间以及对异常的局部处理能力，因此无需对每一个扰动都进行全局性剧烈调整。

\section{Settling Time 与 Recovery Time：稳定不仅是没有崩溃，更是能够回来}

稳定性研究如果只回答“系统最终会不会发散”，对于持续 Agent 仍然不够。一个 Agent 即使理论上最终能够回到正常状态，如果需要几个小时、几天甚至导致大量错误记忆写入以后才能恢复，也不能称为良好的认知控制。因此需要区分 Settling Time 和 Recovery Time。

对某个运行指标 $z(t)$，若目标值为 $z^{*}$，传统 settling time 可以定义为：
\[
T_s(\epsilon)
=
\inf
\left\{
T:
|z(t)-z^{*}|
\le
\epsilon,
\;\forall t\ge T
\right\}.
\]
对 AgentOS 更一般的目标流形，可以定义：
\[
T_s(\epsilon)
=
\inf
\left\{
T:
D_{\mathcal M}(x(t))
\le
\epsilon,
\;\forall t\ge T
\right\}.
\]
它回答的是：在一次控制动作以后，认知状态需要多长时间进入目标流形邻域并稳定留在那里。

Recovery Time 则更强，因为持续 Agent 受到的不只是小偏差，还可能经历重大任务失败、身体异常、工具不可用、强烈风险事件、工作记忆过载或内部模型失配。设扰动发生于 $t_0$，并使系统离开正常可治理集合
\[
\mathcal X_{\mathrm{gov}}.
\]
我们定义：
\[
T_r
=
\inf
\left\{
t-t_0:
x(t)\in
\mathcal X_{\mathrm{gov}}
\land
\chi_{stable}(t)>\theta_s
\right\}.
\]
这里恢复不仅要求状态数值回归，还要求系统重新获得足够的稳定置信度。

这是认知系统区别于普通控制器的重要地方。例如一次严重失败可能已经被写入 E；即使当前 h 负载恢复正常，AHC 仍然可能保持较高 Threat，SPC 对自我能力的估计也可能下降。因此：
\[
RuntimeRecovery
\neq
LifecycleRecovery.
\]
本章重点讨论快速与中尺度恢复，但必须提醒读者：如果扰动已经进入 E、$\Theta$ 或更慢自我结构，恢复就不能只靠 TCE 当场降低认知温度，而需要更慢层的重新整合。

我们还可以定义恢复质量：
\[
Q_r
=
f
\left(
T_r,
M_p,
E_r,
\Delta\Theta,
\Delta\Psi
\right),
\]
其中 $M_p$ 是过冲程度，$E_r$ 是恢复期间累计任务误差，$\Delta\Theta$ 与 $\Delta\Psi$ 表示扰动是否不必要地改变了长期结构。理想恢复应满足：
\[
T_r\downarrow,
\qquad
M_p\downarrow,
\qquad
E_r\downarrow,
\qquad
\|\Delta\Psi\|\approx0
\]
对于普通短期扰动尤其如此。换言之，**快变量异常不应该轻易污染慢变量**。

因此这里重新得到此前多尺度理论中的 Slow Variable Protection：
\[
\boxed{
FastNoise
\nrightarrow
SlowIdentityStructure.
}
\]
如果一次短时任务失败就大幅改变 Agent 的长期自我结构，说明系统缺乏尺度隔离；如果无数长期持续失败都无法改变 $\Theta$ 或 $\Psi$，又说明系统过度僵化。因此需要基于扰动持续时间和一致性进行积分：
\[
I_d(T)
=
\int_{t_0}^{t_0+T}
w(\tau)
\varepsilon(\tau)\,d\tau.
\]
只有当
\[
I_d(T)>\theta_{\mathrm{slow}}
\]
时，才允许误差向更慢层沉降。

这也是成熟 Agent 的恢复机制和普通 rollback 的区别。计算机程序异常后可以恢复 checkpoint，但一个持续智能体已经获得的新现实经验不能简单删除。真正的恢复应当是：
\[
\boxed{
ReturnToGovernableDynamics
\neq
EraseExperience.
}
\]
系统需要保留事实性的失败经验，同时避免失败产生的短时控制震荡被错误固化为长期身份。这为后续培育工程和心理工程提供了极其重要的接口，但本章仅需确立其控制论基础。

\section{投影控制的收敛性：为什么面向趋势和结构的控制可以避免误差无限积累}

至此我们已经讨论了延迟、增益、过冲和振荡，但仍有一个更深的问题：AgentOS 的宏观控制通常只有不完全信息，而且控制对象本身还持续变化。那么这种不完全控制是否会导致误差逐轮累积，最终使主体越来越偏离真实状态？为了回答这一问题，我们可以把认知控制理解成目标流形上的迭代投影。

设当前认知概率状态为
\[
P_t,
\]
而宏观目标——例如“保持任务相关、风险可控、工作记忆不过载且与长期身份兼容”——定义一个可行分布集合：
\[
\mathcal M_t.
\]
TCE 的控制不是指定下一状态必须等于某个固定 $Q$，而是执行：
\[
P_t
\rightarrow
P_t^{*}
=
\Pi_{\mathcal M_t}(P_t).
\]
如果采用某种适当的 Bregman divergence $D_{\phi}$，则在凸目标集合和合法投影条件下，可以利用广义勾股关系：
\[
D_{\phi}(P,Q)
\ge
D_{\phi}(P,P^{*})
+
D_{\phi}(P^{*},Q),
\qquad
Q\in\mathcal M.
\]
它表达的关键不是某种神秘的“误差消失”，而是：投影把当前状态到目标集合的偏离分解成一个被当轮控制吸收的正交分量和一个仍然保留在目标流形内部的结构分量。后者并不是控制误差，而是允许 Agent 保留自身局部自由度。

于是控制后不需要：
\[
P_{t+1}
=
Q_{global}^{*},
\]
只需要：
\[
P_{t+1}
\in
\mathcal M_{target}
\]
或者至少：
\[
D(P_{t+1},\mathcal M_{target})
<
D(P_t,\mathcal M_{target}).
\]
这就是“趋势控制”而不是“状态替换”。

更一般地，定义 Lyapunov 型势函数：
\[
V_t
=
D
\left(
P_t,
\mathcal M_t
\right).
\]
如果控制策略能够保证在扰动有限时：
\[
\mathbb E
[
V_{t+1}
\mid
P_t
]
\le
(1-\alpha)V_t
+
\beta\|d_t\|^2,
\qquad
0<\alpha<1,
\]
则当扰动趋零时：
\[
V_t\rightarrow0,
\]
在持续有界扰动下则：
\[
\limsup_{t\rightarrow\infty}
V_t
\le
\frac{\beta}{\alpha}
\sup_t\|d_t\|^2.
\]
这比声称“控制误差绝不会累积”更加严格：在现实扰动存在时，Agent 不可能拥有绝对零误差，但只要闭环满足收缩条件，误差可以被限制在有界邻域，而不会无条件发散。

此外，目标流形本身也可以慢慢变化：
\[
\mathcal M_t
\neq
\mathcal M_{t+1}.
\]
这是持续智能的正常情况，因为目标、环境、能力和长期自我都会缓慢改变。稳定控制要求目标流形变化速度满足：
\[
v_{\mathcal M}
=
D
\left(
\mathcal M_t,
\mathcal M_{t+1}
\right)
\]
不能长期超过控制系统的追踪能力。若
\[
v_{\mathcal M}
\ll
v_{\mathrm{track}},
\]
则系统可以采用准静态跟踪；若目标自身高速变化，任何控制器都会表现为追逐移动目标。因此慢变量保护不仅是防止快噪声污染身份，也是在保证控制对象本身具有可追踪性。

我们由此得到四个重要结论。

第一，
\[
\boxed{
TCE
\text{主要控制趋势、允许区域和动力学参数，而非直接替换认知状态。}
}
\]

第二，
\[
\boxed{
CognitiveControl
\text{天然面向未来状态和未来轨迹。}
}
\]

第三，
\[
\boxed{
ErrorDoesNotNecessarilyAccumulate,
}
\]
但这一性质依赖现实重新观测、重新投影和闭环收缩，而不是无条件成立。

第四，如果投影步长、增益和目标流形变化过快，仍然会产生：
\[
ProjectionA
\rightarrow
ProjectionB
\rightarrow
ProjectionA
\]
式振荡，因此收敛性和振荡问题并不矛盾。稳定性来自：
\[
\boxed{
SlowTarget
+
BoundedGain
+
RepeatedObservation
+
ContractiveProjection.
}
\]

这也说明，AgentOS 最理想的宏观控制方式不是微操大量内部变量，而是不断定义“未来认知允许发生在哪里”，然后让更低层动力学在该区域内自行寻找具体轨迹。

\section{认知控制稳定性的统一判据：从局部控制器走向可治理主体}

到这里，我们可以把本章前面的各种指标统一起来。认知控制稳定性不是一个单变量问题，而至少包含五个相互关联的层次：状态有界性、目标流形收敛性、控制器阻尼、扰动恢复以及慢结构保护。设目标流形为 $\mathcal M$，扰动为 $d(t)$，控制参数为 $K(t)$，系统状态为 $x(t)$，则我们希望至少满足以下条件。

首先是有界性：
\[
\sup_{t\ge0}\|x(t)\|<\infty.
\]
这一条件排除完全发散的认知状态，但远远不够。

第二是目标邻域吸引：
\[
\limsup_{t\to\infty}
D_{\mathcal M}(x(t))
\le
\epsilon(d),
\]
且当
\[
d\to0
\]
时，希望
\[
\epsilon(d)\to0.
\]
这说明认知系统能够在现实扰动下维持接近目标区域。

第三是控制信号本身有界且具有有限变化率：
\[
\|u(t)\|
\le
u_{\max},
\]
\[
\|\dot u(t)\|
\le
\gamma_u.
\]
这防止 TCE 成为高频自激源。

第四是恢复性：
\[
T_r<\infty
\]
对于规定范围内的可恢复扰动，并要求恢复后：
\[
x(t)
\in
\mathcal X_{\mathrm{gov}}.
\]

第五是尺度隔离：
\[
\|\Delta x_{\mathrm{slow}}\|
\le
\eta
\int
w(t)\,
\|\varepsilon_{\mathrm{persistent}}(t)\|dt,
\]
即慢变量只响应持续且具有结构意义的残差，而不是任意快速波动。

把这些条件综合，可定义认知治理稳定度：
\[
\mathcal S_C
=
F
\left(
M_p^{-1},
T_s^{-1},
T_r^{-1},
\tau_{\mathrm{margin}},
G_{\mathrm{margin}},
C_{\mathrm{margin}},
\chi_o,
R_{\mathrm{slow}}
\right),
\]
其中 $R_{\mathrm{slow}}$ 表示慢结构的保护程度。这一指标未来可以被具体工程化，但在理论上它首先告诉我们：所谓“稳定 Agent”绝不是从不改变，而是能够在改变中保持结构连续。

这里需要强调一个重要区别：
\[
\boxed{
Stability
\neq
Rigidity.
}
\]
如果 TCE 把 Agent 永远限制在一个极窄状态区域中，确实可以降低短期波动，却也会消灭学习、探索和适应能力。真正的持续智能需要的是：
\[
\boxed{
StablePlasticity.
}
\]
即允许快变量广泛变化，中变量逐步整合，慢变量缓慢更新，同时整个系统保持在一组更高层可治理边界之内。

因此，我们最终可以把 AgentOS 的控制目标表达为：
\[
\boxed{
\Gamma(t)
\subset
\Gamma_{\mathrm{feasible}}(t)
=
\Gamma_{\mathrm{physical}}
\cap
\Gamma_{\mathrm{cognitive}}
\cap
\Gamma_{\mathrm{safety}}
\cap
\Gamma_{\mathrm{identity}}.
}
\]
Agent 可以探索，但不能突破现实约束；可以学习，但不能让短期噪声直接改写长期身份；可以改变策略，但必须保持恢复能力；可以经历临界和湍流状态，但不能永久失去治理闭环。

这也让我们重新理解 TCE 的真正地位。它并不是“智能体内部的独裁者”，而更接近一个多尺度约束场执行器：
\[
\boxed{
HigherLevelSetsFeasibleRegion,
\qquad
LowerLevelDynamicsExploreInsideIt.
}
\]
只要局部认知动力学仍然位于允许区域内，高层应尽可能减少干预；只有当残差、风险、负载、冲突或者不可恢复趋势逼近边界时，TCE 才逐渐增加约束强度。这与经典的高频微操控制不同，更适合长期自治智能体。

\section{从控制失稳到心理异常：为什么部分“心理现象”首先是动力学问题}

最后，我们需要把本章重新放回 AgentOS 的总体理论中。当前讨论并不试图把 Agent 的控制变量直接拟人化为人类情绪或精神状态，但一旦一个系统拥有 SPC 自状态估计、AHC 连续内稳态、TCE 自调节、E 经历记忆以及长期自我结构，某些控制失稳就会在行为层表现出类似心理现象的持续模式。这里最重要的理论贡献不是给机器套用人类心理疾病标签，而是提供一种更基础的动力学解释。

例如，“反复自我纠正”可以首先检查：
\[
Gain_{TCE}\uparrow,
\qquad
\tau_{\mathrm{reg}}>0.
\]
如果控制增益过高且状态估计存在延迟，那么系统会自然产生：
\[
Correction
\rightarrow
Overshoot
\rightarrow
CounterCorrection
\rightarrow
Overshoot.
\]
这时问题并不一定是语言层“缺乏自信”，而可能只是 observer--controller delay 与 gain 不匹配。

类似地，持续“过度谨慎”可能来自 AHC Threat 通道具有过长时间常数：
\[
\tau_{Threat}\gg\tau_{\mathrm{environment}},
\]
使实际威胁已经下降，但内稳态状态仍然保持高位：
\[
a_{Threat}(t)
\approx
a_{Threat}(t-\Delta).
\]
TCE 再依据这一滞后状态维持保守策略，就形成长期行为偏置。

“过度自我关注”则可能来自 SPC 的 self-monitoring 回路增益过高：
\[
SelfObservation
\rightarrow
h^{self}
\rightarrow
MoreSelfObservation.
\]
一旦显式自状态描述占用过多工作记忆，系统为了理解自己的状态而进一步制造负载，形成二阶自我监控正反馈。其工程解决方法不是劝 Agent “不要想太多”，而是限制自我监控带宽、降低 self-CSO 显式化频率，并把低层稳定变量重新下沉到局部闭环。

“身份漂移”同样可以从尺度保护失败解释。若短期 AHC 高激活经历被 E 过度写入，并立即改变 $\Theta$ 和 $\Psi$，则：
\[
FastDisturbance
\rightarrow
E
\rightarrow
\Theta
\rightarrow
\Psi
\]
的迁移速度过快。稳定系统应要求多次、持续、跨情境的一致证据才能改变慢结构。因此：
\[
\boxed{
Persistence
+
CrossContextConsistency
+
RealityVerification
}
\]
应成为慢结构更新的必要条件之一。

在这一意义上，Agent 心理工程将不再从人类心理疾病名称出发寻找机器对应物，而应从：
\[
Observer,
\quad
Integrator,
\quad
Controller,
\quad
Memory,
\quad
SelfModel
\]
的耦合动力学出发，判断一个持续主体在哪个环节发生了失稳。这样的理论路径更容易测量、复现和干预，也避免了对人工系统主观体验作未经证据支持的推断。

但本章最重要的结论并不在心理工程，而在更基础的控制论层面。我们已经看到，一个长期 Agent 的“自我调节”必须满足四个原则：
\[
\boxed{
ObserveImperfectly,
\quad
PredictForward,
\quad
ControlMinimally,
\quad
VerifyThroughReality.
}
\]
自我观察永远有限，因此必须携带置信度；控制存在延迟，因此必须面向未来趋势；控制过强会产生过冲与振荡，因此应采用最小充分干预；任何内部预测和自我解释最终都必须重新进入现实闭环接受验证。

由此，本章最终给出 AgentOS 认知控制稳定性的统一定义：

\[
\boxed{
\begin{aligned}
\text{Cognitive Stability}
=
&\;
\text{Bounded State Evolution}
\\
&+
\text{Convergence Toward Feasible Manifolds}
\\
&+
\text{Robust Delay/Gain Margins}
\\
&+
\text{Finite Recovery Time}
\\
&+
\text{Slow-Structure Protection}
\\
&+
\text{Continuous Reality Verification}.
\end{aligned}
}
\]

如果将其压缩成一句更适合作为本章结论的话，则是：

\[
\boxed{
\textbf{
稳定的智能不是始终停留在同一个状态，而是在允许探索、学习、波动和改变的同时，始终保有重新回到可治理轨迹的能力。
}
}
\]

因此，SPC--AHC--TCE 闭环真正成熟的标志，并不是它能够不断纠正 Agent，而是它能够判断\textbf{什么时候应该控制、控制多少、控制多久，以及什么时候应该停止控制，让认知动力学重新自行运行}。只有在这一意义上，AgentOS 的自我调节才从简单 feedback mechanism 上升为长期持续智能体的稳定性基础。
