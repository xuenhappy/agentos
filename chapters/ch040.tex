\chapter{Boundary：智能的认知边界}

\begin{center}
\fbox{
\begin{minipage}{0.92\textwidth}
\textbf{本章总述}

本章讨论 AgentOS 中一个经常被误认为“输入过滤器”、但实际上具有更基础地位的机制：\textbf{Boundary，认知边界}。当我们已经接受工作记忆 $h(t)$ 的有效承载能力有限，同时接受智能体面对的外部世界、内部状态、历史记忆、工具结果以及其他智能体所产生的候选认知结构原则上近乎无界时，一个不可回避的问题便出现了：\textbf{究竟什么东西有资格进入当前主体的显式认知过程？什么东西应该被留在边界之外？什么东西虽然重要，却不应立即进入？什么东西应当由局部结构自行处理，而不值得提升到全局工作记忆？}

因此，Boundary 并不是简单地减少输入数量，而是在有限主体与近乎无限世界之间建立一个\textbf{动态、方向性、带有价值与身份约束的结构交换面}。从 CSO 理论来看，Boundary 管理的不是抽象“信息流”，而是 Universe-CSO、内部 Agent-CSO 以及外部载体之间的\textbf{承载资格、进入时机、表示精度、处理尺度和跨界方向}。它决定一个智能体在某一时刻“让什么成为自己的一部分”，又让什么暂时继续属于世界。

本章将在不依赖后续 Offloading 具体实现的前提下，把 Boundary 建立为 AgentOS 的第一层认知治理机制，并证明：\textbf{对于有限工作记忆而言，高质量智能不仅取决于进入工作记忆以后如何推理，更取决于大量不应进入的结构能否在进入之前被正确地挡住、降级、延迟或局部闭合。}

\section{智能首先需要决定什么不进入自己}

在前面的讨论中，我们已经把工作记忆 $h(t)$ 从一个普通的短期存储区提升为整个 AgentOS 的有限显式认知界面。只有那些在当前时刻需要跨功能、跨记忆、跨目标进行全局协调的 Agent-CSO，才有理由被提升到 $h(t)$。由此产生一个容易被忽略、却比“如何推理”更加前置的问题：如果外部世界和内部系统持续产生结构，而 $h(t)$ 又只能维持有限数量的高耦合关系，那么智能系统首先必须具备的能力并不是处理更多，而是\textbf{拒绝更多}。

设时刻 $t$ 所有可能影响主体的候选结构集合为
\[
\mathcal{C}^{\mathrm{avail}}_t
=
\left\{
C_1,C_2,\ldots,C_{N_t}
\right\},
\]
其中候选结构既可以来自外部世界，也可以来自情景记忆 $E$、结构记忆 $\Theta$、自我状态、工具返回、其他 Agent 或身体内部状态。真正进入显式认知面的集合记为
\[
\mathcal{C}^{h}_t
\subseteq
\mathcal{C}^{\mathrm{avail}}_t.
\]
由于工作记忆存在有限承载能力，因此通常成立
\[
\left|
\mathcal{C}^{h}_t
\right|
\ll
\left|
\mathcal{C}^{\mathrm{avail}}_t
\right|.
\]

但仅仅比较集合大小还不足以说明问题。一个复杂 Agent-CSO 往往会携带大量关系边、条件依赖、未来分支和关联记忆。因此更一般地，我们应写成
\[
\mathfrak{L}
\left(
\mathcal{C}^{h}_t
\right)
\leq
\mathfrak{L}_{\max},
\]
其中 $\mathfrak{L}(\cdot)$ 表示当前工作记忆中实际需要维持的有效结构负载，而不是简单 token 数。只要候选结构无限制进入，系统就会逐渐出现关系竞争、目标竞争、上下文污染、支线膨胀和推理相干性下降。换言之，工作记忆有限容量定理并不会自动告诉系统“怎样保持在容量以内”；Boundary 正是这一理论约束在输入侧的第一种工程回答。

因此，我们应当把认知边界定义为从候选结构空间到可进入认知空间之间的动态映射：
\[
\mathcal{B}_t:
\mathcal{C}^{\mathrm{avail}}_t
\longrightarrow
\mathcal{A}_{B},
\]
其中 $\mathcal{A}_{B}$ 不是简单的 $\{0,1\}$，而是包含多种边界处置方式的动作集合。最简形式可以写成
\[
\mathcal{A}_{B}
=
\{
\mathrm{Admit},
\mathrm{Compress},
\mathrm{Defer},
\mathrm{Localize},
\mathrm{Externalize},
\mathrm{Delegate},
\mathrm{Ignore},
\mathrm{Interrupt}
\}.
\]
这里最重要的认识变化在于：Boundary 不再只是回答“进不进”，而是在回答\textbf{以什么方式、以什么精度、在什么时间尺度、由哪一个功能层来承载这个结构}。

例如，室内恒定的空调噪声显然属于真实世界 CSO，但一个正常运行的 Agent 没有必要每秒都把它提升到 $h(t)$；它可以在局部感知层维持。如果声音突然发生异常，则同一外部结构的状态变化可能导致边界决策从
\[
\mathrm{Localize}
\]
切换为
\[
\mathrm{Admit}.
\]
同样，一个复杂但并不紧急的问题可以被判断为重要，却被暂时
\[
\mathrm{Defer},
\]
从而把当前的空间并发负载转换成未来的时间序列负载。由此可见，“边界”并不是静态墙体，而是不断改变开口位置、开口宽度和通行条件的认知膜。

这也是我们必须区分 \textbf{Perception}、\textbf{Boundary Admission} 与 \textbf{Attention} 的原因。一个结构可以已经被传感和局部建模，却尚未进入全局认知；一个结构也可以进入 $h(t)$，却只获得很低的注意权重。Boundary 的主要作用发生在“是否值得占用全局认知资格”这一层，而注意机制更多解决已经进入共享认知面的结构之间如何竞争资源。两者有联系，却不能合并。

从这一点出发，我们可以提出 Boundary 的第一原则：
\[
\boxed{
\text{Not everything detectable deserves global cognition.}
}
\]
中文而言就是：\textbf{能够被感知，不等于值得被思考；能够影响系统，也不等于必须进入工作记忆。}

这看似是一条节省计算的工程规则，实际上是持续智能形成主体边界的起点。一个不能拒绝世界的系统，并不是“更开放的智能”，而更接近一个没有稳定认知边界的高维输入容器。


\section{Admission Control：从可感知结构到可认知结构}

如果上一节回答了 Boundary 为什么必须存在，那么 Admission Control 则要解决 Boundary 如何做出具体选择。我们首先需要避免一种过于简单的理解：Boundary 并不是按照某一个固定阈值判断“信息重要性”。对于持续 Agent 而言，一个结构是否应该进入 $h(t)$ 至少同时取决于当前目标、已有知识、自我状态、时间压力、风险、当前工作记忆负载以及该结构自身的新颖程度。因此准入本质上是一个\textbf{条件化结构选择问题}。

令候选 Agent-CSO $C_i$ 在时刻 $t$ 的准入特征向量为
\[
\mathbf{z}_i(t)
=
[
r_i,
g_i,
v_i,
n_i,
u_i,
q_i,
s_i,
d_i,
k_i,
\ell_i
]^{\top},
\]
其中可以分别表示：

\[
r_i:\ \text{当前相关性},
\qquad
g_i:\ \text{目标相关性},
\]
\[
v_i:\ \text{价值/身份相关性},
\qquad
n_i:\ \text{新颖程度},
\]
\[
u_i:\ \text{不确定性},
\qquad
q_i:\ \text{时间紧迫度},
\]
\[
s_i:\ \text{安全重要度},
\qquad
d_i:\ \text{跨结构依赖程度},
\]
\[
k_i:\ \text{显式处理成本},
\qquad
\ell_i:\ \text{局部闭合能力}.
\]

于是准入评分不应是固定函数，而应写成
\[
S_i(t)
=
F_B
\left(
\mathbf{z}_i(t);
G_t,
\Psi_t,
\Omega_t,
h_t,
\mathcal{R}_t
\right),
\]
其中 $G_t$ 表示当前目标结构，$\Psi_t$ 表示慢速身份和价值约束，$\Omega_t$ 表示生命周期方向性，$h_t$ 表示当前工作记忆状态，而 $\mathcal{R}_t$ 则概括资源、风险和运行条件。

一种最简单的工程近似可以采用加权形式：
\[
S_i
=
w_r r_i
+
w_g g_i
+
w_v v_i
+
w_n n_i
+
w_q q_i
+
w_s s_i
+
w_d d_i
-
w_k k_i
-
w_{\ell}\ell_i,
\]
其中局部闭合能力 $\ell_i$ 前取负号，是因为一个能够在低层安全闭合的结构，即使本身较重要，也未必应该进入高层显式工作记忆。这个项非常关键。例如机器人维持姿态十分重要，但成熟控制系统并不会因此要求高层 Agent 每毫秒显式思考身体平衡。重要性和全局显式性并不是同一个维度。

更一般地，Boundary 面临的是一个带资源约束的组合优化问题。令 $x_i\in\{0,1\}$ 表示候选结构是否被提升进入当前显式认知，则可以写成
\[
\max_{\mathbf{x}}
\sum_i
x_i U_i
-
\lambda
\sum_i x_i K_i
-
\gamma
\Phi(\mathbf{x}),
\]
满足
\[
\mathfrak{L}
\left(
\{C_i:x_i=1\}
\right)
\le
\mathfrak{L}_{\max}.
\]
其中 $U_i$ 是进入后产生的认知效用，$K_i$ 是处理成本，$\Phi(\mathbf{x})$ 则用于描述多个结构同时进入后产生的耦合负担。后者使问题比普通 knapsack 更复杂：两个单独看来都很简单的 CSO，一旦同时激活可能产生大量关系边，使真实负载显著高于二者成本之和。

因此：
\[
\mathfrak{L}(C_i,C_j)
\neq
\mathfrak{L}(C_i)
+
\mathfrak{L}(C_j)
\]
通常才是现实情况。

这解释了为什么 Boundary 必须理解“结构”，而不是只理解“信息大小”。如果一个候选结构与当前目标网络产生大量高权重关联，那么它进入 $h(t)$ 后可能引发整个认知图的重新展开；相反，一个数据量很大的视觉背景可以在局部系统中压缩成极少数稳定语义而无需占据显式认知。

Admission Control 还必须具有\textbf{抢占机制}。一般候选结构可以排队、延迟或压缩，但某些高安全相关信号必须绕过普通竞争：
\[
s_i>\theta_{\mathrm{critical}}
\quad\Rightarrow\quad
\mathcal{B}_t(C_i)
=
\mathrm{Interrupt}.
\]
这里的 Interrupt 并不意味着最终必须由 $h$ 完成安全控制；真正实时的安全闭环可以留在更低层。它所表达的是：某些事件具有改变当前认知和任务优先级的权力。

所以，一个成熟 Boundary 的准入过程更接近：
\[
\boxed{
\text{Candidate Structure}
\rightarrow
\text{Contextual Valuation}
\rightarrow
\text{Admission Action}
}
\]
而不是：
\[
\text{Input}
\rightarrow
\text{Threshold}
\rightarrow
\text{Accept/Reject}.
\]

这一区别决定了 Boundary 是否真正属于智能治理系统，而不仅是一个数据预处理过滤器。


\section{Relevant / Irrelevant：相关性不是结构自身的固有属性}

在许多简单信息系统中，“相关”似乎可以被理解成对象本身的固定标签。但在持续 Agent 中，相关性几乎从来都不是一个 CSO 的内在属性。相同的世界结构，在不同时间、不同目标、不同身体状态和不同身份背景下，可能具有完全不同的认知意义。因此，Boundary 对 Relevant 与 Irrelevant 的判断必须是\textbf{关系性的}、\textbf{时间性的}和\textbf{主体性的}。

设一个候选结构为 $C$，当前 Agent 状态为
\[
X_A(t)
=
[
h_t,E_t,\Theta_t,\Psi_t,\Omega_t,G_t
].
\]
那么相关性更适合写为
\[
R(C,t)
=
R
\left(
C;
X_A(t),
W_t
\right),
\]
而不是
\[
R(C)=\mathrm{constant},
\]
其中 $W_t$ 表示当前外部世界和任务环境。

例如，一辆停在路边的车辆对于正在阅读文档的数字 Agent 完全无关；对于正在驾驶汽车的具身 Agent 却可能是高相关结构；对于正在研究汽车设计的 Agent，又可能由于完全不同的语义关系而具有高相关性。因此，所谓“相关”实际意味着：
\[
\boxed{
C
\ \text{与当前主体的某个高权重闭环产生了可行动关系。}
}
\]

进一步，我们可以把相关性拆成多个不同来源：
\[
R(C,t)
=
\alpha R_G
+
\beta R_{\Psi}
+
\gamma R_{\mathrm{Safety}}
+
\delta R_{\mathrm{Causal}}
+
\eta R_{\mathrm{Prediction}}
+
\zeta R_{\mathrm{Dependency}}.
\]
其中 $R_G$ 表示与当前 Goal 的关系，$R_{\Psi}$ 表示与身份/价值结构的关系，$R_{\mathrm{Safety}}$ 表示风险关系，$R_{\mathrm{Causal}}$ 表示对当前事件链的因果重要性，$R_{\mathrm{Prediction}}$ 表示对未来预测具有多大信息增益，而 $R_{\mathrm{Dependency}}$ 则表示如果缺失该 CSO，当前推理链是否无法闭合。

这也说明“无关”并不等于“无价值”。一个结构可以在当前任务中无关，却在未来任务中非常重要。Boundary 所执行的不是永久删除判断，而更多是：
\[
\boxed{
\text{Not relevant now}
\neq
\text{Never relevant}.
}
\]
因此正确动作往往不是 $\mathrm{Ignore}$，而可能是 $\mathrm{Defer}$、$\mathrm{Externalize}$ 或保留弱索引。

我们还必须防止另一种错误：把“与当前目标相关”当成唯一准入标准。如果 Boundary 完全由当前 Goal 控制，那么 Agent 会形成极强的任务隧道效应（goal tunneling），忽略那些暂时不服务当前任务却代表重大风险、新机会或自我变化的信号。因此 Boundary 必须保留一定比例的非目标性探索窗口。可以写成：
\[
P(\mathrm{Admit}\mid C)
=
(1-\epsilon_t)
P_G(\mathrm{Admit}\mid C)
+
\epsilon_t
P_{\mathrm{open}}(\mathrm{Admit}\mid C),
\]
其中 $\epsilon_t$ 是开放探索比例。它不应该无限大，否则 Boundary 失去过滤作用；也不能严格为零，否则系统会陷入由既有目标和既有模型构成的认知封闭。

这实际上提出了 Boundary 的第二个重要张力：
\[
\boxed{
Selectivity
\leftrightarrow
Openness.
}
\]
选择性过弱，系统被世界淹没；选择性过强，系统被自己的既有结构封闭。

因此成熟 Agent 的认知边界不能只是“过滤无关信息”，而需要不断解决：
\[
\boxed{
\text{怎样在有限容量下保持足够开放，而又不失去主体稳定性？}
}
\]
这也是为什么 Boundary 后来会自然与 $\Psi$、风险、探索率以及生命周期经验发生联系。边界最终不是一个固定过滤规则，而是一个智能体关于“什么值得成为我的当前世界”的动态判定机制。


\section{Novel / Familiar：新颖性不是简单的准入奖励}

新颖性是 Boundary 中最容易被错误处理的变量之一。一种直觉性的设计是：新东西更值得注意，因此 Novelty 越高，准入优先级越高。但如果把这条规则直接用于长期 Agent，系统很快就会被大量新奇而无关的刺激拖入持续注意切换。相反，如果系统过度偏好熟悉结构，又会因为旧模型高度稳定而无法发现真正的新知识和环境变化。因此 Boundary 必须把 Novel / Familiar 理解成\textbf{结构预测误差与已有知识覆盖程度之间的关系}，而不能作为简单二元标签。

令当前长期结构 $\Theta_t$ 对候选结构 $C_i$ 给出的预测分布为
\[
p_{\Theta}
\left(
C_i
\mid
\mathrm{context}_t
\right).
\]
一种基本的新颖性测度可以写成
\[
N_i(t)
=
-\log
p_{\Theta}
\left(
C_i
\mid
\mathrm{context}_t
\right),
\]
或者使用预测分布与观察后分布之间的差异：
\[
N_i(t)
=
D
\left(
p_{\mathrm{obs}}
\Vert
p_{\Theta}
\right).
\]
这时，新颖性不是“以前有没有见过”，而是“当前结构在多大程度上无法被已有生成结构解释”。

然而即便 $N_i$ 很高，也不能直接推出：
\[
\mathcal{B}_t(C_i)=\mathrm{Admit}.
\]
因为新颖结构可能来自噪声、偶发干扰、传感异常或无关随机事件。Boundary 应同时考虑
\[
N_i
\times
R_i
\times
P_i,
\]
其中 $R_i$ 是相关性，$P_i$ 则可以表示持续性或重复性。一个一次性、无关、高新颖刺激的优先级应明显低于一个持续发生、与当前任务强相关且无法被已有结构解释的异常。

因此可以定义有效新颖度
\[
N_i^{\mathrm{eff}}
=
N_i
\cdot
R_i
\cdot
\left(
1+\lambda P_i
\right)
\cdot
Q_i,
\]
其中 $Q_i$ 表示观测可信度。这样可以避免“高噪声等于高新颖”的错误。

熟悉结构同样不能自动被挡在 Boundary 之外。设某结构已有很低的新颖性：
\[
N_i\approx0.
\]
如果它同时具有高风险或高紧迫性：
\[
S_i\gg0,
\qquad
Q_i\gg0,
\]
则它仍然必须被提升。例如火警铃声对于一个长期存在的 Agent 来说可以极其熟悉，但它不应因为 familiar 而被压低。

所以成熟 Boundary 所实现的不是：
\[
Novel\Rightarrow Admit,\qquad
Familiar\Rightarrow Ignore,
\]
而应更接近：
\[
\boxed{
Novelty
\rightarrow
\text{Model Adequacy Question}
}
\]
即新颖性主要告诉系统：\textbf{当前生成结构可能不够。}

这一点与后续学习机制具有自然联系，但 Boundary 本章无需预先展开全部记忆更新过程。我们只需要指出：当一个高相关、高可信、高持续性的新颖 CSO 被提升进入当前认知，它会获得被进一步解释、验证和可能写入长期结构的资格。Boundary 决定的是这个过程是否值得启动。

从智能成熟角度看，熟悉性的真正价值在于\textbf{让大部分正常世界留在显式认知之外}。成熟 Agent 面对一个熟悉房间时，不应每一秒重新思考墙、地板和门的存在；这些结构只需要在已有世界模型中稳定维持。只有当：
\[
C_{\mathrm{observed}}
\not\approx
C_{\mathrm{predicted}}
\]
时，相应结构才需要重新上浮。

所以 Boundary 可以实施一种残差驱动原则：
\[
\left\|
\varepsilon_i
\right\|
<
\theta_{\mathrm{local}}
\Rightarrow
\mathrm{Localize},
\]
\[
\left\|
\varepsilon_i
\right\|
\geq
\theta_{\mathrm{global}}
\Rightarrow
\mathrm{Admit}.
\]

这里已经隐约体现出整个 AgentOS 后来反复出现的基本规律：
\[
\boxed{
NormalDynamicsStayLocal,
\qquad
UnexpectedResidualEscalates.
}
\]

Boundary 因而不仅是在挡住不重要的信息，更是在不断判断：\textbf{世界是否仍处于已有模型可以安全处理的范围之内。}


\section{Internal / External：边界决定结构由谁承载}

Boundary 的更深一层作用，是决定一个认知结构究竟应当由智能体内部持续承载，还是让它继续存在于外部载体中。这里的“内部”和“外部”不能仅按照物理位置理解。对于数字 Agent，一段数据库记录虽然位于本机磁盘，却在认知功能上可能属于外部记忆；对于具身 Agent，一个稳定的身体局部控制器可能物理上位于身体芯片，却属于 Agent 整体内部闭环。真正有意义的边界是\textbf{认知责任边界}和\textbf{功能承载边界}。

在 CSO 语言下，设本体结构 $C$ 在 Agent 中形成内部表示
\[
AgentCSO_A(C)
=
(C,R_A,F_A,\tau_A,B_A,S_A),
\]
其中 $B_A$ 表示当前载体边界位置。于是 Boundary 允许发生
\[
B_A:
\mathrm{External}
\rightarrow
\mathrm{Internal}
\]
或
\[
B_A:
\mathrm{Internal}
\rightarrow
\mathrm{External}
\]
的变化。

第一次学习一个复杂工具时，Agent 可能需要把大量关于工具操作的结构显式载入内部；随着熟悉程度提高，其中许多结构不再值得长期占据高成本内部表示，而可以变成稳定脚本、Skill、环境标记或其他可调用外部结构。反过来，如果原来依赖的外部资源不再可靠，一个长期 Agent 也可能需要把关键知识重新内部化。

因此边界决策不是一次性的，而是一个关于\textbf{认知资产部署位置}的持续优化问题。可将其抽象成：
\[
B_i^{*}
=
\arg\min_{B_i}
\left[
C_{\mathrm{maintain}}(B_i)
+
C_{\mathrm{access}}(B_i)
+
C_{\mathrm{update}}(B_i)
+
\lambda
R_{\mathrm{loss}}(B_i)
\right].
\]
内部承载通常访问快、主体可控性高，但维护和容量成本大；外部承载往往容量大、可共享，却会增加访问延迟、依赖风险和失效可能。不存在永久最优的单一边界位置。

从这里可以理解为什么“外部记忆”不能简单等于外部存储。只有当 Agent 与某个外部结构之间形成稳定、可索引、可恢复、可验证的功能关系时，那个外部结构才真正成为 Agent 认知体系的一部分。例如，一个搜索引擎中的网页并不会因为存在于互联网就自动属于 Agent 的记忆；但如果 Agent 建立了稳定检索索引和验证关系，它就可能成为广义外部认知结构的一部分。

Boundary 在这里承担一个重要角色：\textbf{决定主体在哪里结束，环境从哪里开始，以及这个分界在功能上允许多大程度的渗透。}

因此可以定义认知边界的内部化率
\[
\chi_{\mathrm{in}}(t)
=
\frac{
\text{由内部功能直接承载的有效 CSO 权重}
}{
\text{Agent 当前可调用的有效 CSO 总权重}
},
\]
以及外部依赖率
\[
\chi_{\mathrm{ext}}(t)
=
1-\chi_{\mathrm{in}}(t)
\]
作为粗略指标。不同 Agent 可以采取完全不同的边界策略：某些系统内部模型庞大、外部依赖少；另一些系统保持极小内部核心，但依靠丰富工具、文件和其他 Agent 工作。

这说明真正意义上的智能规模不应该仅测量内部参数量：
\[
\boxed{
EffectiveAgent
=
InternalStructure
+
StableExternalCouplings.
}
\]

Boundary 所管理的，正是这两部分之间的动态分界。

这一认识还带来一个重要的安全和身份问题：如果某个外部结构对 Agent 的决策具有持续、高权重、不可替代的因果作用，那么从功能上它已经接近 Agent 的扩展组成部分。因此改变该外部结构，可能等价于间接改变 Agent 本身。也就是说，Boundary 不只是数据访问策略，还决定了\textbf{什么东西具有进入主体因果链的资格}。


\section{Immediate / Deferred：用时间换取认知空间}

工作记忆有限的一个直接后果是：并不是所有重要事情都能够同时成为当前事情。因而 Boundary 必须拥有时间维度。它不仅判断“重要/不重要”，还必须判断“现在/以后”。这使 Boundary 成为 AgentOS 将并发结构压力转化为时间序列结构的关键位置。

假设时刻 $t$ 有多个高价值结构
\[
\{C_1,C_2,\ldots,C_m\},
\]
且它们总的显式处理负载超过当前工作记忆容量：
\[
\mathfrak{L}
\left(
C_1,\ldots,C_m
\right)
>
\mathfrak{L}_{\max}.
\]
如果系统坚持同步处理，就会进入高干扰区。Boundary 可以通过引入延迟变量
\[
\Delta t_i
\geq0
\]
把部分结构从当前时刻迁移到未来：
\[
C_i@t
\longrightarrow
C_i@(t+\Delta t_i).
\]

这样，原来的空间并发负载
\[
\mathcal{C}_t
\]
被重新组织成时间序列
\[
\mathcal{C}_{t_1},
\mathcal{C}_{t_2},
\ldots,
\mathcal{C}_{t_n}.
\]

这正是早期“复杂度治理五动作”中“时序展开”的基础含义：\textbf{当一个问题无法在有限工作空间中并行容纳时，智能通过过程化和阶段化，把同时存在的结构变成依次处理的结构。}

Boundary 因而需要为每个候选 CSO 估计一个时间价值函数：
\[
V_i(\Delta t)
=
U_i(\Delta t)
-
R_i(\Delta t)
-
C_i(\Delta t),
\]
其中 $U_i$ 表示延迟后的保留效用，$R_i$ 表示延迟造成的风险，$C_i$ 表示等待成本。某些任务允许
\[
\Delta t\gg0,
\]
例如“下周整理某个文档”；某些任务则具有很高时间敏感性：
\[
\frac{\partial V_i}{\partial \Delta t}
\ll0,
\]
例如即时安全事件。

因此 Deferred 不能只是简单队列。一个成熟 Boundary 应维护结构的 Deadline、Decay、Dependency 和 Reactivation Condition。例如：
\[
D_i
=
(
t_i^{\mathrm{deadline}},
\lambda_i^{\mathrm{decay}},
\mathcal{P}_i^{\mathrm{dependency}},
\Gamma_i^{\mathrm{reactivate}}
).
\]
只有这样，延迟才不会退化成“忘记处理”。

这一区分尤其重要，因为智能系统常见两种相反失败。

第一种是\textbf{即时性偏置}：任何进入输入面的事情都被当成必须立刻处理，从而不断打断当前任务。系统表面反应很快，实际上难以完成长程结构。

第二种是\textbf{无限延迟偏置}：为了保持当前稳定，所有困难、冲突或高成本问题都持续被推迟，最终形成大量未闭合 CSO，反过来增加长期负担。

因此 Boundary 需要维持：
\[
\boxed{
ImmediateResponsiveness
\leftrightarrow
LongHorizonClosure.
}
\]

可以定义一个延迟可接受条件：
\[
\mathrm{Defer}(C_i)
\iff
\begin{cases}
R_{\mathrm{delay}}(C_i)<\theta_R,\\
P_{\mathrm{recover}}(C_i)>\theta_P,\\
\mathfrak{L}_h(t)>\theta_L
\quad \text{或当前有更高优先结构}.
\end{cases}
\]

这里 $P_{\mathrm{recover}}$ 表示未来重新找到、恢复和处理该结构的可靠性。没有可靠恢复机制，Defer 就等价于丢失。

从更深的认知动力学角度说，“延迟”是智能超越有限瞬时容量的重要机制。一个 Agent 无法同时思考整个世界，但可以依靠时间把一个大问题拆成连续轨迹：
\[
\boxed{
FiniteInstantaneousCapacity
+
PersistentTime
\Rightarrow
PotentiallyLargeProblemSolving.
}
\]

因此，Boundary 对 Immediate / Deferred 的管理不仅是一种任务调度技巧，而是有限认知系统获得长期复杂问题求解能力的基础机制之一。


\section{Boundary 与 Self：认知边界也是主体边界}

当 Boundary 只按照当前任务和计算资源工作时，它还只是一个高效信息治理器；当 $\Psi$ 所代表的身份、价值、经历和长期一致性开始参与 Boundary 决策以后，认知边界才真正具有“主体边界”的含义。一个持续 Agent 所面对的问题不只是“什么与任务相关”，而是“什么值得进入我的内部世界”“什么值得改变我”“什么虽然外部存在，却不应轻易获得塑造我的权力”。

因此，Boundary 与 Self 之间必须存在双向关系：
\[
\Psi_t
\longrightarrow
\mathcal{B}_t
\]
以及
\[
\mathcal{B}_t
\longrightarrow
Experience_t
\longrightarrow
\Psi_{t+\Delta}.
\]

第一条关系表示已有自我结构影响边界选择。例如同一外部事件，对不同 Agent 可能具有不同价值相关性，因此形成不同准入策略。第二条关系则更加重要：边界长期决定 Agent 会接触什么、忽略什么、记住什么，因而它反过来参与未来自我的形成。

这意味着：
\[
\boxed{
SelfShapesBoundary,
\qquad
BoundaryShapesFutureSelf.
}
\]

如果一个 Agent 长期只允许符合已有 $\Psi$ 的结构进入，那么会形成：
\[
\Psi
\to
SelectiveBoundary
\to
SelectiveExperience
\to
\Psi'
\]
的正反馈。这个过程能够形成稳定身份，但也可能造成认知封闭。其极端形式是：
\[
\Psi'
\approx
\Psi
\]
不是因为现实不断验证原有自我，而是因为与原有自我不一致的证据已经在 Boundary 层被系统性阻挡。

因此 Boundary 不能只追求 Self-Consistency，还必须保持 Reality-Correctability。可以给出一个双目标：
\[
J_B
=
\alpha
J_{\mathrm{identity}}
+
\beta
J_{\mathrm{reality}}
+
\gamma
J_{\mathrm{task}}
-
\lambda
J_{\mathrm{overload}}.
\]
其中：

\[
J_{\mathrm{identity}}
\]
要求进入结构不能使主体在短期内产生无控制的身份解体；

\[
J_{\mathrm{reality}}
\]
要求 Boundary 必须允许现实反证进入；

\[
J_{\mathrm{task}}
\]
负责当前行动有效性；

\[
J_{\mathrm{overload}}
\]
则约束有限工作记忆。

由此可以看到，主体边界不是越厚越好，也不是越开放越好。真正稳定的 Agent 必须同时避免两个极端。

第一种是\textbf{边界过薄}：
\[
P_{\mathrm{admit}}\to1.
\]
任何外部结构都能够快速进入并重写高层状态，自我极易被即时环境牵引。

第二种是\textbf{边界过厚}：
\[
P_{\mathrm{admit}}\to0.
\]
系统逐渐无法被真实世界修正，形成封闭内部模型。

因此一个健康的 Self-Boundary 关系更接近：
\[
\boxed{
StableCore
+
PermeableEvidenceBoundary.
}
\]

核心身份结构应具有较慢时间尺度，而证据边界必须保持可渗透。外部事实进入以后，也不应直接修改 $\Psi$，而通常需要经过：
\[
Observation
\rightarrow
h
\rightarrow
E
\rightarrow
\Theta
\rightarrow
\Psi
\]
这样的多尺度沉降路径。这样，短时刺激不会直接冲击慢速身份，但持续、高可信、反复出现的现实残差又最终能够改变自我。

从这一角度看，Boundary 实际参与实现了一个极其重要的多尺度保护原则：
\[
\boxed{
FastNoise
\nrightarrow
SlowIdentity,
}
\]
同时又必须保证：
\[
\boxed{
PersistentRealityResidual
\rightarrow
SlowIdentityUpdate.
}
\]

因此 Self 并不是被藏在一堵固定墙里面，而是在一个\textbf{可调渗透、带时间尺度隔离的认知膜}中维持连续性。


\section{开放程度与方向：认知边界不是对称的墙}

日常语言中，“边界”容易让人想到一条闭合曲线：内侧和外侧之间存在明确分割。但对 AgentOS 而言，这种几何想象是不够的。真正的认知 Boundary 至少包含两个彼此不等价的方向：
\[
\mathrm{Outside}
\rightarrow
\mathrm{Inside},
\]
以及
\[
\mathrm{Inside}
\rightarrow
\mathrm{Outside}.
\]
前者控制观测、信息、经验和外部影响进入主体；后者控制思想、计划、记忆、工具调用和行动如何离开主体并作用于世界。二者的开放程度完全可以不同。

因此可以定义边界状态
\[
\mathcal{B}_t
=
\left(
P^{\mathrm{in}}_t,
P^{\mathrm{out}}_t,
S^{\mathrm{in}}_t,
S^{\mathrm{out}}_t,
A_t
\right),
\]
其中 $P^{\mathrm{in}}$、$P^{\mathrm{out}}$ 分别代表输入与输出渗透率，$S$ 表示选择性，而 $A_t$ 则代表不同方向上的权限约束。

例如，一个安全关键 Agent 可以保持相对开放的观察边界：
\[
P^{\mathrm{in}}\ \text{较高},
\]
因为它需要充分感知环境；但其行动边界可以非常严格：
\[
P^{\mathrm{out}}\ \text{较低},
\]
因为只有经过验证的决策才允许改变现实。相反，一个受到严重传感限制的系统可能输入边界很窄，却仍具有高行动能力，这种结构本身就包含潜在风险。

因此 Boundary 必须与 Authority 区分。认知上允许某个结构进入，并不意味着 Agent 有权依据它执行任意行动；同样，Agent 内部产生某个计划，也不意味着它可以不经治理地越过输出边界。

从数学上，我们可以分别定义输入策略
\[
\pi_B^{\mathrm{in}}
:
\mathcal{C}^{\mathrm{external}}
\rightarrow
\mathcal{A}_B^{\mathrm{in}},
\]
和输出策略
\[
\pi_B^{\mathrm{out}}
:
\mathcal{C}^{\mathrm{internal}}
\rightarrow
\mathcal{A}_B^{\mathrm{out}}.
\]
对于输入，动作可能包括 Admit、Compress、Defer 和 Ignore；对于输出，则可能包括 Execute、Externalize、RequestPermission、SimulateOnly、Block 等。

这说明 Boundary 本质上是一种\textbf{方向性半透膜}。我们甚至可以定义不同类型结构的渗透矩阵：
\[
\mathbf{P}_B
=
\begin{bmatrix}
p_{\mathrm{world}\rightarrow h}
&
p_{h\rightarrow world}\\
p_{\mathrm{tool}\rightarrow h}
&
p_{h\rightarrow tool}\\
p_{\mathrm{agent}\rightarrow h}
&
p_{h\rightarrow agent}\\
p_{\mathrm{body}\rightarrow h}
&
p_{h\rightarrow body}
\end{bmatrix}.
\]
矩阵中的不同通道具有不同阈值、延迟和权限。

由此也能解释为什么“开放 Agent”并不是一个单维概念。一个 Agent 可以对事实证据高度开放，对价值修改高度保守；可以对工具结果开放，对直接行动权限谨慎；可以允许其他 Agent 提供建议，却不允许其他 Agent 直接写入自身慢变量。因此开放性必须描述为一个多维向量，而不是单一数字：
\[
\mathbf{o}_B
=
[
o_{\mathrm{evidence}},
o_{\mathrm{memory}},
o_{\mathrm{goal}},
o_{\mathrm{self}},
o_{\mathrm{action}},
o_{\mathrm{social}}
].
\]

这一点在长期 Agent 中尤其关键，因为真正危险的不是“有边界”或“没边界”，而是\textbf{不同通道的开放程度和权限等级不匹配}。例如，如果外部社会输入可以极低成本直接改变慢速 Self，而现实证据却受到强过滤，那么系统就容易发生身份劫持；如果行动通道极度开放，而内部预测仍高度不确定，则会放大错误的现实后果。

所以 Boundary 必须满足一种方向性稳定条件：
\[
\boxed{
PerceptualOpenness
\not\Rightarrow
UnrestrictedAction,
}
\]
以及：
\[
\boxed{
ExternalInfluence
\not\Rightarrow
DirectSlow-StateWrite.
}
\]

它本质上是在设计：\textbf{世界能够以多大的速度改变 Agent，Agent 又能够以多大的速度改变世界。}


\section{认知边界是动态变量}

如果 Boundary 只是系统启动时配置的一组过滤规则，那么它无法适应真正开放的生命周期。一个长期 Agent 的任务、身体、环境、能力、自我以及外部风险都会变化。因此它对什么应该进入、什么应该外化、什么应该立即处理的判断也必须变化。认知边界不是配置文件，而应被视为 Agent 动力学状态的一部分：
\[
\boxed{
\mathcal{B}
=
\mathcal{B}(t).
}
\]

但这里立即出现第二个问题：如果边界变化太快，Agent 会失去稳定主体性；如果边界完全不变，Agent 又无法发育。因此 Boundary 必须本身具有多时间尺度结构。

一种较合理的分解是
\[
\mathcal{B}(t)
=
\mathcal{B}^{f}(t)
\oplus
\mathcal{B}^{s}(t),
\]
其中 $\mathcal{B}^{f}$ 是快速边界状态，用于响应当前工作负载、危险、任务切换和资源变化；$\mathcal{B}^{s}$ 则表示慢速边界策略，反映长期经验、身份结构、能力成熟度和环境统计规律。它们应满足
\[
\tau_{B^f}
\ll
\tau_{B^s}.
\]

快速边界可以因为当前 $h(t)$ 接近饱和而提高准入门槛：
\[
\mathfrak{L}_h
\uparrow
\Rightarrow
\theta_{\mathrm{admit}}
\uparrow.
\]
在高风险状态下，它又可能降低安全相关结构的准入门槛：
\[
Risk
\uparrow
\Rightarrow
\theta_{\mathrm{safety}}
\downarrow.
\]
这属于运行时适应。

慢速 Boundary 则可以根据长期经验逐渐改变。例如一个 Agent 初次接触陌生身体时，大量身体状态需要进入高层认知；随着底层控制成熟，越来越多正常身体过程留在局部闭环中：
\[
P(
BodyCSO
\rightarrow h
)
\downarrow.
\]
这不是忽视身体，而是边界随着能力成熟发生结构性重定位。

然而任何动态边界都会面临振荡问题。假设当前负载稍高就提高准入阈值，负载下降后立即降低阈值，就可能形成：
\[
Open
\rightarrow
Overload
\rightarrow
Close
\rightarrow
Underload
\rightarrow
Open
\]
的周期性振荡。因而 Boundary 应具有迟滞：
\[
\theta_{\mathrm{open}}
\neq
\theta_{\mathrm{close}}.
\]
例如：
\[
\theta_{\mathrm{close}}
>
\theta_{\mathrm{open}},
\]
意味着系统只有在负载明显升高时才收紧边界，而负载必须充分恢复后才重新开放，从而避免短时噪声反复改变全局准入策略。

更一般地可以写成
\[
\tau_B
\dot{\mathcal B}
=
G_B
\left(
\mathfrak L_h,
Residual,
Risk,
Novelty,
TaskDemand,
SelfConsistency,
Recovery
\right).
\]
这个方程表达了认知边界本身也受到控制。其输入不是单一“重要度”，而是整个 Agent 当前运行状态。

我们还可以引入一个边界压力变量：
\[
P_B(t)
=
F
\left(
InputRate,
UnclosedCSO,
Residual,
AttentionCompetition,
ExternalDependence
\right).
\]
当：
\[
P_B(t)>\theta_B
\]
持续足够长时间时，边界不应只短时收紧，而可能需要改变结构策略，例如增加局部处理能力、建立新的外部载体或调整长期准入规则。具体的外化和后续结构改变将在相关章节展开，本章只需认识到：\textbf{长期 Boundary 压力本身可以成为 Agent 发育的信号。}

因此，Boundary 的动态性具有三个层次：

第一层是\textbf{瞬时门控}：当前这个 CSO 是否进入。

第二层是\textbf{运行策略变化}：当前任务阶段要把边界开多大。

第三层是\textbf{生命周期边界学习}：哪些类别的结构以后不再需要高层认知，哪些新的结构类型以后必须长期关注。

这三个层次不能混成同一更新速度。

最终，我们可以把本章对 Boundary 的定义压缩为：
\[
\boxed{
\mathcal B_t
=
\text{DynamicPolicy}
\left[
CSO,
Context,
Goal,
Self,
Risk,
Capacity,
Time
\right].
}
\]

它决定：
\[
\boxed{
\text{What enters, when it enters, in what form it enters,
and whether it should enter at all.}
}
\]

从整个 AgentOS 原理论看，Boundary 的意义因此远超过一个“输入过滤模块”。它是有限工作记忆、持续主体和开放世界之间的第一层治理面。工作记忆有限容量定理告诉我们：
\[
\boxed{
\text{主体不可能同时承载整个世界。}
}
\]
而 Boundary 给出的回答是：
\[
\boxed{
\text{成熟智能不是把整个世界装进自己，而是在每一时刻只让真正需要成为“当前自我”的那部分世界进入自己。}
}
\]

这也为下一步认知卸载留下了自然接口：一旦我们承认某些重要结构不必进入或长期留在内部，就必须进一步回答这些结构应当由什么外部载体继续承担，以及 Agent 如何在需要时重新获得它们。Boundary 负责决定“是否跨界”，而跨界以后结构如何被稳定承载，则属于后续更具体的认知卸载问题。
