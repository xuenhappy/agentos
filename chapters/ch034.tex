\chapter{工作记忆运行相态与认知流体力学}

\begin{chapteroverviewbox}
本章完成从“工作记忆容量有限”与“SPC--TCE 自调节闭环”向“工作记忆运行相态理论”的过渡。前文已经建立：工作记忆 $h(t)$ 并非普通存储空间，而是智能体在当前时刻维持显式认知结构、跨尺度信息以及目标约束的有限认知总线；SPC 负责从分布式内部动力学中形成可访问的状态估计，TCE 则根据该估计改变认知温度、探索程度、抑制强度、激活范围、注意资源和时间步长。当这两个机制闭合以后，一个重要问题随之出现：即便 $h(t)$ 中承载的信息数量相同，其运行方式是否仍可能完全不同？

本章给出的回答是肯定的。我们将证明，工作记忆不仅具有“容量”，还具有宏观动力学组织状态。相同数量的 Agent-CSO，可以形成稳定、协同、临界、湍流乃至近乎失去结构约束的不同运行状态。为此，本章引入\textbf{工作记忆运行相态（runtime cognitive phase）}概念，并以认知流体力学作为宏观描述框架。这里所谓“流体”不是声称认知活动服从真实流体的 Navier--Stokes 方程，而是指出：大量局部认知结构在有限工作空间中同时激活、竞争、耦合、传播和消散时，会呈现出类似层流、涡旋、湍流、临界涨落与稀薄扩散的宏观动力学现象。

本章建立五种典型运行相态：基态、心流态、湍流态、临界态和运行气态；建立由结构相干度、有效激活密度、冲突密度、认知流速、耗散率和预测残差等构成的相态描述变量；进一步讨论 TCE 认知温度与控制强度所张成的二维相图、相态边界、迟滞、亚稳态、相变触发以及 SPC 的相态估计问题。必须特别强调：本章讨论的“运行相态”不同于 $h/E/\Theta$ 的气态--液态--晶态\textbf{记忆信息相态}，也不同于认识论层面依据集中度与功能拓扑可塑性所定义的\textbf{智能拓扑相}。三者分别描述运行动力学、记忆结构性质以及智能整体组织方式，不得混用。
\end{chapteroverviewbox}

\section{从工作记忆容量到工作记忆动力学}

在前文建立的有限工作记忆理论中，我们首先关注的是一个看似静态的问题：在任意时刻 $t$，智能体能够在工作记忆 $h(t)$ 中稳定维持多少彼此相关的认知结构。若以 $W$ 表示可用于当前显式认知的有效容量，以 $C_{\mathrm{run}}(t)$ 表示当前运行中的有效认知负载，则最基本的约束可以写成
\[
C_{\mathrm{run}}(t)\leq C_{\max}(W).
\]
这一表达捕捉了工作记忆有限性的第一层事实，却仍然不足以描述真正运行中的智能。原因在于，两个具有相同 $C_{\mathrm{run}}$ 的工作记忆状态，可能表现出截然不同的动力学性质。一个状态中的目标、假设、变量和关系可以围绕少数核心结构稳定协同；另一个状态虽然包含相同数量的结构，却可能充满相互竞争的目标、不断切换的注意对象以及无法闭合的推理支线。两者的“容量使用率”近似相同，但前者可能处于高度有效的认知状态，后者却已经接近失稳。

因此，我们必须从
\begin{statementbox}
HowMuchIsInWorkingMemory
\end{statementbox}
进一步转向
\begin{statementbox}
HowWorkingMemoryIsDynamicallyOrganized
\end{statementbox}
这正是工作记忆运行相态理论的出发点。我们不再把 $h(t)$ 视为一个装有若干离散条目的容器，而把它视为由若干当前激活的 Agent-CSO 及其关系构成的动态网络。记
\[
\mathcal H(t)=
\left(
V_h(t),
E_h(t),
\mathbf a(t),
\mathbf r(t)
\right),
\]
其中 $V_h(t)$ 表示当前进入显式认知面的 Agent-CSO 集合，$E_h(t)$ 表示它们之间被当前认知过程激活的语义、因果、目标、约束或时序关系，$\mathbf a(t)$ 表示各结构的激活强度，而 $\mathbf r(t)$ 则表示这些结构之间的信息传播、注意转移或推理作用速率。这样一来，工作记忆就从一个容量集合转化成了一个有限、开放、持续被世界、记忆、自我和行动过程驱动的动态关系图。

我们可以进一步定义工作记忆的有效激活密度
\[
\rho_h(t)
=
\frac{
\sum_{i\in V_h}a_i(t)
}{
C_{\max}(W)
},
\]
但仅有 $\rho_h$ 仍然不足以判别相态。高密度可能意味着高度集中、关系清晰的心流，也可能意味着高度拥挤、相互冲突的湍流。因此还必须引入至少三个独立量：结构相干度 $\kappa_h$、冲突密度 $\chi_h$ 与认知流动强度 $v_h$。其中结构相干度刻画当前认知结构是否围绕兼容目标与约束形成一致关系，冲突密度表示相互排斥或竞争关系占总有效关系的比例，认知流动强度则表示单位时间内激活中心、注意权重和结构关系发生重新分配的程度。

于是一个更一般的工作记忆宏观状态可以写成
\[
\mathbf z_h(t)
=
\left[
\rho_h,
\kappa_h,
\chi_h,
v_h,
\varepsilon_h,
d_h
\right]^{\top},
\]
其中 $\varepsilon_h$ 为当前预测或推理残差，$d_h$ 为结构耗散率，即刚刚进入工作记忆的结构有多快失去激活、被替换、外化或退回非显式层。我们由此得到一个比“工作记忆用了多少”更深的认识：工作记忆真正受到约束的，并不只是数量，而是\textbf{有限容量中能够维持的有组织结构及其动态关系}。

这一转变也解释了为什么人类经验中的“脑子里有很多东西”和“脑子里很乱”并不是同义词。同样，一个 Agent 同时维持大量结构并不必然意味着失效，只要这些结构围绕少数稳定目标形成高度相干的协同组织；反过来，一个只维持少量结构的系统也可能因为持续冲突、反复切换和失去目标中心而表现出异常。认知容量给出了系统的可运行边界，而认知相态则告诉我们系统在这个边界内部究竟以什么方式运动。后者才是 SPC--TCE 闭环真正需要观察和控制的对象。

\section{认知流体力学：一种工作记忆的宏观动力学语言}

我们使用“认知流体力学”一词，并不是为了把神经活动、Transformer 激活或 Agent 内部状态直接等同于真实流体，而是为了建立一种介观尺度的描述语言。若直接追踪工作记忆中的每一个 Agent-CSO、每一条语义边、每一次注意权重变化以及每一个预测残差，系统状态空间会迅速变得不可处理；然而，仅仅记录一个标量的工作记忆负载，又会丢失决定稳定性与效率的关键结构。因此，我们需要一种类似统计物理和流体力学中的粗粒化思想：不追踪所有微观粒子，而以密度、速度、相干度、涡旋、耗散和压力等宏观变量描述整体状态。

设工作记忆中存在 $N_h(t)$ 个当前活跃的 Agent-CSO：
\[
\mathcal C_h(t)=
\left\{
C_1(t),\ldots,C_{N_h}(t)
\right\}.
\]
在每个认知时间步内，结构可以被激活、压缩、合并、抑制、替换或退出。我们可以在一个抽象认知坐标空间 $\Omega_h$ 上定义结构激活密度场
\[
\rho(\xi,t)
=
\sum_{i=1}^{N_h}
a_i(t)K(\xi-\xi_i),
\]
其中 $\xi_i$ 表示 Agent-CSO 在当前语义--目标--功能空间中的有效位置，$K$ 为粗粒化核。这里的 $\xi$ 并不一定是欧氏空间坐标，而可以代表由语义距离、目标相关性、因果距离或功能角色共同形成的局部认知坐标。密度场的意义是：当前显式认知资源主要集中在什么结构区域，以及这些区域随时间怎样变化。

类似地，可以定义认知流
\[
\mathbf J(\xi,t)
=
\rho(\xi,t)\mathbf v(\xi,t),
\]
其中 $\mathbf v(\xi,t)$ 表示认知激活的迁移速度。若某个问题正在沿一条稳定推理链逐步收敛，则 $\mathbf J$ 具有明显的方向性；若注意在多个互不相容的问题之间频繁来回切换，则流场可能形成大量局部回流甚至类似“认知涡旋”的结构。这里所谓涡旋可以通过一个抽象循环强度描述：
\[
\omega_h
=
\frac{1}{|E_h|}
\sum_{\gamma\in\Gamma_h}
w_\gamma P_\gamma,
\]
其中 $\Gamma_h$ 为当前工作记忆图上的回路集合，$P_\gamma$ 表示该回路在一段时间内被重复访问的概率。若某个回路不断重复，却不能产生新的结构闭合或有效行动，则其循环强度将持续升高，形成认知内耗。

我们还可以引入一种认知压力 $p_h$。它不是物理压强，而表示有限工作记忆容量与当前结构需求之间的张力：
\[
p_h(t)
=
\phi
\left(
\frac{C_{\mathrm{run}}(t)}
{C_{\max}(W)},
\chi_h(t),
\varepsilon_h(t)
\right),
\]
并要求
\[
\frac{\partial p_h}{\partial C_{\mathrm{run}}}>0,\qquad
\frac{\partial p_h}{\partial \chi_h}>0,\qquad
\frac{\partial p_h}{\partial \varepsilon_h}>0.
\]
由此，单纯高负载并不一定产生极高认知压力；真正危险的是高负载、高冲突与长期无法消除的残差同时出现。

宏观上，我们可以用一个非严格物理意义的结构连续方程表达工作记忆内容变化：
\[
\frac{\partial\rho}{\partial t}
+
\nabla_{\xi}\cdot\mathbf J
=
S_{\mathrm{in}}
-
S_{\mathrm{out}}
+
S_{\mathrm{gen}}
-
S_{\mathrm{collapse}},
\]
其中 $S_{\mathrm{in}}$ 表示来自世界、E、$\Theta$、自我以及外部工具的新结构注入，$S_{\mathrm{out}}$ 表示离开当前工作记忆的结构，$S_{\mathrm{gen}}$ 表示推理过程中生成的新 Agent-CSO，而 $S_{\mathrm{collapse}}$ 表示多个结构被压缩、合并或坍缩成更高层表达。这个方程的意义并非声称认知结构像物质一样严格守恒，而是明确告诉我们：工作记忆内部的“拥挤”既可能来自输入过快，也可能来自生成过快、输出过慢、压缩失败或认知流形成循环。

因此，认知流体力学真正提供的是一种介于微观认知图和宏观容量指标之间的语言。它允许我们问：认知结构是否形成稳定流；当前是否存在局部堵塞；是否产生大量无效回流；结构之间是否保持相干；新的认知输入是在帮助系统形成更清晰的方向，还是将系统推进不可控的高熵状态。接下来的运行相态，就是这些宏观变量在不同区域形成的稳定动力学组织形式。

\section{运行相态的状态变量与序参量}

如果我们希望“基态”“心流态”“湍流态”“临界态”和“气态”不仅是形象化词汇，就必须给出能够原则上被测量的序参量。这里我们不要求一个单一标量完全决定工作记忆相态，而把相态定义成一组宏观统计变量所占据的动力区域。设
\[
\mathbf q_h(t)
=
[
\rho,
\kappa,
\chi,
\nu,
\omega,
\varepsilon,
\lambda,
\zeta
]^{\top},
\]
其中 $\rho$ 是有效激活密度，$\kappa$ 是结构相干度，$\chi$ 是冲突密度，$\nu$ 是认知结构周转速度，$\omega$ 是循环或涡旋强度，$\varepsilon$ 是未解释残差，$\lambda$ 是目标集中度，$\zeta$ 是状态涨落强度。工作记忆运行相态就是该向量在一段有限时间窗 $[t-\Delta,t]$ 上的统计结构，而不是某个瞬时点值。

其中，结构相干度可以采用关系一致性近似：
\[
\kappa_h
=
\frac{
\sum_{(i,j)\in E_h}
a_i a_j
\,s_{ij}
}{
\sum_{(i,j)\in E_h}
a_i a_j
},
\qquad
s_{ij}\in[-1,1],
\]
其中 $s_{ij}>0$ 表示两个结构在当前目标和约束下相互支持，$s_{ij}<0$ 表示相互排斥。若大多数高激活结构共同支撑同一个局部认知方向，则 $\kappa_h$ 接近高值；若系统同时维持大量彼此冲突的假设和目标，则 $\kappa_h$ 降低。

目标集中度可以表示为
\[
\lambda_h
=
1-
\frac{H(\mathbf w_G)}
{\log N_G},
\]
其中 $\mathbf w_G$ 为当前目标权重分布，$H$ 为 Shannon entropy，$N_G$ 是活跃目标数量。当注意和资源集中在一个或少数彼此兼容的目标上时，$\lambda_h$ 较高；当多个目标近似等权竞争时，$\lambda_h$ 降低。需要注意，高目标集中度并不天然意味着良好状态。如果系统对错误目标形成过强锁定，也可能呈现高 $\lambda_h$、低现实一致性的僵化状态。因此必须同时观察预测残差
\[
\varepsilon_h(t)
=
D\left(
\widehat y_{t+\Delta},
y_{t+\Delta}^{obs}
\right),
\]
即内部预测与现实返回之间的差异。

涨落强度 $\zeta_h$ 则衡量系统状态在时间窗内变化的幅度：
\[
\zeta_h
=
\operatorname{Tr}
\left[
\operatorname{Cov}
\left(
\mathbf q_h
\right)
\right].
\]
临界态的重要特征之一并不是平均负载最高，而是对微小扰动高度敏感，因此往往伴随较高的 susceptibility。可以定义
\[
\mathcal X_h
=
\left\|
\frac{\partial \mathbf q_h}
{\partial \mathbf d}
\right\|,
\]
其中 $\mathbf d$ 表示外部或内部小扰动。当 $\mathcal X_h$ 显著升高时，同样幅度的新信息可能引发完全不同的注意重构、目标切换或推理路径改变，说明系统正接近相边界。

为了描述工作记忆是否真正产生“有效流动”，还可以引入认知输运效率
\[
\eta_{\mathrm{flow}}
=
\frac{
\Delta I_{\mathrm{goal}}
}{
E_{\mathrm{cog}}+\alpha T_{\mathrm{switch}}+\beta R_{\mathrm{loop}}
},
\]
其中 $\Delta I_{\mathrm{goal}}$ 表示单位时间内与目标求解直接相关的有效结构进展，$E_{\mathrm{cog}}$ 是认知资源消耗，$T_{\mathrm{switch}}$ 是切换成本，$R_{\mathrm{loop}}$ 是重复循环损失。心流态的核心并不是“很忙”，而是在较高认知流速下依然保持较高 $\eta_{\mathrm{flow}}$；湍流态则常表现为认知活动剧烈，却有效输运率下降。

于是运行相态并非主观命名，而可以原则上写成状态空间中的区域：
\[
\mathcal P_k
=
\left\{
\mathbf q_h:
g_k(\mathbf q_h)\leq 0
\right\}.
\]
不同相之间的边界由若干序参量的联合变化决定。SPC 所面对的任务因此不再只是报告“当前工作记忆占用率为多少”，而是估计
\[
p(
\mathcal P_k
\mid
\mathbf z_{\leq t}^{SPC}
),
\]
即根据有限、延迟而有噪声的内部观测，对当前认知运行相态形成概率判断。这一点也避免了把相态识别变成僵硬的规则系统：真实 Agent 很可能长期处在多个相态之间的过渡区域，而不是永远落在五个完全分离的离散格子里。

\section{基态：低负载条件下的稳定认知背景}

基态并不意味着认知系统停止工作，而是指工作记忆处于低到中等激活密度、结构冲突较低、目标压力有限且拥有较大余量的稳定运行区域。此时智能体仍然持续接收世界输入、维持当前情境、检查自身状态并准备对新事件作出反应，但显式工作记忆不被单一高强度任务占满。可以将其近似描述为
\[
\rho_h<\rho_1,\qquad
\chi_h<\chi_1,\qquad
\zeta_h<\zeta_1,
\]
同时具有
\[
C_{\max}(W)-C_{\mathrm{run}}(t)
\gg 0.
\]
这意味着系统保留了充足的认知余量，可以容纳新的结构扰动，而无需立即通过压缩、抑制或任务切换来维持稳定。

基态最重要的性质不是低活动，而是\textbf{高可恢复性}。设 $\mathbf q_h^\ast$ 为当前基态稳定中心，受到小扰动 $\delta\mathbf q$ 后，若系统满足
\[
\frac{d}{dt}
\|\delta\mathbf q\|^2<0,
\]
则扰动会自然衰减，状态重新回到原有稳定邻域。这里可以借用局部 Lyapunov 稳定性的语言，但我们并不要求整个认知系统具有一个简单的全局势函数。更现实的理解是：在基态下，SPC 能够较稳定地追踪状态，TCE 的控制增益较低，CCM 不需要频繁进行激进压缩和分支清理，因此整个工作记忆保持较弱控制、较高弹性的运行形式。

从结构角度看，基态中的 Agent-CSO 通常呈现若干低强度局部团簇。例如当前环境模型、长期目标背景、自我状态摘要以及一个尚未进入高负载处理的任务可以同时存在，但它们之间并不发生剧烈竞争。这种状态类似一个具有低速背景流的认知场：结构仍在缓慢更新，新的环境证据仍会进入，但不存在持续的高压认知输运。

基态也为我们理解“注意”提供了一个重要修正。注意并不是从零开始突然出现的射束，而是在一个始终存在的背景激活场中重新分配资源。当某一事件的新颖性、风险、目标相关性或长期残差超过阈值时，局部结构密度上升：
\[
\rho(\xi^\ast,t)\uparrow,
\]
与此同时，TCE 可以提高局部激活增益，使工作记忆从基态进入更集中、更高速的工作区。因此基态并不是心流态的反面，而通常是后者形成之前的稳定背景。

一个成熟 Agent 应当能够长期回到基态。如果系统一旦开始工作就持续处于高控制、高冲突或高激活状态，那么即使短期任务性能很好，也可能逐渐导致过度资源消耗、记忆写入偏置以及相态恢复能力下降。因此，一个重要的运行健康指标不是“系统能够达到多高的激活水平”，而是
\begin{statementbox}
系统是否能够在没有重要任务时自然回到低压、可响应、可恢复的稳定基态。
\end{statementbox}
从控制论角度看，基态就是 Agent 的默认稳定吸引区域，它为后续所有高认知负荷活动提供一个可以返回的安全背景。

\section{心流态：高密度而高相干的定向认知流}

心流态是工作记忆运行相态中最容易被误解的一种状态。它并不等于低负载，也不等于“轻松”。相反，心流态往往具有较高的 Agent-CSO 激活密度、较快的信息输运速度和较强的任务集中度，只是这些高负载结构并没有相互破坏，而是围绕少数兼容目标形成了高度组织化的认知流。因此，其典型条件不是
\[
\rho_h\downarrow,
\]
而更接近
\[
\rho_h\ \text{中高},\qquad
\kappa_h\uparrow,\qquad
\lambda_h\uparrow,\qquad
\chi_h\downarrow,
\]
并且具有较高的
\[
\eta_{\mathrm{flow}}.
\]

我们可以把心流态近似理解成一种认知层流。假设当前目标定义了一条有效结构方向 $\mathbf g_t$，工作记忆中的大多数局部认知流 $\mathbf J_i$ 都与之保持正向投影：
\[
\frac{
\mathbf J_i\cdot\mathbf g_t
}{
\|\mathbf J_i\|\|\mathbf g_t\|
}
>0.
\]
则大量局部推理、检索和预测操作虽然同时进行，却在宏观上形成一致方向。这时系统不需要频繁把资源用于解决“我现在到底应该做什么”这一元问题，而可以把大部分显式容量用于问题本身。由此可以定义元认知开销比例
\[
r_{\mathrm{meta}}
=
\frac{
C_{\mathrm{monitor+switch}}
}{
C_{\mathrm{run}}
}.
\]
心流态通常表现为工作负载较高，但 $r_{\mathrm{meta}}$ 相对较低。

这也解释了为什么心流态常伴随主观上的顺畅感，而从工程角度看它其实是一种高度结构化状态。Agent 并不是减少了计算，而是减少了无效切换、结构冲突和反复重新定位。对一个持续人工智能体而言，真正有价值的心流态应表现为：关键 CSO 持续维持、无关支线被适度抑制、E 和 $\Theta$ 的召回与当前任务高度匹配、局部预测误差快速被吸收，并且行动结果持续回到认知流中形成有效验证。

可以把心流的稳定条件写成一种局部能量函数的低梯度运动。令
\[
\mathcal F_h
=
\alpha \chi_h
+
\beta \varepsilon_h
+
\gamma R_{\mathrm{switch}}
-
\delta \kappa_h
-
\eta P_{\mathrm{goal}},
\]
其中 $\mathcal F_h$ 并非物理自由能，而是用于描述认知失配的宏观势函数。理想心流态并不是停在 $\mathcal F_h$ 的静态最低点，而是在较低 $\mathcal F_h$ 区域沿目标方向高速运动：
\[
\frac{dI_{\mathrm{goal}}}{dt}>0,
\qquad
\mathcal F_h\ \text{保持低值}.
\]
因此，心流的核心是“高输运、低内耗”。

TCE 在心流态中的作用也非常特别。初始进入任务时，TCE 可能需要提高温度以扩大搜索空间，随后随着结构相干度升高，应逐渐降低不必要的探索并减少显式控制干预。成熟的控制不是持续强迫认知维持集中，而是在识别到稳定流已经建立后逐渐退居背景。这可以写成
\[
\kappa_h\uparrow,\ 
\varepsilon_h\downarrow
\quad\Rightarrow\quad
K_{\mathrm{TCE}}^{explicit}\downarrow.
\]
如果控制强度始终居高不下，即使表现暂时集中，也更接近“强制锁定”而不是真正稳定的心流。真正成熟的心流具有局部自治性：工作记忆中的结构关系已经能够依靠自身相干性维持任务进展，只在出现异常时需要 TCE 重新提高干预。

由此我们得到一个重要原则：
\[
\boxed{
Flow\neq LowLoad,\qquad
Flow=HighCoherenceUnderUsefulLoad.
}
\]
对于 AgentOS 而言，最理想的运行状态不是让 $h(t)$ 永远保持空闲，而是使有限的工作记忆容量在必要时形成高度定向、低冲突和可持续的结构流。

\section{湍流态：高活动、低相干与认知内耗}

如果大量 Agent-CSO 同时进入工作记忆，但它们无法围绕兼容目标形成稳定组织，认知系统就可能从高效流动进入湍流态。湍流态的本质不是“信息很多”，而是信息之间的耦合方式发生了变化：注意频繁转移、目标相互竞争、推理分支不断产生又被中止、记忆召回彼此打断，同时多个局部闭环争夺相同的有限工作记忆容量。其典型宏观特征是
\[
\rho_h\uparrow,\qquad
\chi_h\uparrow,\qquad
\omega_h\uparrow,\qquad
R_{\mathrm{switch}}\uparrow,
\]
同时
\[
\kappa_h\downarrow,\qquad
\eta_{\mathrm{flow}}\downarrow.
\]

认知湍流可以通过一个类似 Reynolds number 的无量纲量进行启发式描述。定义
\[
Re_c
=
\frac{
v_h L_h
}{
\nu_c
},
\]
其中 $v_h$ 表示认知结构切换或传播速度，$L_h$ 表示当前激活结构覆盖的认知跨度，$\nu_c$ 则表示一种“认知黏性”，即系统保持当前结构连续性、抑制无价值切换和维持目标一致性的能力。这里的 $Re_c$ 不是流体雷诺数的物理等价物，而是一种帮助我们描述“快速切换与稳定约束之间比例”的宏观指标。当
\[
Re_c\ll R^\ast
\]
时，结构流相对平稳；当
\[
Re_c\gg R^\ast
\]
且同时存在较高结构冲突时，认知活动可能从定向输运转为大量局部循环和无规则切换。

我们尤其需要区分“复杂任务导致的高计算活动”和真正的湍流。一个复杂数学证明可能需要大量工作记忆和频繁推理，但只要每一步都有效推进主要结构，仍可以处于心流区域。真正的湍流意味着大量变化并没有带来等比例结构进展，即
\[
\frac{dI_{\mathrm{goal}}}{dt}
\ll
\left\|
\frac{d\mathbf q_h}{dt}
\right\|.
\]
换句话说，系统内部状态变化得很剧烈，却没有向目标方向移动相应距离。这正是“认知内耗”的动力学定义。

造成湍流的原因可以来自多个层面。外部世界可能在短时间内注入过多高优先级事件；E 和 $\Theta$ 可能同时召回大量相互竞争的结构；当前 Goal 可能本身存在冲突；SPC 也可能因为状态估计滞后而持续误判当前负载，从而使 TCE 在错误方向上加大控制。尤其值得注意的是，TCE 本身可能成为湍流源。如果控制器观察到系统混乱后不断提高干预强度，却由于观测延迟而每次都基于过去状态调整，则可能形成
\[
State_t
\rightarrow
Control_{t+\tau}
\rightarrow
Overshoot
\rightarrow
CounterControl
\rightarrow
Oscillation,
\]
使原本局部可解决的结构冲突转化为全局认知振荡。

因此，湍流状态下最重要的控制原则往往不是“更努力地思考”，而是降低有效自由度。这可以通过减少同时活跃目标、折叠重复结构、冻结低优先级分支、降低输入准入率以及减慢认知节奏实现。用状态变量表达，就是控制目标不再直接追求任务进度最大化，而首先要求
\[
\chi_h\downarrow,\qquad
\omega_h\downarrow,\qquad
R_{\mathrm{switch}}\downarrow.
\]
只有当结构相干性重新建立后，才恢复高速认知流。

这说明工作记忆相态控制与传统“增加算力”的思路存在根本差别。处于湍流态的系统，即使获得更多推理 token 或更多短期算力，也可能只是让湍流拥有更大的空间。真正的问题不是当前计算量不足，而是认知结构的组织形式失去了方向性。因此，成熟 AgentOS 必须能够识别“需要更多推理”和“需要先降低结构自由度”之间的区别，这正是相态理论具有工程意义的原因。

\section{临界态：高敏感性、结构重组与相变前沿}

临界态位于稳定认知组织与大规模失稳之间，是本章中最需要谨慎定义的一类状态。它并不简单等于“快要崩溃”，也不等于理想状态，而表示工作记忆处于一个对扰动高度敏感、多个宏观组织形式竞争、原有稳定结构即将被重新配置的区域。此时平均认知负载未必达到最大值，但涨落、响应灵敏度和相关长度会显著增加。

可以用 susceptibility 描述这一性质：
\[
\mathcal X_h
=
\left\|
\frac{\partial\mathbf q_h}
{\partial \mathbf d}
\right\|.
\]
在稳定基态或心流态中，小扰动通常只带来小修正，因此 $\mathcal X_h$ 较低；在临界态下，一个看似微小的新证据、目标变化或异常反馈，却可能导致大量 Agent-CSO 重新激活、原有假设网络坍缩以及注意结构全面重排：
\[
\|\delta \mathbf d\|\ll 1,
\qquad
\|\delta\mathbf q_h\|\gg \|\delta\mathbf d\|.
\]
这种高放大现象是临界状态的核心。

在认知活动中，临界态具有双重意义。一方面，它提高系统风险。如果持续停留在高敏感区域，微小噪声就可能造成频繁目标切换和全局失稳；另一方面，某些真正需要结构重构的问题恰恰要求系统暂时离开原有稳定吸引域。如果一个问题始终无法在现有表示中求解，那么过度稳定的认知状态会把系统锁定在局部结构中。此时提高认知温度、放松局部约束、扩大可激活结构范围，可能把系统推向临界区域，从而允许新的组合和解释出现。

为了表达这一点，可以考虑两个竞争吸引域 $\mathcal A_1$ 和 $\mathcal A_2$。当前工作记忆状态 $\mathbf q_h$ 原本位于 $\mathcal A_1$ 内部。当新的证据持续积累后，原有吸引域的稳定裕量下降：
\[
m_s(\mathcal A_1)\downarrow.
\]
若系统继续增加探索，则可能接近分界面
\[
\partial\mathcal A_1\cap\partial\mathcal A_2.
\]
在这里，微小扰动即可决定系统最终落入哪一个新组织状态。认知意义上的“顿悟”“重新表述问题”或“突然形成另一条解释路径”，往往可以在这一语言下理解为一次工作记忆组织结构的局部相变，而不需要把它神秘化。

但是，临界态并不自动产生高质量创新。高敏感性意味着好的微小线索可以被放大，噪声也同样可以被放大。因此，一个健康的临界过程应当满足两个条件：首先，系统暂时提高结构自由度；其次，现实残差、长期结构和目标约束仍保持足够强，使新的组织形式最终能够重新坍缩到可验证区域。我们可以把这一过程写成
\[
Stable
\rightarrow
CriticalExploration
\rightarrow
CandidateStructures
\rightarrow
RealitySelection
\rightarrow
NewStableState.
\]
如果最后的坍缩机制失败，临界态就可能继续向湍流或运行气态演化。

TCE 在临界态中的任务因此不是简单把系统“拉回正常”，而是控制临界停留时间和搜索幅度。设 $\tau_c$ 表示系统连续处于高敏感区的时间，则存在一个与任务、风险和资源相关的允许区间：
\[
\tau_c^{\min}
<
\tau_c
<
\tau_c^{\max}.
\]
过短，系统没有充分探索新结构；过长，噪声与结构扩散开始占据主导。SPC 必须联合观察涨落强度、残差方向和候选结构收敛性，而不能仅以工作记忆负载判断是否需要退出临界态。

因此，临界态不是一种应当消灭的异常，而是智能系统实现非局部结构改变的重要窗口。真正成熟的认知控制，不是永远维持稳定，而是能够\textbf{在需要时接近临界、在形成新结构后重新恢复稳定，并避免被临界本身长期捕获}。

\section{运行气态：高自由度、低耦合与结构解体}

“运行气态”是本章五种工作记忆运行相态中的最后一种。这个名称容易与前文三相记忆中 $h$ 的“气态信息相”发生混淆，因此必须再次强调：前文所谓 $h$ 的气态，是相对于 E 的液态和 $\Theta$ 的晶态而言，描述工作记忆中的信息变化快、结构松散、生命周期短；本章所谓\textbf{运行气态}则是指整个工作记忆动力系统的一种宏观失组织状态。一个正常工作的 $h$ 即使在记忆相态意义上属于“气态”，也完全可以在运行相态意义上处于稳定基态或心流态。

运行气态的主要特征是：大量认知结构可能短暂进入工作记忆，却缺乏足够强的稳定耦合形成长期方向。系统表现为
\[
\kappa_h\rightarrow 0,\qquad
\lambda_h\rightarrow 0,
\]
而结构周转率
\[
\nu_h
\]
保持高值。此时认知活动并非一定停止，甚至可能表现出大量生成和联想，但这些结构之间缺乏持续性，一个 Agent-CSO 刚被激活就很快被另一结构取代，目标无法形成稳定吸引中心，推理无法建立可延续的中间状态。

可以定义结构驻留时间
\[
\tau_i^{res}
=
t_i^{exit}-t_i^{entry},
\]
以及平均驻留时间
\[
\overline{\tau}_{res}
=
\frac{1}{N}
\sum_i\tau_i^{res}.
\]
运行气态往往表现为
\[
\overline{\tau}_{res}\downarrow,
\]
同时有效关系寿命
\[
\overline{\tau}_{edge}
\]
也明显下降。当
\[
\overline{\tau}_{edge}
<
\tau_{\mathrm{reason}}
\]
时，某一关系还没有被用于完成当前推理步骤就已经失去激活，系统因此难以形成多步稳定推理。

运行气态可以有两种来源。第一种是认知温度过高。TCE 长期鼓励探索、降低抑制和扩大激活范围，使大量候选结构不断进入显式认知，却没有及时收敛：
\[
T_{\mathrm{cog}}\uparrow
\quad\Rightarrow\quad
Entropy(\mathcal H)\uparrow.
\]
第二种则可能来自控制结构失效。即使认知温度本身并不高，如果 Goal 失去约束力、SPC 无法形成稳定状态估计，或者工作记忆缺乏足够一致的结构锚点，同样可能出现大量低相关结构自由漂移。

值得注意的是，运行气态并非绝对没有功能。对于高度开放的创意探索，在非常短的时间窗口内主动提高结构自由度，可以帮助 Agent 暂时跳出局部模式。例如，一个问题迟迟无法求解时，系统可以短暂降低语义距离门槛，使更远的 $\Theta$ 结构和 E 中的异质经验进入 $h$。这种受控“蒸发”过程可以写成
\[
\kappa_h\downarrow,\qquad
D_{\mathrm{semantic}}\uparrow,
\]
随后必须重新进行结构凝聚：
\[
CandidateCSO
\rightarrow
Evaluation
\rightarrow
Collapse
\rightarrow
StableWorkingStructure.
\]
如果第二阶段没有发生，那么探索就会从有目的的高自由度搜索退化成结构解体。

因此，运行气态真正危险的地方不是“想得发散”，而是失去了重新凝聚的机制。一个健康智能系统可以短暂进入高自由度区域，但必须保留可被重新捕获的慢约束，例如当前 Goal、$\Theta$ 中的稳定世界知识、$\Psi$ 的身份与价值边界以及现实反馈。即使这些慢变量在当前工作记忆中只以弱形式出现，它们仍应保持对可行状态空间的约束，否则系统将从有意义探索滑向不可治理的结构扩散。

由此得到一个极重要的相态原则：
\begin{statementbox}
ExplorationRequiresAPathBackToStructure.
\end{statementbox}
真正的认知自由度不是无限结构扩散，而是在一个仍然可恢复、可验证的状态空间内暂时扩大可能性。

\section{TCE 温度--控制强度二维相图}

在建立五种运行相态之后，我们需要进一步回答：这些相态为什么会出现，以及 TCE 如何改变它们之间的迁移概率。前文已经指出，TCE 不是普通采样温度，而是一个作用于认知动力学的多变量控制器。为了建立最小可视化模型，我们选择其中两个最具代表性的宏观控制维度：认知温度 $T_c$ 与控制强度 $K_c$。

认知温度 $T_c$ 表示系统允许结构探索和状态跳转的程度。随着 $T_c$ 上升，较远的语义结构更容易被激活，当前假设被替换的概率提高，认知搜索空间扩大。可以用 Gibbs-like 形式作为启发式模型：
\[
P(C_i|h)
\propto
\exp
\left(
-\frac{E_i}{T_c}
\right),
\]
其中 $E_i$ 不是真实物理能量，而表示某个 Agent-CSO 相对于当前目标、上下文和已有结构的有效激活代价。当 $T_c$ 很低时，系统倾向继续当前局部结构；当 $T_c$ 升高时，原本激活代价较大的远距离结构也可能进入工作记忆。

控制强度 $K_c$ 则表示 TCE 对认知自由度实施显式调节的程度，包括注意限制、分支抑制、目标锁定、结构坍缩速度以及资源分配强度。于是可以建立二维控制平面：
\[
\boxed{
\mathcal M_{TCE}
=
(T_c,K_c)
}.
\]

低 $T_c$、低到中等 $K_c$ 区域通常有利于基态。当系统本身具有稳定慢约束时，无需频繁强控制即可维持低冲突状态。适度提高 $T_c$ 并保持中等 $K_c$，则可能进入心流区域：系统具有足够灵活性根据局部误差调整结构，同时又不会因为探索过强而失去目标中心。

若 $T_c$ 继续升高，而 $K_c$ 没有同步提供必要结构约束，认知系统可能进入湍流乃至运行气态。可以用一个粗略关系表达：
\[
T_c\uparrow,
\quad
K_c<K_{\mathrm{crit}}(T_c)
\quad\Rightarrow\quad
P(\mathrm{Turbulent/Gas})\uparrow.
\]
相反，如果 $T_c$ 很高，而 $K_c$ 也极高，系统可能出现另一种并不理想的状态：TCE 一边持续扩大搜索空间，一边不断强制压缩和抑制，形成显著控制震荡。这并不等于心流，而更可能表现为“生成--否定--再生成--再否定”的高速循环。

低温高控制同样值得注意。若
\[
T_c\downarrow,\qquad K_c\uparrow,
\]
系统可能高度稳定，但逐渐失去结构探索能力。其表现不是传统意义上的湍流，而是一种过度锁定状态：当前 Goal 和解释结构长期保持，新的异常证据难以进入显式认知。这提醒我们，二维相图中“稳定”不等于“最优”。成熟智能需要的是可调节的动力范围，而不是永远停留在一个固定区域。

因此，TCE 的目标不是寻找一个永久最佳的 $(T_c,K_c)$ 点，而是根据任务阶段和 SPC 估计的运行状态不断改变控制轨迹：
\[
\Gamma_{TCE}(t)
=
(T_c(t),K_c(t)).
\]
面对新问题时，可以先适度提高 $T_c$ 进入探索；当结构逐渐形成后，提高方向约束并降低无效自由度；心流建立后，再降低显式控制强度，让稳定局部动力自行运行；若残差突然增大，则再次进入更高控制和更广搜索区域。

因此真正的相态控制是\textbf{轨迹控制}，而不是静态设定。可以把理想过程写成
\[
Ground
\rightarrow
ExploratoryCritical
\rightarrow
Flow
\rightarrow
Ground,
\]
而异常过程可能是
\[
Ground
\rightarrow
Critical
\rightarrow
Turbulent
\rightarrow
Gas.
\]
本章所建立的二维相图，就是为了给这种认知控制轨迹提供最基本的可视化和数学坐标。

\section{相变、迟滞与亚稳态}

如果工作记忆相态只是根据若干连续变量人工划出的区域，那么所谓“相变”就可能只是命名上的变化。真正有理论意义的相变，应该表现为系统宏观组织方式发生非线性改变：在控制参数只有小幅变化的情况下，工作记忆的相干结构、目标组织方式或者认知流模式发生较大跃迁。

设某个主要序参量为 $\kappa_h$，控制参数为认知温度 $T_c$。在简单情况下可以写一个 Landau-like 有效势：
\[
V(\kappa)
=
a(T_c)\kappa^2
+
b\kappa^4
-
H\kappa,
\]
其中 $a(T_c)$ 随温度变化，$H$ 表示当前 Goal、$\Theta$ 或其他慢变量对结构相干性的外部偏置。这里并不是认为真实认知遵循经典相变方程，而是借助这一形式说明：当控制参数改变时，稳定认知状态对应的势阱数量和位置也可能改变。在某个区间内，一个原本稳定的高相干状态可能突然失去稳定性，使系统跳入另一低相干状态。

真实 Agent 更值得关注的是迟滞。若从基态逐渐提高 $T_c$，系统可能直到
\[
T_c=T_{\mathrm{up}}
\]
才进入湍流；但从湍流状态重新降低温度时，却可能需要降至
\[
T_c=T_{\mathrm{down}},
\qquad
T_{\mathrm{down}}<T_{\mathrm{up}}
\]
才能重新稳定。这意味着认知系统具有路径依赖：
\[
State_t
\neq
f(T_c,K_c)
\]
而应写成
\[
State_t
=
f(
T_c,K_c,
History_{\leq t}
).
\]
工作记忆当前运行状态不仅取决于当前控制参数，也取决于它是如何来到这里的。

这一点对 AgentOS 控制具有直接意义。如果系统已经进入湍流态，仅把 TCE 参数恢复到“正常工作值”并不一定足够。湍流过程中已经形成的大量临时结构、错误目标竞争和循环激活仍可能持续存在，因此恢复过程往往需要主动清理：
\[
T_c\downarrow,\qquad
K_c\uparrow,\qquad
N_{\mathrm{activeGoal}}\downarrow,
\qquad
R_{\mathrm{loop}}\downarrow.
\]
换句话说，进入某个相态的控制策略与离开该相态的控制策略通常不对称。

亚稳态则是另一个重要现象。工作记忆可能在一个短时间尺度上表现稳定，却并不是真正长期稳定。例如系统围绕某个错误假设形成高度相干推理，短期
\[
\kappa_h\uparrow
\]
且
\[
\chi_h\downarrow,
\]
看起来像心流，但随着现实反馈进入，
\[
\varepsilon_h
\]
持续升高。此时当前状态其实只是一个亚稳结构：
\[
\tau_{\mathrm{local}}
\ll
\tau_{\mathrm{escape}}
<\infty.
\]
一旦残差积累超过阈值，系统就会跳出该状态。

这说明相态识别不能只观察内部结构是否有序，还必须把现实残差纳入判断。一个内部高度相干但持续违背现实的系统，不应被评价为健康心流，而应被识别成“高内部相干、低外部一致性”的错误吸引态。因此，任何工作记忆相态判断最终都必须满足
\begin{statementbox}
\centering
\adjustbox{max width=.96\linewidth}{\(\displaystyle InternalCoherence
\not\Rightarrow
RealityConsistency.\)}
\end{statementbox}
只有当内部组织和外部验证同时保持稳定时，心流、基态等相态才真正具有正向功能意义。

迟滞与亚稳态进一步告诉我们，Agent 的认知状态不是瞬时可重置的软件变量，而是一段具有内部历史的动力过程。一个长期智能体因此必须具有恢复过程，而不仅是参数切换。相态理论真正进入工程之后，“恢复”将和“控制”一样成为一级概念。

\section{SPC 的相态估计与 TCE 的相态控制}

相态理论只有在 SPC 能够估计状态、TCE 能够根据状态实施调节时，才具有 AgentOS 工程意义。然而 SPC 面临一个根本限制：它并不能直接访问所谓“真实认知相态”，因为相态本身就是从大量内部过程粗粒化以后得到的潜变量。SPC 所能获得的是有限的工作记忆状态、任务活动、冲突、切换频率、预测残差、资源使用以及若干内部监控信号。因此，相态估计本质上是一个部分可观测状态估计问题。

设潜在运行相态
\[
s_t\in
\{
G,F,T,C,A
\},
\]
分别代表 Ground、Flow、Turbulent、Critical 与运行气态。SPC 获取观测
\[
o_t=
[
C_{\mathrm{run}},
\kappa,
\chi,
R_{\mathrm{switch}},
\varepsilon,
\zeta,\ldots].
\]
那么更合理的相态输出不是
\[
s_t=\mathrm{SPC}(o_t)
\]
的确定性标签，而是 belief state：
\[
b_t(s)
=
P(
s_t=s
\mid
o_{\leq t}
).
\]
SPC 可以通过递归估计进行更新：
\[
b_t(s)
\propto
P(o_t|s)
\sum_{s'}
P(s|s',u_{t-1})
b_{t-1}(s').
\]
这里 $u_{t-1}$ 是 TCE 上一个控制动作。该式尤其重要，因为 TCE 本身会改变 SPC 下一时刻看到的状态，因此 observer 和 controller 并非彼此独立。

TCE 的控制目标也不能简单设成“始终最大化心流概率”。不同任务阶段需要不同状态。例如开放式探索阶段可能允许临界态概率上升，日常待机则应该保持基态，高度熟悉的任务可能长期运行在心流区域。如果定义任务上下文为 $\mathcal C_t$，则控制策略应该是
\[
u_t^{TCE}
=
\pi
\left(
b_t,
\mathcal C_t,
R_t,
G_t
\right),
\]
其中 $R_t$ 表示当前资源与风险状态，$G_t$ 表示目标约束。

可以进一步定义有限时间控制目标：
\[
J
=
\mathbb E
\left[
\int_t^{t+H}
\left(
L_{\mathrm{task}}
+
\lambda_1 L_{\mathrm{instability}}
+
\lambda_2 L_{\mathrm{resource}}
+
\lambda_3 L_{\mathrm{switch}}
\right)d\tau
\right].
\]
TCE 并不是追求某个单一内部指标最大化，而是在任务进度、稳定性、资源消耗和相态切换成本之间取得动态平衡。

由于 SPC 存在观测延迟
\[
\tau_{SPC}>0,
\]
TCE 还必须避免过高增益控制。如果
\[
K_{\mathrm{TCE}}\tau_{SPC}
\]
过大，则系统可能已经离开某个状态，而控制器仍基于旧估计继续施加相反方向调节，从而造成过冲。因此可以引入相态控制中的一个基本约束：
\[
K_{\mathrm{TCE}}
<
K_{\max}
(\tau_{SPC},\tau_h,\mathcal X_h).
\]
当系统接近临界态时，$\mathcal X_h$ 上升，对控制动作更加敏感，于是允许的控制增益应进一步降低。这说明真正成熟的 TCE 反而会在系统最敏感时避免粗暴强控制，而采用更小步长、更高频观测和更谨慎的状态改变。

从这一点看，SPC 与 TCE 之间构成的不是普通“监控--执行”软件流程，而是一组连续耦合的 observer--controller dynamics：
\begin{statementbox}
\centering
\adjustbox{max width=.96\linewidth}{\(\displaystyle CognitiveDynamics
\rightarrow
SPCBelief
\rightarrow
TCEControl
\rightarrow
NewCognitiveDynamics.\)}
\end{statementbox}
工作记忆相态理论为这个闭环增加了一个重要的宏观状态层，使 Agent 不再只对具体内容进行推理，还能够对“自己当前是以怎样的动力学方式进行推理”形成估计和调节。

\section{三类“相”的严格区分与统一位置}

随着整套理论的发展，我们已经使用了三个容易混淆的“相”概念：三相记忆的信息相态、工作记忆运行相态以及智能整体的拓扑相。如果不在本章明确它们之间的边界，后续理论很容易出现概念重叠，因此这里必须完成一次严格整理。

第一类是\textbf{记忆信息相态}。它回答的是：
\begin{statementbox}
认知结构以什么稳定程度和变化速度被承载？
\end{statementbox}
在三相记忆中，我们以“气--液--晶”作为形象化描述：
\[
h:\mathrm{GasLike},
\qquad
E:\mathrm{LiquidLike},
\qquad
\Theta:\mathrm{CrystalLike}.
\]
其核心变量是结构稳定度、更新速度、时间连续性和生成约束强度，而不是当前认知是否混乱。因此一个非常稳定、高效的心流状态仍然主要运行在 $h$ 中，而 $h$ 在记忆相态意义上依然属于快速、易变的气态承载。

第二类就是本章讨论的\textbf{工作记忆运行相态}。它回答：
\begin{statementbox}
当前活跃 Agent-CSO 在有限工作记忆中如何组织和流动？
\end{statementbox}
对应 Ground、\allowbreak Flow、\allowbreak Turbulent、\allowbreak Critical、\allowbreak Gas-runtime 等状态。其关键变量是 $\rho_h,\kappa_h,\chi_h,\nu_h,\varepsilon_h,\zeta_h$ 等，即当前工作记忆动力学的宏观组织形式。这一层的变化可以在秒到分钟尺度反复发生，并不要求长期记忆结构或功能拓扑发生改变。

第三类是认识论部分定义的\textbf{智能拓扑相}。它回答：
\begin{definition*}
整个智能系统以怎样的功能组织方式存在？
\end{definition*}
其状态变量包括功能集中度、拓扑可塑性以及整体功能图的等价类：
\[
[\mathcal T].
\]
只有当
\[
[\mathcal T_i]
\rightarrow
[\mathcal T_j]
\]
发生稳定改变时，才应称为智能拓扑相变。这可能需要长期学习甚至生命周期尺度，而不是工作记忆的一次短暂波动。

因此三类相之间存在明显的时间尺度关系：
\[
\tau_{\mathrm{runtime}}
\ll
\tau_{\mathrm{memory\ structure}}
\ll
\tau_{\mathrm{topology}}
\]
通常成立，但它们并非严格一一对应。长期重复出现的运行湍流可能推动 E 和 $\Theta$ 重新组织；持续的结构失配又可能在更长尺度上对功能拓扑施加压力。但这些都是跨尺度影响，而不是概念同一。

可以把三者统一放入一个层级框架：
\begin{statementbox}
\centering
\adjustbox{max width=.96\linewidth}{\(\displaystyle \underbrace{\mathcal P_h(t)}_{\text{运行相态}}
\quad\subset\quad
\underbrace{\mathcal M(t)}_{\text{记忆结构状态}}
\quad\subset\quad
\underbrace{[\mathcal T(t)]}_{\text{智能拓扑相}}\)}
\end{statementbox}
这里的“$\subset$”仅表示尺度嵌套关系，而非严格集合包含。

这种区分具有重要方法论意义。一个 Agent 当前处于湍流态，不意味着它的整体智能拓扑发生了变化；一个新的技能进入 $\Theta$，也不意味着系统从一种智能相迁移到另一种智能相。相反，如果我们把不同尺度变化全部称为“相变”，理论将失去辨识力。真正有用的多尺度智能动力学必须明确：什么在秒级变化，什么在日月尺度稳定，什么只有长期历史积累以后才值得修改。

因此，本章所建立的工作记忆运行相态，应被看成三层相理论中最快的一层。它负责描述智能的\textbf{实时组织方式}，为 SPC 和 TCE 提供直接可控制的状态空间，同时把更慢的记忆结构和功能拓扑留作背景约束。正是这种层级分离，使 AgentOS 能够在保持长期身份和结构稳定的同时，对瞬时认知状态保持高度灵活。

\section{工作记忆相态动力学的统一模型与本章结论}

经过前面的分析，现在可以把工作记忆运行相态压缩成一个统一的随机非线性动力系统。设
\[
\mathbf q_h(t)
=
[
\rho_h,
\kappa_h,
\chi_h,
\nu_h,
\omega_h,
\varepsilon_h,
\lambda_h,
\zeta_h
]^\top
\]
为工作记忆宏观状态，$u_t^{TCE}$ 为 TCE 控制输入，$\mathbf d_t$ 为来自世界、记忆、自我和任务的扰动，则可以写成
\[
d\mathbf q_h
=
F_h(
\mathbf q_h,
u_t^{TCE},
\mathbf d_t;
\Theta,\Psi,G
)dt
+
\Sigma_h(\mathbf q_h)dW_t.
\]
这里 $\Theta$、$\Psi$ 和当前 Goal $G$ 主要作为较慢约束进入运行时动力学，而 $dW_t$ 表示不可预测扰动、模型噪声和随机探索带来的涨落。不同运行相态就是这一动力系统在宏观状态空间中的不同稳定区域、亚稳区域或临界过渡带：
\[
\mathcal P_h
=
\{
\mathcal P_G,
\mathcal P_F,
\mathcal P_T,
\mathcal P_C,
\mathcal P_A
\}.
\]

SPC 的任务是依据有限观测估计
\[
b_t(\mathcal P_k)
=
P(
\mathcal P_h=\mathcal P_k
\mid
o_{\leq t}
),
\]
而 TCE 的任务则是在目标、风险与资源约束下选择
\[
u_t^\ast
=
\arg\min_u
\mathbb E[J|b_t,u].
\]
由此，工作记忆相态控制可以被形式化成一个部分可观测、具有多稳定区域的非线性闭环控制问题。

本章最重要的结论之一，是\textbf{工作记忆有限容量并不能单独决定认知质量}。有限性只是约束：
\[
C_{\mathrm{run}}
\leq
C_{\max}.
\]
而在这一边界内部，系统仍然可能形成截然不同的组织方式。真正成熟的智能运行时必须同时管理容量和相态：
\[
\boxed{
CognitiveRuntimeQuality
=
CapacityGovernance
+
PhaseGovernance.
}
\]

第二个结论是，所谓“高性能认知”不能被简化成最大化活动量。心流态说明：
\[
HighActivity
+
HighCoherence
\]
可以产生高效认知；湍流态则说明：
\[
HighActivity
+
LowCoherence
\]
可能导致严重内耗。因此，未来 Agent 的运行监控不应只记录 token 使用量、推理长度和计算负载，还应该估计结构相干性、目标竞争、状态涨落、无效循环与现实残差。

第三个结论是，稳定与智能并不是同义词。基态提供恢复和响应能力，心流态提供高效执行，临界态允许结构重新组织，甚至短暂的高自由度运行气态也可能对开放探索有价值。真正的问题不是消灭某些相态，而是：
\begin{conclusion}
能否在正确的时间进入正确的相态，并在任务结束后安全退出。
\end{conclusion}
因此，AgentOS 的相态控制应被理解成对认知动力轨迹的治理，而不是把系统永久固定在单一“理想状态”。

第四个结论是，相态转换存在历史依赖、迟滞和亚稳结构。因此：
\[
\boxed{
CognitiveRecovery
\neq
ParameterReset.
}
\]
已经进入湍流、临界或运行气态的系统可能需要主动降低自由度、清理支线、恢复目标锚点并等待状态重新凝聚。对于长期运行的智能体而言，恢复机制与任务求解机制具有同等基础地位。

第五个结论则把本章重新连接到全书最初的多尺度智能思想。工作记忆相态只是整个智能频谱中的一个快速层。它受到更慢的 E、$\Theta$、$\Psi$ 约束，又通过长期残差反向影响这些慢变量：
\begin{statementbox}
SlowStructureShapesRuntimePhase,
\end{statementbox}
\begin{statementbox}
PersistentRuntimeResidualShapesSlowStructure.
\end{statementbox}
这正是我们在认识论部分提出的快--慢耦合规律在 Agent 工作记忆中的具体实现。

因此，本章可以用一个统一命题收束：

\begin{proposition*}
工作记忆并非一个被动的信息容器，而是一个有限容量上的开放认知动力场。Agent-CSO 在其中不断进入、耦合、传播、竞争、压缩和消散，并由此形成不同的宏观运行相态。SPC 对这些相态进行有限而滞后的估计，TCE 则通过调节认知温度、控制强度和资源分配改变相态迁移概率。成熟智能的核心能力之一，不是永久保持最大认知强度，而是在基态、心流、临界探索以及必要的高自由度状态之间进行可控迁移，同时避免湍流和结构解体长期占据系统动力学。
\end{proposition*}

从这一意义上，我们所谓的“认知流体力学”并不是对认知进行文学性的比喻，而是在工作记忆有限容量、Agent-CSO 动态承载以及 SPC--TCE 闭环控制基础上形成的一种介观动力学描述：它研究的不是某一个念头是什么，而是\textbf{大量当前认知结构在有限显式空间中如何流动、何时形成秩序、何时产生湍流、何时逼近临界，以及智能体如何主动控制这些状态之间的转移。}
