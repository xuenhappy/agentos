## 基本原理与核心思想

本书的出发点是：**智能是有时空边界、受容量与身体约束、依靠现实反馈持续组织自身的动力过程。** 理解一个智能系统，需要说明它观察和作用于什么范围、哪些状态以什么速度变化，以及这些状态如何形成闭环。一次回答的正确性只是这一过程的局部表现；持续智能还涉及经历的积累、能力的形成、自我调节与身份连续。

贯穿全书的基本闭环是：**状态估计 → 预测 → 行动 → 观测 → 残差 → 更新**。身体控制、当前思考、经验巩固和长期自我变化运行在不同时间尺度上：慢层提供目标、先验与约束，快层在局部闭合反馈；快层长期无法消除的残差推动慢层调整。书中所说的智能“分形性”，指不同尺度上可以重复出现相似的闭环形式，各层仍具有各自的状态空间、权限与时间尺度。

CSO（认知结构对象）为这套动力学提供结构语言：对象、关系、事件、目标、约束和可能未来都可以作为认知结构研究；Agent-CSO 则描述某个主体如何表示、承载和使用它们。由此，学习既包括内部状态与参数的改变，也包括认知结构在表示方式、功能位置、时间尺度及内外载体之间的迁移。稳定能力可以逐渐沉降为局部技能，意外残差则向更高层升级；现实观测始终保留纠正内部预测的权限。

### 智能的分类：集中度与拓扑可塑度

在给定的空间边界和观察时间窗口内，本书用两个坐标描述智能的宏观组织形态：

- **认知集中度**：关键认知处理、决策影响和控制权在多大程度上集中于少数功能位置。它描述功能上的集中程度，不能直接用机器数量或物理位置判断。
- **功能拓扑可塑度**：稳定的功能关系、闭环组织、职责分布和认知结构承载关系，在生命周期中能够发生多大程度的持续重组。一次注意转移或临时路由变化不足以说明拓扑已经改变。

| 认知集中度 | 拓扑可塑度 | 智能形态 | 组织特征 |
| --- | --- | --- | --- |
| 高 | 低 | 中央固定型智能 | 主要认知由中央核心承担，功能组织相对稳定 |
| 低 | 低 | 分布固定型智能 | 多个局部闭环分担认知，长期分工与连接相对稳定 |
| 高 | 高 | 自重构中央智能 | 保持中央认知核心，同时能持续重组功能关系与能力承载方式 |
| 低 | 高 | 分布发育型智能 | 分布式局部闭环可随经验形成、重组并演化出新的分工 |

这四类是连续相空间中的典型区域，不代表能力高低或必经的进化顺序；同一系统的分类也取决于观察尺度。“智能相”描述宏观组织形态，三相记忆描述结构如何持续存在，工作记忆的心流、湍流等则描述运行状态，三者需要分别理解。**固定功能拓扑仍然可以支持持续学习**：状态、经历与生成结构可以不断变化，而功能组织关系保持稳定，这正是本书构建 AgentOS 原理论时采用的起点。

详见[智能相分类](chapters/ch_epistemology_007.tex)与[智能频谱](chapters/ch_epistemology_006.tex)。

### 三相记忆：让过去持续影响未来

三相记忆的核心问题是：**过去的经历如何继续改变未来的认知与行动？** 本书从活动性、历史身份和生成作用区分三相：

| 相 | 含义 | 持续方式 |
| --- | --- | --- |
| `h`：工作记忆／当前活动态 | 正在参与当前认知闭环的对象、目标、假设和关系 | 过去仍作为“现在”起作用；归属依据是当前活动性，而非固定保存时长 |
| `E`：情景经历 | 已退出当前活动、但保留事件身份的关系实例 | 将对象、位置、时间、动作与结果绑定为“发生过什么”，允许召回和后续重解释 |
| `Θ`：长期生成结构 | 由经历逐渐形成的规则、技能、先验与生成模型 | 过去成为未来认知的生成条件，影响注意、预测、理解与行动 |

其典型时间尺度满足 `τ_h ≪ τ_E ≪ τ_Θ`，核心转换是 **`h ↔ E ↔ Θ`**，并包含 `Θ → h` 对当前认知的直接约束：

- **`h → E`，经历形成**：选择有价值的当前活动，保留其事件边界、来源与关系，而非记录全部激活。
- **`E → h`，情景召回**：把与当前问题有关的经历重新带入活动认知，参与判断与行动。
- **`E → Θ`，选择性巩固**：从经历中提取可迁移的规律和技能，使“记得某件事”逐渐转化为“学会如何处理一类事”。情景层也为快速经历与慢结构之间提供保护，避免一次偶然或错误经历立即成为长期规则。
- **`Θ → E` 与 `Θ → h`，生成与重解释**：已有结构帮助理解和重解释经历，也支持预测、想象与当前推理；生成的可能情景必须与实际发生过的经历保持区别。

例如，机器人初次抓取杯子时，当前杯子位置、接触反馈和抓取假设属于 `h`；这次抓取的具体过程与结果形成 `E`；经过多次尝试与校正，稳定的抓取规律逐渐进入 `Θ`。下一次抓取又由这些规律指导，并在新反馈中继续修正。这体现了循环 **`Θ_t → h_t → E_t → Θ_{t+1}`**：经历塑造结构，结构生成新的活动。

“气态、液态、晶态”是对活动性、情景身份保持和生成约束的组织方式所作的物理隐喻。三相可以由同一种计算介质承载；RAM、数据库与模型权重并不会自动分别构成三相。遗忘、召回、巩固和再解释共同调节过去如何影响未来，长期结构也始终保留可塑性。

详见[三相记忆的信息相态](chapters/ch_principle_024.tex)、[认知结构持续化动力学](chapters/ch_principle_024b.tex)与[GPU 上的 What–Where 双通路及 Soft-HGU](chapters/ch_roadmap_080b.tex)。

## 核心议题

- **认知结构与承载分离**：用 CSO（认知结构对象）和 Agent-CSO 区分结构本身及其在主体中的承载，讨论结构迁移如何改变表示、时间尺度与功能拓扑。
- **三相记忆与持续学习**：以工作记忆状态 `h`、情景经历 `E`、长期生成结构 `Θ` 构成双向循环；讨论有限容量、选择性巩固、遗忘与多时间尺度可塑性。
- **持续主体与认知治理**：以自我慢变量 `Ψ`、生命周期生成倾向 `Ω`，以及 SPC、AHC、TCE 等机制研究身份连续、状态估计、内稳态调制和认知控制；通过 CCM、Scheduler、Boundary 与 Offloading 治理认知负载。
- **具身运行时与现实闭环**：以 `Agent Kernel ⋈ Body Runtime` 描述完整 Agent。身体可以是机器人，也可以是浏览器、Shell 或文件系统；SGC 表示实体、关系与认识论状态，FCS 表示现实对主体的功能作用，BPCC 承担快速身体预测控制，KRA 负责内核与运行时的适配。
- **预测、行动与现实权限**：高层预测通过约束与预测包络连接局部控制；真实观测和行动残差保留纠正内部模型的权限。
- **实现与生命周期工程**：从 GPU 上的 What–Where 双通路和 Soft-HGU 记忆验证，延伸到控制、培育、心理工程，以及组织与文明尺度的结构讨论。

## 本地编译

### 环境要求

- GNU Make 与 XeLaTeX；建议使用包含中文支持及常用宏包的完整 TeX Live 环境。
- 中文正文字体：检测到 `HYZhengYuan-45W` 时使用汉仪正圆字体族（另需 `HYZhengYuan-55W`、`HYZhengYuan-35W`）；否则回退到 `Source Han Serif SC`。
- 中文无衬线与等宽字体：`Noto Sans CJK SC`、`Noto Sans Mono CJK SC`。
- 西文字体：`TeX Gyre Pagella`、`TeX Gyre Heros`。
- `make check` 另需 Poppler 提供的 `pdfinfo`。

字体名称需与 `main.tex` 一致；缺少字体时应安装对应字体或调整配置。书稿包含大量插图与公式，完整编译需要一定时间。

### 常用命令

在仓库根目录执行：

```bash
# 完整编译，并复制为根目录发布版 PDF
make

# 按依赖关系构建 build/main.pdf
make pdf

# 单轮快速编译
make quick

# 检查日志中的 LaTeX 错误、未定义引用及缺失文件，并输出 PDF 信息
make check

# 将 build/main.pdf 复制为根目录发布版 PDF
make release

# 清理中间文件，保留 PDF
make clean

# 清理中间文件和生成的 PDF
make distclean
```

需要重建时，完整构建会连续运行两次 XeLaTeX，以生成目录与交叉引用。输出位于 `build/main.pdf`，`make release` 将其复制为 `智能动力学与AgentOS.pdf`。若只修改了 `elegantbook.cls` 或构建规则，需使用 `make -B` 强制重建，因为当前 Makefile 未将它们列入 PDF 的文件依赖。`make quick` 仅运行一轮，目录或引用仍可能需要再编译；`make check` 的日志检查也不能代替人工版面检查。

## 理论定位与讨论

本书提出的是一组结构假说、数学骨架、接口原则与工程判据，不提供可直接复制的产品代码，也不宣称已经解决人工意识。控制论、信息论、快慢系统、持续学习、具身认知与模型预测控制构成理论锚点；CSO、三相记忆、SPC/AHC/TCE、SGC/FCS、BPCC/KRA 等综合框架仍需长期、可重复且允许失败的实验检验。“相态”“频谱”“地貌”等物理隐喻应与已建立的物理定律区分。
